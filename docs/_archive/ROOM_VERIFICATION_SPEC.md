# 운종 · 리딩방 검증 설계 (ROOM VERIFICATION SPEC)

> ⚠️ **[이력·폐기]** 구 정체성("안 속는 곳") 기반 스펙 — 현행 정체성 권위 = `docs/BRAND_IDENTITY.md` (3기둥 무기·직시·자립 · "종목을 보는 눈을, 누구에게나"). 금감원 등록·신고 뱃지 등 사실 요소는 유효.

> **상태**: 설계만 확정 — **데이터(실제 채널) 확보·구현은 플랫폼(웹+모바일) 완성 후**.
> **목적**: 리딩방을 "안 속는 곳" 관점에서 중립·사실 기반으로 검증·제공하는 운종의 핵심 차별점 설계.
> (현재 틀은 일부 존재: 리딩방 리스트 탭 + 금감원 신고 검증 뱃지(FSS 1,738건) + 추천/비추천 투표(카카오 OAuth 활성화 시 동작).)

---

## 1. 배경 — 리딩방 법적 지형 (2026 기준)
- **합법 리딩방 = 「유사투자자문업」 신고 업체.** 금융위/금감원 신고 → **불특정 다수**에게 투자 정보 제공 가능.
- **2024.8 자본시장법 개정으로 합법 범위 축소:**
  - 합법 = 신고 + **단방향 채널만**(운영자만 글: 텔레그램 공지채널·유튜브·웹·이메일).
  - **불법**: ① 유료 **양방향 채널**(카톡 오픈채팅·텔레 실시간 대화방) ← 흔히 "리딩방" = 이제 불법, ② **1:1 개별 자문**(=등록 「투자자문업」 영역), ③ 수익률 보장·"손실 없다" 광고, ④ 미신고.
- **핵심**: "신고 = 합법"일 뿐 **"신고 = 믿을 만"은 아님**(신고 문턱 낮음, 품질·정직 보장 X). 신고 업체도 과장·먹튀·선행매매 사고 다수.

## 2. 운종의 포지션
- **중립 정보 제공자.** 사실(facts)을 모아 보여주고 판단은 이용자에게. **단정(고발)·단속기관 아님.**
- 운종 자체는 유사투자자문업이 아님(유료 리딩 X, 정보·커뮤니티·검증만).

## 3. 핵심 설계 결정 (확정)
1. **전체 리딩방을 다 리스트화**(최대한 포괄). 신고 안 된 곳도 다 넣되 "신고 미확인"으로 드러나게 → **사실 자체가 경고**.
2. **신고업체 + 광고업체를 상위 정렬.** 단 **광고는 'Sponsored'로 명확히 표시**(신고=신뢰 신호 ↔ 광고=유료, 분리 — V6 'Sponsored↔평가 분리' 원칙). "돈 내면 위로"로 신뢰 깨지지 않게.
3. **라벨은 '사실'로, '단정' 금지.** "금감원 유사투자자문업 신고 **확인됨 / 확인 안 됨**" 같은 객관 사실. **"불법·사기" 단정 X.** 이유: ① 채널↔회사 매칭이 빗나갈 수 있음(다른 상호로 신고됐을 수도) → "미신고" 단정은 틀릴 위험, ② 특정 업체 '불법' 단정 = **명예훼손·영업방해 소송 리스크**. (V6에서 별점 빼고 신고번호 검증으로 간 것과 동일 원칙 — 법적 방패.)

## 4. 리딩방 카드에 보여줄 '사실 신호' (후보)
- 금감원 유사투자자문업 **신고 확인 / 미확인** (+ 신고번호·신고일)
- **직권말소** 여부
- 채널 방식: **단방향(합법) / 양방향(2024 법상 불법)**
- **수익률 보장·과장 광고** 여부
- **1:1 유도** 여부
- (커뮤니티) 추천/비추천 투표 · 사기의심 신고 누적

## 5. 데이터 소스 — 회사 ≠ 채널
- **회사(업체) 목록 = 공식, 확보 가능.** 금감원 파인(fine.fss.or.kr) 「유사투자자문업자 신고현황」(조회·다운로드). **이미 1,738건 적재**(검증 뱃지). 정기 갱신(실시간 API 아님, 신고현황은 자주 안 바뀜 → 주기적 수신으로 충분).
- **채널 목록 = 공식 소스 없음.** 금감원은 '회사'를 신고받지 '그 회사의 텔레/카톡 채널'까지 등록·공개 안 함. → **초기 큐레이션 + 사용자 제보**로 점진적 확보.
- **채널 ↔ 회사 매칭**: 별도 작업. 매칭 안 되면 "신고 미확인"(단정 금지).

## 6. 단계(시퀀싱) — 확정
1. **플랫폼(틀) 완성 먼저** (웹 + 모바일).
2. **그 후 리딩방 채널 데이터 확보** (큐레이션 + 제보).
3. "**데이터 먼저 확보 → 신뢰 → 깨끗한 문화**." 규제기관(금감원) 협력·신고는 **데이터·신뢰가 쌓인 후**. 서둘러 모으다 부정확하면 신뢰 훼손 → 정확한 틀·검증 우선.
4. 운종은 끝까지 **정보 제공자**(사실 제공)지 고발자가 아님 — 그게 법적으로 안전하고 길게 강함.

## 7. 수익화 연계
- Tier 1·2·3 **인증 광고**(Sponsored). **광고 ↔ 평가 명확 분리·표시** 필수(3번 원칙).

## 8. 법적 주의
- 본 설계는 변호사 자문 아님. 게시 전 **법률 검토 권장**(특히 라벨 문구·미확인 표기·제보 처리).
- 원칙: **특정 업체 '불법/사기' 단정 금지, 검증 가능한 '사실(신고 여부 등)'만.**
