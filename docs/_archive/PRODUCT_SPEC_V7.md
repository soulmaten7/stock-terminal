# 운종(UNJONG) · PRODUCT SPEC V7 — 신뢰할 수 있는 중립 관문 + 검증

> ⚠️ **[이력·폐기] 이 스펙(V7)은 구 정체성("투자상품에 속지 않게 돕는 곳" · 검증=핵심 차별화) 기반 — 현행 아님.** 현행 권위 = `docs/BRAND_IDENTITY.md`(3기둥 무기·직시·자립 · 슬로건 "종목을 보는 눈을, 누구에게나"). 옛 '검증' 탭은 현재 '정보' 하위탭 '유사투자자문 조회'(KR). 아래 본문은 히스토리 보존용.

> **V7 대전환 (2026-06-19 확정).** V6까지의 "네이버증권 레이아웃 + 랭킹·차트·종목상세 = in-house 데이터 플랫폼" 노선을 **폐기**하고, 운종을 **"흩어진 주식 정보·서비스로 가는, 검증된 중립 관문(Gateway)"**으로 재정의한다.
> 마스터 한 줄은 그대로: **"투자상품에 속지 않게 돕는 곳."**
> V6 보존(히스토리): `docs/PRODUCT_SPEC_V6.md`

---

## 0. 왜 바꿨나 (핵심 깨달음)

- 랭킹·차트·종목상세 = **네이버증권/토스를 in-house로 다시 짓는 것.** 자본·인력으로 못 이기고, '관문'이 아니라 '목적지'라 정체성과 반대 방향.
- 운종만의 빈 자리 = **① 흩어진 주식 정보·서비스를 한 곳에서 접근하는 중립 관문 + ② 리딩방·유사투자자문 검증**("어디가 안 속는 곳인지"를 사실로).
- 네이버·토스는 자기 데이터에 사용자를 **가둔다**(walled garden). 운종은 어디로든 **보낸다**(다른 플랫폼·리딩방·도구까지) = 중립.

---

## 1. 정체성 (LOCK)

운종 = **신뢰할 수 있는 중립 관문 + 검증.**

- **중립** (안 팔고·안 가둠) → 믿을 수 있음
- **검증** (어디가 안 속는 곳인지 '사실'로) → 올 가치 있음
- **관문** (한 곳에서 다 접근) → 편함

이 셋은 하나다: **"신뢰할 수 있는 중립 관문."**

---

## 2. 버림 / 살림

**버림(폐기):**
- 홈의 랭킹·차트·종목 미리보기
- `/market` 상품리스트 (ETF/ETN/리츠 디렉토리)
- `/stock/[code]` 종목상세
- → 전부 commodity(네이버가 더 잘함). 관문이 아니라 목적지.

**살림(재활용):**
- 추천/관심/신고 인프라, 로그인·토론 인프라 (→ 리딩방·커뮤니티에 재활용)
- `/toolbox`(주식 관련 링크모음) → **새 홈(게이트웨이)**의 뼈대

**제거 결정:** 리딩방에 **미리보기·좋아요/싫어요(투표) 없음** (§6 참고).

---

## 3. 구조

- **헤더 = 주식 / 코인.** (코인은 한국 주식 완성 후 같은 구조 복제.)
- **홈(`/`) = `/toolbox` 승격** (게이트웨이). 옛 홈(랭킹) 내림.
- **한국 주식 먼저** → 완성 후 미국·중국·홍콩·일본 확장.
- 한국 주식 = **카테고리 탭** 형식.

---

## 4. 한국 주식 — 카테고리 탭

`유튜브채널 · 뉴스 · 차트/기술분석 · 재무/종목분석 · 공시/규제 · 리서치/리포트 · ETF/펀드 · 공모주/배당 · 증권사/운용사 · 리딩방(검증)`

각 탭 = 큐레이션된 **사이트/채널 링크 디렉토리.**

- 포함 기준 (증권사·운용사·정보사이트): **제도권(금융위 인가)** 또는 **실재 + 유용 + 합법.** → 운종 큐레이션(품질 게이트).
- 사기·도박·불법리딩 유도 사이트 제외.

---

## 5. 유튜브 Top100 시스템 (자동)

- **주 1회 검색 크론** (Vercel Cron 또는 Supabase 스케줄러).
- 흐름: **YouTube Data API `search`(정밀 키워드) → 채널 발굴 → `channels.list` 구독자수 → 정렬 → Top100 → 그 주차 스냅샷 저장.**
- **주차 라벨**: "2026년 X월 Y주차 한국 주식 유튜브 구독자순" — 주1회 갱신 = 자연스러움 + 순위 변동.
- 비용: 무료 쿼터로 충분(주1회).

**정밀 포함 키워드 (코인엔 없는 주식 전용어):**
`코스피 · 코스닥 · 코스피200 · 공모주 · 배당주 · 우량주 · 가치주 · 국내주식 · 한국주식 · 증시 · 실적발표`

**검색에서 제외 (코인과 겹침):**
`종목 · 상한가 · 급등 · 테마 · 차트 · 단타/장타 · 시세 · 매수매도 · 시가총액 · 호재` + 광의어(`경제 · 시황 · 투자 · 재테크`)

**제외 블랙리스트 (채널 이름/설명에 있으면 컷):**
- 코인: `코인·비트코인·암호화폐·가상자산·알트코인·이더리움·업비트·빗썸·김치프리미엄·스테이킹·NFT·디파이`
- 부동산: `부동산·아파트·청약·분양`
- 기타: `골프·등산·먹방·게임`

**시드(안전망):** 빠지면 안 되는 대형 채널은 수동 시드로 보강 + 운영하며 제외 블랙리스트 축적.
**원칙:** "코인엔 존재조차 안 하는 단어"로 검색, 애매하면 무조건 뺀다.

---

## 6. 리딩방·유사투자자문 검증

- **미리보기·좋아요/싫어요(투표) 없음** — 투표 조작 리스크 제거 = 중립.
- **신원 인증 입장**: 등록하려면 신원(개인정보) 인증. 목적 = ① 익명 먹튀 진입장벽 ② 문제 시 금감원 **역추적.**
- **정렬**: 광고(뱃지) → 인증(랜덤 상위) → 미인증(랜덤 하위). (랜덤 = 조작 불가·중립.)
- **사실 라벨만**: 유사투자자문 등록 여부(금융투자협회 공시) · 신고 이력(FSS) · **출처 명시** · 당사자 **정정/반론 권리.**
- **운종은 '사기' 판단 안 함 / '안전' 도장 안 찍음.** 사실만 깔고 판단은 사용자. (보증 도장 = 사기 세탁소 됨, 절대 금지.)
- 미인증·익명방도 공시·신고로 운종이 깔아둠 → **"운종에 신원 인증해서 없는 방은 의심하라"는 문화 자체가 경고.**
- 심각 제보 → **금감원 전달** (공익 + 운종 권위).

---

## 7. 수익 모델

- **제휴(affiliate) — 특히 증권사 계좌개설 CPA.** "보내주고 대가 받는다" = 관문 본질과 일치.
- **표시된 광고** (상위노출 + 광고 뱃지).
- **절대 규칙**: **광고로 '노출'은 팔아도 '신뢰(검증·안전 판단)'는 안 판다.** 사실=공개, 광고=표시, 안전 보증=미판매.
- **순서**: 트래픽(검증·관문) 먼저 → 수익은 뒤. 돈부터 설계하면 신뢰가 먼저 죽는다.

---

## 8. 확장

- 한국 주식 **완성 후** → 미국·중국·홍콩·일본 + 코인. 같은 탭/구조 복제, 언어별·국가별 제휴 링크.
- 단, 검증·커뮤니티(moat)는 나라마다 거의 새로 지어야 함(규제·언어·데이터 다름) → **한 나라씩.**

---

## 9. 빌드 순서

1. **`/toolbox` → 홈(`/`) 승격** + 옛 홈·상품리스트(`/market`) 제거 + 헤더(주식/코인).
2. **유튜브 Top100 주간 크론** (search 정밀키워드 + 제외필터 + 주차 스냅샷).
3. **리딩방 검증** (신원인증 입장 + 랜덤정렬 + 사실 라벨 + 금감원 전달).
4. 나머지 카테고리 탭(뉴스·공시·리서치 등) 큐레이션 채우기.
