# 토스증권 전체 분석 + 운종 새 IA (토스식 개편 spec)

> ⚠️ **[이력·폐기]** 구 정체성("안 속게…신뢰 허브")·구 IA(토스식 개편) 기반 스펙 — 현행 정체성 권위 = `docs/BRAND_IDENTITY.md` (3기둥 무기·직시·자립 · "종목을 보는 눈을, 누구에게나"). 현행 IA는 게이트웨이 + 상단 종목·정보 2탭.

> **목적**: 토스증권 PC 웹 전체 페이지를 빠짐없이 분석(검색 + 화면) → 운종(타겟 중심 신뢰 허브)에 매핑 → 토스식 개편 구조 확정.
> **전제 합의(2026-06-04)**: 운종 = "정보·뉴스 포털"이 아니라 **"이 종목·상품·리딩방에 안 속게 해주는 타겟 중심 신뢰 허브"**. 구조는 토스처럼 단순·절제, 정체성은 운종 고유(평가·검증).

---

## 1. 토스증권 전체 구조 (검색 + 사용자 제공 화면 종합)

### 상단 4탭 (단순·직관)
**홈 · 피드 · 주식 골라보기 · 내 계좌** (+ 중앙 검색 + 로그인) · 우측 **관심 레일**(관심 주식 TOP10) · **하단 얇은 고정 티커**(투자유의사항 옆, 코스피·코스닥·나스닥·S&P·필반·VIX)

### 페이지별 디테일
| 탭 | 내용 |
|----|------|
| **① 홈** | 개인화 랜딩 — 주요 지수, 관심 종목, 실시간 거래 현황 (로그인 시 내 투자 중심) |
| **② 피드** | 콘텐츠/커뮤니티 스트림 — 종목 콘텐츠·뉴스·AI 인사이트·커뮤니티 글 (토스증권 AI) |
| **③ 주식 골라보기**(스크리너) | 조건 검색: **기본·재무·시세·기술 4 카테고리** 필터(PER·PBR·시총·업종·매출증감 등) → 종목 발굴. + 외국인/기관/개인 순매수 랭킹 둘러보기 |
| **④ 내 계좌** | 자산·거래내역·주문내역·판매수익·배당내역·계좌관리 (**거래**) |
| **+ 종목 상세** | 탭: **차트·호가 / 종목정보 / 뉴스·공시 / 거래현황 / 커뮤니티**. 우측: 주문 패널 + 관심 TOP10. 하단: 얇은 티커. "패널 편집"(커스터마이즈) |

### 커뮤니티 (★ 운종에 가장 중요)
- **종목별** 커뮤니티 (월 400만, 매매자 80%+ 사용)
- **신뢰 기반 설계**: 계좌 기반 프로필 · **주주 인증 배지** · **거래내역 공개** → 익명이지만 *실제 행동* 검증
- **ML로 허위 정보·리딩방·도배 자동 차단** + 신고 + 운영팀 모니터링
- **"의견 < 사실"** — 토론방을 없애거나 제한하며 *신뢰 기반 콘텐츠*로 브랜드 구축

### 디자인 철학
단순한 4탭 · 깔끔한 카드 · 넉넉한 여백 · 명확한 위계 · 패널 편집(개인화) · 다크모드 · **티커는 하단 얇게(ambient)**

## 2. ★ 결정적 인사이트 — 리딩방을 대하는 방식이 정반대

| | 리딩방 문제 | 해법 |
|---|---|---|
| **토스** | 커뮤니티 신뢰 해침 | **ML로 차단·삭제** (숨김) |
| **운종** | 투자자가 속는 대상 | **리스트업 + 금감원 검증 + 평가** (드러냄) |

→ 토스는 "리딩방을 가린다", 운종은 **"리딩방을 검증해서 보여준다"**. 같은 문제, 반대 해법.
**이게 운종이 토스·네이버와 다른 이유이자 해자.** 어떤 증권사 API로도 못 가져옴 — 운종이 직접 모으고 검증.

## 3. 토스 → 운종 매핑

| 토스 | 운종 | 처리 |
|------|------|------|
| 홈 (지수·관심·거래) | **홈 = 검증 대상 디렉토리**(종목·상품·리딩방 리스트) + 관심 + 신뢰 훅(금감원 1,738) | 🔄 적응 — 거래 대신 "검증 대상" 중심 |
| 피드 (콘텐츠·커뮤니티) | **토론·평가 스트림** (HOT 토론·평가 글) | 🔄 운종 토론/평가를 피드화 |
| 주식 골라보기 (정밀 스크리너) | **마켓 (발굴)** — 랭킹 + *라이트* 필터 | ⚠️ 결정 필요 (아래) |
| 내 계좌 (거래) | **MY** (관심·최근 본·내 평가) | ✂️ 거래 제거 |
| 종목 상세 5탭 | 운종 종목 5탭 (이미 유사) | ✅ 거의 동일 |
| 커뮤니티 (계좌인증·주주배지·ML 차단) | **운종 토론·평가** (추천/비추천·신고·금감원 검증) | 🔄 운종은 리딩방 *검증* |

### ⚠️ 결정 필요 1 — "주식 골라보기(스크리너)"
- 토스의 골라보기는 핵심 인기 기능(조건 필터 발굴).
- 근데 운종 V6 ④는 **"정밀 스크리너 X — 외부 링크(키움·FnGuide)"**.
- **절충안**: 운종은 *정밀* 스크리너는 안 하되, 마켓 페이지에 **가벼운 발굴(랭킹 + 시총·52주·인기 필터 — 지금 STEP 152~154로 만드는 중)** 까지만. 정밀 조건검색은 외부 링크. → V6 정체성 유지하면서 발굴 욕구 충족.

## 4. 제안 — 운종 새 구조 (6탭 → 4탭, 토스식 단순화)

현재 운종: 홈·마켓·토론·뉴스·평가검증·MY (6개). **토스 교훈 = 더 적게.** 제안:

| 운종 새 메뉴 | 내용 | 현재에서 변화 |
|------|------|---------------|
| **홈** | **검증 대상 디렉토리** = 종목 리스트 + 상품 리스트 + 리딩방 리스트(금감원 검증) + 관심 + 신뢰 훅. 일반 시장데이터·뉴스 나열 X | 🔴 큰 변화 (포털 홈 → 디렉토리 홈) |
| **마켓** | 종목 발굴·랭킹 (국내+미국, 시총/52주/인기 필터). 정밀스크리너는 외부 | ✅ 거의 유지 (STEP 152~154) |
| **토론·평가** | 토론 + 상품·리딩방 평가를 **하나의 신뢰 스트림**으로 (HOT 토론·HOT 평가·금감원 검증) | 🔄 토론+평가검증 통합 |
| **MY** | 관심·최근 본·내 평가/토론 (거래 X) | 🟡 메뉴 노출 |

- **뉴스** → 독립 탭 제거. 종목 안(뉴스·공시 탭) + 홈 헤드라인 한 줄. (포털 아님)
- **평가·검증** → 독립 탭 대신 **홈(디렉토리) + 토론·평가**에 전면 배치 (운종 핵심이라 숨기지 않음)
- **티커** → 제거 또는 토스식 하단 얇은 정적 스트립(우리 데이터). 지표는 홈 "주요 지수" 한 곳만(클릭 가능, 코스피·코스닥 실값 Yahoo `^KS11`/`^KQ11`)

## 5. 토스식 디자인 원칙 (운종 적용)
- **한 곳에 한 가지** — 같은 데이터 반복 금지(지표 3중 중복 제거)
- **카드 + 여백 + 명확한 위계** — 이미 V5 토스 색/카드 있음, *절제*를 강화
- **타겟 중심** — 모든 동선이 "이 종목/상품/리딩방 검증"으로 수렴
- **티커는 ambient** — 있다면 하단 얇게
- **운종 톤** — 차분·정확·신뢰 (트레이딩 어드레날린 X)

## 6. 제작 순서 (제안)
1. **네비 6→4탭 재편** (홈·마켓·토론평가·MY) + 뉴스 탭 정리 + 티커 결정
2. **홈 = 검증 대상 디렉토리**로 재구성 (종목·상품·리딩방 리스트 전면)
3. **토론·평가 통합** 스트림
4. 각 페이지 토스식 절제 패스
