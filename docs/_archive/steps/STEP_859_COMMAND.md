## §1 — 지평을 원전과 동일하게

1. **탐색 상한 = 25년.** 배치·API·엔진 호출에서 `maxYears: 100`을 제거하고 **원전값 25**로 통일.
2. 🔴 **`over_cap` verdict의 의미가 바뀐다** — "100년 초과"가 아니라 **"25년 가치 < 주가"** = 원전의 `"25+"`.
   - verdict 이름을 바꿀지, 의미만 바꿀지 판단하고 **사유 기재**. 🔴 DB 마이그레이션이 필요하면 `as_of`로 새 행을 쌓고 과거 행은 보존.
3. **`"<1"`** — 원전은 `주가 < 주당가치(1년)`이면 `"<1"`. 우리 `below_one`과 **조건이 정확히 같은지 대조**하고 다르면 원전에 맞출 것.

## §2 — `"25+"`일 때의 대체 산출물 (원전 `C33`)
