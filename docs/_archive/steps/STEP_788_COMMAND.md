## 수정

### 1) 파트 구분 헤더 (시간축 카드와 렌즈 목록 사이)

- 구분선 + 제목 **"7가지 방법으로 따로 보기"** / 부제 **"기관이 쓰는 검증된 기법들이 이 종목을 저마다 어떻게 보는지"**.
- en: `Seven methods, one at a time` / `How each proven method reads this stock`(기존 en 톤 정합·새 브랜드 용어 발명 금지).
- 접힘 아님(스크롤로 지나감) · i18n ko/en 패리티.

### 2) 닫는 카드 "7가지 방법을 종합하면" (렌즈 7장 **아래**)

민트 테두리 강조 카드 1개. 내용 전부 **이미 있는 값의 재조립**:

- 카운트: `강점 N · 주의 N · 보통 N`(기존 tone 집계 재사용 — 상단 렌즈 헤더와 **같은 수치여야 함**).
- 분류 줄 2개: `강점 · {렌즈 쉬운이름 나열}` / `주의 · {나열}` — 여기 쓰는 이름은 **`question`이 아니라 짧은 쉬운 라벨**이 필요하므로 `lib/lensCopy.ts`에 `shortLabel` 신설(ko: 오름세·단기 흐름·가격 대비 가치·돈 버는 힘·몸집 관리·가격 출렁임·재무 건전성 / en: Uptrend·Short-term trend·Value·Profitability·Asset discipline·Price swings·Financial health). 보통(flat)은 나열 생략(길이 관리).
- **한 문장 정리(결정론 템플릿·LLM 아님)**: 시간축(horizon)별 tone 분포로 분기하는 템플릿 — 예시:
  - 장기 pos 우세 & 단기 warn 우세 → "길게 보는 기법들은 좋게, 짧게 보는 기법들은 나쁘게 봤습니다. 시간축에 따라 평가가 갈리는 종목입니다."
  - 전 축 pos 우세 → "짧게 보든 길게 보든 대체로 긍정적으로 봤습니다."
  - 전 축 warn 우세 → "짧게 보든 길게 보든 대체로 부정적으로 봤습니다."
  - 혼재/판정 부족 → "기법마다 평가가 갈립니다." / 데이터 부족 시 문장 생략(정직 결측).
  - **분기는 4~6개 이내**로 제한하고 각 문장은 ko/en 패리티. 예측·추천 표현 금지(멍거 톤).
- 푸터: `사실만 정리했습니다 · 판단은 당신`(기존 문법 재사용).
- ETF 뷰 제외.

### 3) 상단 렌즈 헤더와의 중복 정리

- 종목 상단(④A에서 만든 압축 렌즈 헤더: 점7+강점/주의/보통)과 이 닫는 카드가 **같은 카운트를 두 번 말함** → 상단은 "미리보기"(숫자+점), 하단은 "정리"(분류+문장) 역할이므로 **둘 다 유지하되**, 하단 카드에서 점 7개 도트는 반복하지 않음(숫자 + 분류 + 문장만).
