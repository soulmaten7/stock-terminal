## §1 — 🔴 변화줄 렌즈명 중복 (821 §2-6에서 이월)

- **증상**: `Today.lensChangeLine` = `"{lensName} {from} → {to}"` 템플릿인데, **여러 렌즈의 verdict phrase에 이미 주제어가 포함**돼 있다(모멘텀 상위권 · 밸류 중간권 · 변동 중간권 · 수익성 상위권 · 확장 공격적) → 화면에 **"모멘텀 모멘텀 상위권"**, **"밸류 밸류 중간권"**처럼 중복된다.
- **노출 위치**: 오늘 화면 변화 섹션 · 탐색 변화 목록·풀리스트 · 이메일 브리핑 · daily-brief 프롬프트(확인 필요).
- **조치**(택1하고 근거 기재):
  - (a) 템플릿에서 `lensName`을 빼고 **phrase만** 사용 — phrase에 이미 주제어가 있으므로 정보 손실 없음. 다만 주제어가 없는 phrase(예: F-스코어 "재무 건전")가 있는지 **전 렌즈 phrase를 전수 확인**할 것.
  - (b) 중복될 때만 `lensName` 생략(문자열 접두 비교) — 방어적이지만 규칙이 암묵적.
  - 🔑 **(a)를 기본 검토**하되, 전수 확인 결과 주제어 없는 phrase가 있으면 (b) 또는 phrase 보완.
- ko/en 양쪽. `compactPhrase`(819에서 "(시장 대비)" 보존하도록 수정)와 **함께 동작**하는지 확인.

## §2 — 🔴 집계 문구가 결측 사유를 뭉뚱그림 (822 §2-1에서 이월)

- **증상**: 822·825·826에서 개별 카드의 결측 사유를 분기했다(적자 / 우선주 / 매출총이익 미보고 / 1년치만 / 연도 불연속 / 재무 없음). 그런데 **헤더·닫는 카드의 집계 문구는 여전히 "N개는 데이터가 없어 계산하지 못했어요"** 하나로 전부를 묶는다 → **적자 종목이 "데이터가 없다"로 표현**된다(822에서 없앤 거짓이 집계에서 부활).
- **조치**: 집계 문구를 사유가 오도되지 않게 재작성. 🔑 사유를 전부 나열하면 과밀해지므로 **"계산하지 못한 렌즈 N개"처럼 사유를 단정하지 않는 표현**이 현실적일 수 있다 — 택1하고 근거 기재. 카드를 열면 각 사유가 정확히 보이므로 집계는 **중립적**이면 충분하다.
- 대상: 헤더 요약(`naNote`·`pendingNote` 계열) · 788 닫는 카드 · 관심목록·탐색 등 같은 문구를 쓰는 곳 전수.

## §3 — 비로그인 사용자가 카드를 펼치면 판정이 사라짐

- **증상**: 판정 문구·headline 숫자는 `!isOpen`일 때만 렌더되고, 펼치면 **scope(주의사항) + 로그인 벽**만 남는다 → 초보에게 **"눌렀더니 경고문만 나오는"** 경험. 접힘 상태에서 보이던 "모멘텀 상위권 · 12-1 42%"가 사라진다.
- **조치**: 비로그인 펼침 상태에서도 **판정·headline은 유지**하고, 게이트는 **근거 상세(서사·컷·detail)**에만 걸리게. 🔑 810 §1이 "가장 강한 주장은 무료, 그것을 무력화하는 단서는 유료" 비대칭을 없애려 한 것과 **같은 방향**(정보를 빼는 게 아니라 맥락을 함께 보이게).
- 로그인 유도 문구도 "무엇을 더 볼 수 있는지" 정확히.

## §4 — 결측 공통 문구의 사유 단정

- **증상**: "데이터가 부족해 이 방법으론 계산하지 못했어요 **(상장·거래 이력이 짧아서요)**" — 실제로는 거래정지·야후 부분 응답·회계연도 불연속에서도 같은 문구가 나온다(824에서 저변동은 정확했으나 공통 문구 자체는 단정형).
- **조치**: 괄호의 단정을 **조건부**로 바꾸거나 제거. 렌즈별로 정확한 사유가 이미 분기됐으므로(822·825·826) 공통 문구는 **단정하지 않는 편**이 안전하다.
