## §2 — 🔴 종목 페이지 설계 (핵심 화면)

### 2-1. 5분기별 헤드라인 문구 (전부 다르게)

| verdict | 헤드라인 안 | 보조 |
|---|---|---|
| `years` | **"시장은 {N}년의 초과성장을 요구합니다"** | 밴드 · 분포 내 위치 |
| `value_destroying` | **"지금 이익률로는 성장할수록 가치가 줄어듭니다"** | 현재 마진 vs **임계마진** 대비 |
| `below_one` | **"성장이 없다고 봐도 지금 주가가 설명됩니다"** | |
| `over_cap` | **"이 기법으로는 설명되지 않는 가격입니다"** | 100년이 주가의 몇 %를 설명 |
| `skipped` | **사유별** — "상장·분할 후 5년이 지나지 않았습니다" / "이 기법은 은행에 성립하지 않습니다" / "재무 항목이 확보되지 않았습니다" | 🔴 **"데이터 없음" 금지**(822 전례) |

🔴 **각 문구가 초보에게 읽히는지** 자체 점검할 것. 전문용어(GAP·WACC·NOPAT)를 헤드라인에 쓰지 말 것.

### 2-2. 🔴 밴드 표시 방식 (850: 중앙 6년 · p90 50년)

**단일 숫자 금지.** 세 안을 검토하고 **하나를 근거와 함께 채택**:

| 안 | 표시 |
|---|---|
| A | "**14년** (자본비용 ±1%p에서 9~20년)" — 점 + 괄호 |
| B | "**9 ~ 20년**" — 범위만 |
| C | **표**: 자본비용 6.1% → 20년 / 7.1% → 14년 / 8.1% → 9년 |

🔴 **밴드가 극단적으로 넓은 종목(p90급)은 다르게 표시**해야 한다. 규칙을 정할 것(예: 밴드 > X년이면 "자본비용 가정에 매우 민감 — 숫자로 읽지 마십시오").

### 2-3. 반드시 함께 보여줄 것

- **입력 드라이버 전부 공개** (성장률·마진·세율·운전자본율·자본집약도·WACC) — 우리 원칙: 계산 공개
- 🔴 **`growthIsHistorical` 플래그를 문구로**: "성장률은 과거 5년 실적에서 계산했습니다. 애널리스트 전망이 아닙니다."
- **임계마진 vs 현재 마진** (원전 지표)
- 🔴 **기준일**: "세율·자본비용은 {damodaran as_of} 기준"

## §3 — 🔴 분포 내 위치 (우리 차별점)

계산기는 이미 여럿이다(GuruFocus·TIKR·FinChat). **우리 자리는 "전 종목 × 매일 × 분포 내 위치".**

- `years` 195 안에서의 **백분위**를 함께 표시: "14년 — 시장 상위 {x}%"
- 🔴 **표본이 195개**다. 상위 1% = 2종목이라 **1% 컷은 쓰지 않는다.** 3%·5%·10% 등 어느 컷을 쓸지 결정.
- 🔴 **분포 표본 정의를 화면에 밝힌다**: "미국 시총 상위 1,000 중 이 기법이 성립하는 195개 기준"
