### 2. 컷 계산

**대상 지표** — 🔴 **지금 데이터가 실제로 있는 것만.** 없는 지표를 위해 자리를 만들지 말 것.

```
lens 계열 (lens_scores US · 지표별 존재 종목 전체):
  momentum · technical · valuation · lowvol · quality · assetgrowth · fscore
역DCF 계열 (revdcf_results 최신 as_of · 604):
  🔴 어떤 컬럼을 쓸지는 실제 스키마를 열어 확인하고, 값이 있는 것만 대상으로 할 것

방법 (method 컬럼에 문자열로 기록)
  p30/p70 · 섹터 내 · 결측 제외 · n = 그 섹터에서 값이 있는 종목 수
  🔴 방향(고/저 중 어느 쪽이 좋은지)은 이 STEP에서 정하지 않는다 — 컷 값만 낸다

🔴 n < 20 인 (섹터 × 지표) 조합은 행을 만들지 않고 skip 목록에 사유와 함께 기록
```

### 3. 🔑 부트스트랩 안정성 실측 (이 STEP의 핵심)

```
각 (섹터 × 지표)에 대해:
  - 복원추출 재표본 1,000회 (🔴 고정 시드 · 시드값을 리포트에 기록)
  - 매회 p30·p70을 계산
  - 산출: p30의 2.5~97.5 백분위 구간 폭 · p70의 같은 구간 폭
  - 🔑 폭을 「해당 지표의 섹터 내 사분위범위(IQR) 대비 비율」로도 낼 것
        (지표마다 단위가 달라 절대값만으로는 비교가 안 된다)
```

### 4. 실측 리포트 (`scripts/probe_943_sector_cuts.ts` → `docs/probe_943_sector_cuts.json`)

1. **컷 표** — (섹터 × 지표)별 `lo`·`hi`·`n`
2. 🔑 **부트스트랩 흔들림** — 섹터별·지표별 p30/p70 구간 폭 (절대값 ＋ IQR 대비 비율)
3. 🔑 **n과 흔들림의 관계** — n을 가로축으로 흔들림 폭을 정렬한 표. 🔴 **판정 ⓚ의 직접 재료**
4. 🔑 **시장 전체 컷 vs 섹터 컷 차이** — 지표별로, 섹터 컷을 쓰면 **판정이 바뀌는 종목 수**. 🔴 **이것이 결함 ⑤의 실제 크기다**
5. **skip 목록** — n < 20으로 제외된 조합과 사유
6. **Utilities(n=43) 상세** — 가장 작은 섹터라 별도로 뽑을 것
