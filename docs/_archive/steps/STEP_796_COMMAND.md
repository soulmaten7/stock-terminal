## 수정

### 1) 공용 페이지 셸 도입 — 오늘·탐색·관심

- **기준 = 오늘 화면 구조**(`max-w-[1040px]` = 본문 680 + 레일 320 + gap). 이 구조를 **공용 컴포넌트로 추출**(예: `components/layout/PageShell.tsx`):
  - 바깥: `mx-auto max-w-[1040px] py-6 sm:px-6 lg:flex lg:items-start lg:gap-8`
  - 본문 슬롯: `min-w-0 flex-1 lg:max-w-[680px]`
  - 레일 슬롯(옵션): `hidden lg:block lg:w-80 lg:shrink-0` — **레일 콘텐츠가 없으면 렌더하지 않되, 본문 폭·좌측 선은 동일하게 유지**(레일 유무로 본문이 움직이면 안 됨 = 이번 문제의 재발).
- **오늘**: 기존 레이아웃을 이 셸로 교체(렌더 결과 byte 동일 목표 — 현행이 기준이므로 변화 0이어야 함).
- **탐색**: `mx-auto max-w-[680px]`(388·436행 2곳) → 셸 사용. 레일 없음. **결과적으로 좌측 시작이 오늘과 동일**해져야 함.
- **관심**: `max-w-7xl px-4 sm:px-6` → 셸 사용(전폭 → 680 본문). 리스트가 좁아지지만 오늘·탐색과 같은 리듬이 되는 것이 목적.
- 모바일(<lg)에서는 **세 화면 모두 현행 그대로**(풀블리드·`px-0 sm:px-6` 규칙 유지 — 763 결정 불변). 이번 변경은 **lg 이상에서만 체감**돼야 함.

### 2) 종목상세 — 좌측 선만 정합

- 렌즈 카드 PC 2단(789)·공시·브리핑 때문에 폭은 유지(내부 `max-w-4xl`). 다만 **바깥 컨테이너를 셸과 같은 `max-w-[1040px]` 계열로 맞춰** 좌측 시작이 오늘·탐색·관심과 같아지게 할 것(현재 `max-w-7xl`이라 1280px에서 24px에서 시작 — 셸 도입 시 오늘이 몇 px에서 시작하는지 계산해 **동일 좌표**가 되도록).
- 렌즈 카드 2단 레이아웃이 좁아진 폭에서 깨지지 않는지 확인(깨지면 2단 분기점을 조정하되 789 구조 유지).

### 3) `/about` 등 문서형 페이지

- `/about`은 읽기 페이지라 좁은 폭이 관례이나, **좌측 선은 셸과 맞추고**(가운데 정렬 → 셸 본문 슬롯 안에 배치) 폭만 읽기 좋게 유지. `/advertise`·`/terms`·`/privacy`·`/feedback`도 같은 원칙으로 점검(전폭 유지가 나은 곳은 사유 기재 후 유지).

### 4) `/explore` h1 누락

- 5면 중 유일하게 `h1`이 없음(실측 확인). 화면 최상단에 페이지 제목 `h1` 추가 — **시각적으로 크게 넣지 말고**(763 밀도 결정 존중) 검색창 위에 작게 또는 `sr-only`로. 문구는 기존 i18n 재사용(탐색/Explore). ko/en 패리티.
