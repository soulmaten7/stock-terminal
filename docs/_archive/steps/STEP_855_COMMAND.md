## §2 — 백분위 방향 오류

**현상**: GOOGL 12년인데 **"상위 60%"**. 실측하면 12년보다 **짧은 종목이 42%** = 기대치가 낮은 편.
**원인**: `app/api/revdcf/route.ts` — `atOrAbove / total`(자기보다 **긴** 종목 비율)을 "상위 %"로 표시.
**851 목업은 "상위 27%"** 였다 → 목업과 구현 불일치.

🔴 **수정 = "상위 x%" 폐기.** 방향이 헷갈리는 백분위는 없느니만 못하다.

**대체안(권장)**: `years` 222 표본 기준 **3분류 + 순위 병기**
- 하위 1/3 → "**기대가 낮은 편**" · 중간 → "**중간**" · 상위 1/3 → "**기대가 높은 편**"
- 함께: "222개 중 {n}번째로 긴 기간" (방향이 문장에 드러남)
- 🔴 **긴 것이 나쁘다/좋다고 말하지 않는다.** 우리는 추천하지 않는다(BRAND_IDENTITY).
- 표본 정의 문구 유지: "미국 시총 상위 1,000 중 이 기법이 성립하는 222개 기준"

🔴 다른 안이 더 낫다고 판단되면 **근거와 함께 바꿔도 좋다.** 단 **방향이 문장에서 명확할 것.**

## §3 — 밴드를 기본 표시로 승격 (851 설계 뒤집기)

**851 전제**: 대부분 좁은 밴드 · 넓은 것만 예외 처리(폭>10년 → 숫자 감춤 + 3점 표)
**실측**: 밴드 폭 **>10년이 47%** (222 중). 중앙 9년.

🔴 **절반이 "예외"면 규칙이 아니다.** 예외 분기를 없애고 **모든 종목을 같은 형식**으로:

```
시장은 23년의 초과성장을 요구합니다
자본비용 6.4% → 9년 · 7.4% → 23년 · 8.4% → 51년
```
- 폭이 좁든 넓든 **동일 형식**. 종목마다 화면이 달라지지 않는다.
- 🔴 폭이 극단(예: `below_one`↔`over_cap` 가로지름 = DPZ 0~100)일 때만 **한 줄 경고 추가**: "자본비용 가정에 따라 결론이 완전히 달라집니다."
- 🔴 **WACC 실제 수치를 표에 노출**(현재는 "±1%p"라고만 씀). 사용자가 자기 관점을 고르려면 숫자가 있어야 한다.
