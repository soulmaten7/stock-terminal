## 2) 결과 전체 붙여넣어 보고 (순서대로)
1. **종목 N/500 · 유효 리밸런스 N개월** — 데이터 충분?(리밸런스 100개월+면 통계 든든).
2. **롱숏 연율 수익** — 기존 pooled +2.4%와 비교(방법 바뀌어 값 달라질 수 있음).
3. **▶ t값** — 핵심. **|t|>2면 5% 유의**(방향성 근거 격상). t<2면 "이 표본·기간에선 통계적으로 약함" 정직 인정.
4. **▶ 샤프(연율)** — 위험 대비 수익(높을수록 좋음, 팩터는 대개 0.3~0.7대).
5. **양(+)의 달 비율** — 꾸준함(50% 훨씬 넘으면 안정적).

## ✅ 판정 (STEP 527에서 반영 — 알파·비용까지 본 뒤)
