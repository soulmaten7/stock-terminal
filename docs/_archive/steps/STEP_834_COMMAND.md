## §2 — 컷 차이 (프로브 계산·프로덕션 미오염)

**B(거래대금 상위 1,000) 유니버스로 렌즈를 실제 계산**해 5개 렌즈의 p30/p70을 산출하고, 현행 A 기준 컷과 비교한다.

- 🔴 **`lens_scores`·`lens_cuts`에 쓰지 말 것.** 계산 결과는 메모리·임시 파일에서 집계(프로브 산출물은 문서에 수치로만 남긴다).
- 833 실측 소요 141s/300s이므로 별도 실행 1회는 가능. 시간·호출량 초과 위험이 있으면 **표본으로 줄이고 표본임을 명시**(임의로 줄여놓고 전수처럼 쓰지 말 것).
- 산출: 렌즈별 **p30/p70 (A) vs (B)** 표 + **판정이 뒤집히는 종목 수**(A에서 `high`인데 B에서 `mid` 등). 🔑 뒤집히는 종목이 몇 %인지가 "정의 변경의 실제 크기"다.

## §3 — 🔴 Cowork 가설 검증: "거래대금 유니버스는 저변동 렌즈를 왜곡한다"

**가설**: 거래대금은 변동성과 같이 움직이므로(volume–volatility relation), 거래대금 상위로 유니버스를 잡으면 표본이 변동성 높은 종목으로 치우쳐 **저변동 렌즈의 기준선(p30/p70)이 위로 밀린다.**

검증:

1. **문헌**: volume–volatility 관계의 **원문 근거**를 확인하라(원문 서지 확인 · 2차 자료 금지). 성립 조건·반례가 있으면 함께.
2. **우리 데이터**: 거래대금 순위와 실현변동성(우리 `lowvol` 계산값)의 **순위상관(스피어만)** — A·B 각각에서. 표본 수·기간 명시.
3. **분포 직접 비교**: A와 B의 실현변동성 **중앙·p30·p70·최대** 표.
4. 🔴 **반박이면 반박으로 보고.** 상관이 약하거나 방향이 반대면 그 수치를 그대로 쓰고, Cowork 가설이 틀렸다고 적을 것.
5. 🔑 같은 검사를 **모멘텀·밸류**에도 하라(거래대금 편중이 다른 렌즈 기준선도 미는지). 렌즈마다 결론이 다를 수 있다(`LENS_DEV_PLAYBOOK` §0-7: 한 기법에서 통한 결론을 다른 기법에 이식 금지).

## §4 — churn (측정 가능/불가를 정직하게 가른다)

- **저장 데이터로는 불가**: `kr_stock_snapshot`은 `bas_dd`가 8개 날짜지만 총 2,774행 = **단일 스냅샷**(심볼별 최신 1행)이고, `us_stock_perf`도 이력이 없다. `us_market_cap`은 833부터 쌓이기 시작해 현재 1일치. → **"과거 churn은 측정 불가"로 명시**할 것.
- **표본 추정은 가능**: 표본 종목(예: 300종목)의 **일별 거래량·종가**로 최근 N영업일의 일별 거래대금 순위를 만들어, **상위 1,000 경계에서의 일별 편입/제외 비율**을 추정. 표본임을 명시하고 표본 선정 방식(무작위인지 층화인지)을 기재.
- 시총 churn은 표본 추정도 어려우면 **불가로 남기고**, `us_market_cap` 누적으로 며칠 후 측정 가능해진다는 사실만 기록.

## §5 — 문헌: 렌즈 원전들은 어떤 모집단을 썼나 (🔴 원문)

각 렌즈 원전의 **표본 구성(유니버스)**을 원문에서 확인해 표로:

| 렌즈 | 원전 | 표본 범위 | breakpoint 기준 | 마이크로캡·유동성 처리 |

| 모멘텀 | Jegadeesh–Titman 1993 (+ Carhart UMD 사양) | | | |
| 저변동 | Baker–Bradley–Wurgler 2011 | | | |
| 밸류 | Basu 1977 · Fama–French 1992 | | | |
| 퀄리티 | Novy-Marx 2013 | | | |
| 자산성장 | Cooper–Gulen–Schill 2008 | | | |
| F-스코어 | Piotroski 2000 | | | |

확인할 것:

1. 표본을 **시총**으로 제한하는지, **거래대금·회전율**로 제한하는지, 아니면 전 종목에 **NYSE breakpoint**를 쓰는지.
2. 🔑 **거래대금 상위 N을 유니버스로 쓰는 관행이 문헌에 있는지** — 없으면 "없다"고 명시(우리 선택이 문헌 밖이라는 사실 자체가 결정 재료다).
3. 마이크로캡·저유동 종목을 어떻게 다루는지(제외·가중·별도 보고).
4. 🔴 원전이 우리 상황(상위 1,000 제한·일간 리밸런스)과 **다른 점**을 숨기지 말 것.
