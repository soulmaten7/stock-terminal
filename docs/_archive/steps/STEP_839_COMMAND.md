## §1 — 🔴 최우선: 겹침 검산 재실행 (기간 매칭)

### 838의 보고

> "겹침 검산 125쌍 중 **88(70%) 불일치** — MA(**24.98B vs 4.41B**) · ADP는 전혀 다른 개념. `Revenues`와 `Excluding`은 **교환 불가** → 합산 아닌 우선순위 1개. B-0의 '애플 전환기 일치'는 특수 사례였다."

### Cowork 반증 (라이브 실측 2026-07-30)

`https://data.sec.gov/api/xbrl/companyconcept/CIK0001141391/us-gaap/Revenues.json` 직접 조회 결과, **마스터카드 `Revenues`는 2007~2026Q1 연속·완전**하다.

| 기간 | 값 |
|---|---|
| CY2023 **연간** | **$25,098M** |
| CY2024 **연간** | **$28,167M** |
| CY2025 **연간** | **$32,791M** |
| **2019-10-01~2019-12-31 (분기)** | **$4,414M** ← 838이 보고한 "4.41B" |

🔑 **`Revenues` 태그 안에는 연간·반기·분기 값이 전부 섞여 있다.** `start`~`end`를 맞추지 않고 비교하면 **연간 vs 분기**를 비교하게 된다.

### 지시

1. **838의 겹침 검산 코드를 열어 기간 매칭 로직을 확인**하라. 두 태그의 값을 짝지을 때 무엇을 키로 썼는가.
2. **기간을 고정해 재실행**한다. 권장 기준:
   - SEC가 붙여주는 **`frame` 필드**를 쓴다. `CY####`(연간) / `CY####Q#`(분기) / `CY####Q#I`(시점).
   - 🔴 **`frame`이 `CY####` 형태인 것만 연간으로 취급**하고, 연간끼리만 비교.
   - `frame`이 없는 항목(정정본·비표준 기간)은 **제외하고 그 수를 보고**.
3. **재실행 결과를 838과 나란히 보고**:

| | 838 (기간 미고정) | 839 (frame 고정) |
|---|---|---|
| 비교 쌍 수 | 125 | ? |
| 불일치 수 | 88 (70%) | ? |
| 불일치 사례 | MA · ADP | ? |

4. 🔴 **MA·ADP를 개별 재검증**하라. 두 태그의 **같은 `frame` 값**을 나란히 놓고 실제로 다른지 확인. 다르면 **얼마나·왜** 다른지(총매출 vs 순매출 등) 규명.
5. **판정**: 기간 매칭 오류였는가, 진짜 개념 차이인가. 🔴 **둘 다 섞여 있으면 사례별로 분류**하라.

## §2 — 태그 전략 확정 (§1 판정 후에만)

§1 결과에 따라 갈린다. **둘 중 하나를 근거와 함께 확정**하라.

- **(a) 기간 매칭 오류였다** → 태그 **합산/이어붙이기 가능**. 우선순위 목록 + 겹침 구간 검산 규칙으로 진행. 커버리지 재산출.
- **(b) 진짜 개념 차이가 있다** → **우선순위 1개만** 사용. 어느 태그를 1순위로 할지와 **그 선택이 종목별 값의 의미를 바꾸는지** 명시.
- **(c) 혼재** → **판별 규칙**을 만든다(예: 같은 frame에서 값 차이가 임계 이상이면 다른 개념으로 보고 우선순위 적용).

🔴 어느 쪽이든 **어느 연도에 어느 태그를 썼는지 데이터에 기록**한다(`REVDCF_SPEC.md` §5의 규칙 — 809 `peBasis` 전례).

## §3 — 🔴 "6 driver 5년 연속 70.3%"의 병목 분해

838은 **6개 driver 전부** 5년 연속 확보가 **70.3%**(623종목 기준 ≈ 438종목)라고 보고했다. **어느 driver가 깎는지는 모른다.**

1. **driver별 단독 5년 연속 확보율**을 각각 산출(6개).
2. **누적 교집합**을 순서대로: driver 1만 → 1∩2 → 1∩2∩3 → … **어디서 급락하는지** 찾는다.
3. 🔑 **병목 driver를 1~2개 고치면 70.3%가 얼마까지 오르는지** 시뮬레이션(예: `OperatingIncomeLoss` 폴백 적용 시, `InterestExpense` 두 태그 합집합 적용 시).
4. §1이 (a)로 판정되면 **매출 태그 합산 적용 후** 수치도 함께.
