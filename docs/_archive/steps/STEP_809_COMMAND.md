## 수정

### 1) 🔴 "PER은 직전 연간 실적 기준" — 거짓 (Cowork 지시 오류)

- STEP 805 §5에서 이 문구를 넣도록 지시했으나, `lib/lensCompute.ts`는 야후 `quote.trailingPE`(= **TTM**)를 1순위로 쓰고 연간 계산은 폴백이다. **없던 거짓말을 만든 것.**
- 조치: **실제로 무엇을 썼는지 데이터에 표시**(`peBasis: 'ttm' | 'annual'`)하고, 화면 문구를 그 값에 따라 분기("최근 4분기 실적(TTM) 기준" / "직전 연간 실적 기준"). ko/en.
- ⚠️ **부수 문제 확인·보고**: 같은 KR 유니버스 안에 TTM PER과 연간 PER이 섞인 채 p30/p70 컷과 백분위가 계산되고 있다. 섞인 비율을 실측해 보고할 것(수정은 이번 스코프 아님 — 판단 후 별도 STEP).

### 2) 🔴 KR 카드에 "시총 상위 1,000 중" — 거짓

- `StockLens.gauge.rank` 문자열이 **시장 무관 하드코딩**인데 KR 유니버스는 **거래대금 상위 1,000**이다. 게다가 같은 카드 근거줄엔 "거래대금 상위권 내 백분위"가 있어 **한 카드 안에 모집단 설명이 두 개·서로 모순**.
- 조치: 807에서 만든 시장별 라벨 분기를 게이지 문구에도 적용하고, **카드 안에서 모집단 표현을 하나로 통일**.

### 3) 🔴 시간축이 "중기 강세"라고 말함 — 거짓 (806/808 누락)

- 806·808에서 모멘텀을 상대 표현으로 바꾸며 `SPECTRUM_LABELS`·`LEVEL_LABELS.momrank`는 고쳤는데 **`HorizonStrip`만 누락**. 12-1이 −15%여도 시장 상위권이면 카드는 "내렸지만 상위권", 같은 페이지 시간축은 **"중기 강세"**.
- 조치: 시간축 단어(`word.bull`/`word.bear`)를 상대 표현으로 정합. 다른 축(단기=기술·장기=재무)도 같은 기준으로 점검.
- 함께: `horizon.summary`("시간축마다 결이 달라요")가 **세 축이 동일해도 무조건 출력**된다 → 실제로 갈릴 때만 출력.

### 4) 🔴 DART 조회 실패가 "중대한 사건은 없어요"로 표시 — 거짓 (797 미완)

- 797이 `/api/kr-events` 라우트에 3상태를 넣었으나, 그 안쪽 **`lib/dartEvents.ts`의 `fetchDartMaterial`이 예외를 먼저 삼키고 `[]`를 반환**한다(HTTP 오류·status≠000·키 없음·corp_code null 전부). 라우트의 `fetch_failed` 분기에 **도달조차 못 함**.
- 조치: `fetchDartMaterial`이 실패를 **구분 가능한 형태로 반환**(예외 전파 또는 `{ok:false, reason}`)하도록 고치고, 라우트의 3상태가 실제로 작동하는지 확인.
- 함께: 빈 상태 문구 **"정기 공시만 있어요"는 삭제**(조회조차 못 한 상태에서 덧붙인 미확인 사실). 그리고 `MATERIAL_KW`에 정기보고서(분기·반기·사업보고서)가 포함돼 있어 **"중대 공시" 목록에 정기 공시가 나열되면서 빈 문구는 "정기 공시만"이라 말하는 모순**도 정리.

### 5) 🔴 `/about`이 "6개 시장" — 거짓 (799 누락)

- 799에서 활성 시장을 KR·US로 좁혔는데 소개 페이지는 "한국·미국·일본·중국·베트남·영국 — 6개 시장" 그대로. 상세 페이지의 "방법이 궁금하면 소개 →"가 이 페이지로 보낸다.
- 조치: `ACTIVE_MARKETS` 기준으로 문구 정정(하드코딩 금지 — 상수에서 파생). ko/en.

### 6) 잔여 "실패를 없음으로" 3곳

- **오늘 화면 시장 변화**: `lib/todayChanges.ts`가 DB 오류 시 Sentry만 남기고 `{count:0, items:[]}` → 화면은 **"오늘은 렌즈 상태 변화가 없어요"**로 단정. 같은 페이지 관심 섹션은 이미 구분하고 있음 → **동일 문법 적용**.
- **최근 뉴스**: `StockNewsBrief`가 `!j.summary`면 `hide` — 429·502까지 조용히 사라짐. 바로 위 `StockBrief`는 797에서 구분했으므로 **같은 처리**.
- **판정 불가가 빈 카드로**: 가격 계열 부족(모멘텀 252봉·저변동 120봉 미만)이면 `verdict`·`headline`·서사가 전부 null이라 **제목과 배지만 남고 본문이 빔**. `naNote` 카운트에도 안 잡힘 → **명시적 결측 표시**(기존 `LensPreview.insufficient` 문구가 이미 있으나 상세에서 미사용).
- 함께: 재무 데이터가 아예 없어 **퀄리티·자산성장 카드 2장이 배열에서 제거**되는 것도 "N개는 데이터가 없어 계산하지 못했어요"에 포함되게(현재는 조용히 사라져 "5가지 방법으로"가 됨).

### 7) 작은 정직성 2건

- **한 입 브리핑에 날짜 표기 없음**: `getLatestDailyBrief`가 날짜 조건 없이 최신 1행 → 크론이 며칠 실패해도 오늘 H1 아래에 옛 브리핑이 날짜 없이 붙는다. 다른 섹션은 전부 `AsOfBadge`가 있으므로 **같은 배지 적용**.
