①소스 층 — 무엇을 담당하는가

층내용담당
1. 정해진 소스시세, SEC/DART 공시 원문, 재무제표사실이 정확해야 하는 것 — 변하는 값(주가·매출·CEO)
2. 웹 검색뉴스, 시장 반응, 맥락지금 무슨 일이 있는지
3. LLM 지식설명·해석(PER이 뭔지, 지주회사를 PER로 보면 안 되는 이유 등)변하지 않는 지식

원칙: 변하는 값은 데이터에서, 변하지 않는 지식은 LLM에서. 사실 주장은 반드시 출처가 있어야 한다.

미정이 구상에서 아직 정하지 않은 것

  • 루프(④~⑤ 반복) 최대 횟수와 멈추는 조건
  • 요금제 구체안(단계·횟수 제한·금액) — 모델 등급뿐 아니라 루프 횟수(=참조 출처 수)로도 등급을 나누는 안 검토 중. 참고: 퍼플렉시티는 무료 5~8개 출처·Pro 15~25개 출처로 깊이를 나눈다
  • 무료와 유료의 경계
  • 나라별 소스 목록 확보(무료 데이터, API·크롤링 가능 여부, 상업적 이용 약관)
  • 웹 검색 API·시세 API 원가
  • 답변이 다루는 범위의 선 — 개인 맞춤 조언은 하지 않음(규제 회피). 사실·데이터·엇갈리는 시각까지만 다루는 것으로 검토 중이나 경계선 자체는 미확정
  • 기존 EarthTicker 아카이브를 언제 어떻게 걷어낼지
