# Trillion 로고 생성 프롬프트 (Claude SVG 디자인용)

> 사용법: **Claude 새 대화**에 아래 "📋 복붙 프롬프트" 전체를 붙여넣어. 시안 여러 개 받고 마음에 드는 걸 고른 뒤, 그 SVG를 다시 가져오면 사이트(파비콘·헤더·앱아이콘)에 내가 적용해줄게.

---

## 📋 복붙 프롬프트 (이거 전체 복사)

```
너는 핀테크 브랜드 전문 로고 디자이너야. 아래 브랜드의 로고를 **확장 가능한 SVG 벡터**로 디자인해줘.
한 번에 컨셉 3안을 그려주고, 각 안마다 ① 심볼(정사각 아이콘) ② 심볼+워드마크(가로 조합) 두 형태를 보여줘. 각 안에 30자 이내 컨셉 설명을 붙여.

[브랜드]
- 이름: Trillion (트릴리언). 법인명 원트릴리언.
- 한 줄 정체성: "종목을 보는 눈을, 누구에게나" — 기관급 분석(TR-AI 렌즈)을 개인 손에, 1차 재료를 정직하게 보여주는 곳(`docs/BRAND_IDENTITY.md`). ※ 로고의 **시각 모티프**는 "흩어진 → 하나로 수렴/명료"(§8 T 모노그램)로 유지 — 아래 컨셉 방향의 '수렴/허브'는 그대로 쓴다.
- 톤: 신뢰·중립·프리미엄. 블룸버그 터미널의 진중함 + 토스의 깔끔함. 과장·현란함 금지.
- 타깃: 한국 개인투자자. 🔴 **2026-08-15(STEP1039) 정정 — 2026-08-08 US 단독 규칙 이전 문구.** 로고 재작업 시 US 개인투자자 기준으로 다시 확인할 것(시각 모티프·톤 자체는 시장 무관이라 무효화되지 않음).

[컨셉 방향 — 이 중 강한 것 위주로, 3안을 서로 다르게]
1. 수렴/허브: 사방에 흩어진 점·선이 하나의 또렷한 초점으로 모이는 형태("흩어진 → 한눈에").
2. T 모노그램: 기하학적이고 단단한 'T'에 수렴/레이어 개념을 녹임.
3. 초점/렌즈: 하나의 또렷한 포컬 포인트(점·원·렌즈)로 "명료함·한눈에"를 상징.
※ 핵심 의미는 "거대한 스케일"보다 **"흩어진 것을 한곳에 모아 명료하게"**.

[스타일]
- 미니멀·기하학적·플랫(그라데이션 없음/최소), 모던 핀테크.
- 그리드 기반 정밀 도형. 앱 아이콘 32px로 줄여도 또렷해야 함.
- 절제된 라운드. 군더더기 없는 형태.

[컬러 — 정확히 이 값]
- 미드나잇 #0E1116 (배경/주색)
- 민트 #2DD4BF (강조)
- 보조 무채색만 허용, 그 외 색 자제.
- 기본은 '미드나잇 배경 + 민트 심볼'. 라이트 버전(흰 배경)과 단색(검정/흰색) 버전도 1개씩.

[타이포 — 워드마크]
- "Trillion": 산세리프, 기하학적·중량감 있는 모던 Bold(Inter/Pretendard 계열 느낌), 자간 살짝 좁게.
- 심볼 모티프를 'T' 또는 'i'의 점에 살짝 연결해도 좋음(과하지 않게).
- "트릴리언"은 작은 보조 표기로 옵션.

[산출물]
- SVG 벡터, 배경 투명.
- 정사각 심볼(앱아이콘) + 가로 조합(심볼+Trillion) + 단색 1버전.
- 32px와 512px 양쪽에서 또렷하게.

[피해야 할 것]
- 흔한 금융 클리셰: 상승 화살표, 촛대(캔들)차트, 달러/원 기호, 지구본, 방패, 황소/곰.
- 과한 그라데이션·드롭섀도·3D·글로우·네온.
- 의미 없는 추상 곡선 남발, 스톡 아이콘 느낌.

먼저 3안을 SVG로 그려줘. 내가 하나 고르면 그 안을 다듬자.
```

## 🎨 참고 (왜 이렇게 잡았나)
- **정체성 핵심 = "흩어진 → 한눈에"** 라서 *수렴/집약/초점* 메타포를 1순위로 줬어. trillion의 '큰 숫자'를 직역(∞·12자리 등)하면 의미가 약해져서 배제.
- **컬러는 현재 사이트와 동일**(미드나잇 #0E1116 + 민트 #2DD4BF) — 로고가 헤더·파비콘에 그대로 녹아들게.
- **앱아이콘 32px 또렷함**을 명시 — 플레이스토어·앱스토어 등록 대비(아이콘이 작아도 살아야 함).
- **클리셰 금지 목록**으로 흔한 금융 로고(화살표·캔들·$) 탈피 → 차별화.
