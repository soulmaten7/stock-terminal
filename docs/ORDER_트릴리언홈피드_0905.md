# ORDER — Trillion AI요약 제거 + 홈 리포트 피드 (2026-09-05)

리포트 적재 배관이 완성돼 실제 데이터가 흐르기 시작했다(채널 →
channel_reports → 종목 페이지 렌더 확인됨). 이제 사이트에 남은 모델
시대 화면 두 곳을 리포트 기준으로 정리한다.

**디자인은 여전히 최소.** 리브랜딩(브랜드명·디자인·도메인 전면 교체)은
이후 별도이며, 이번엔 구조·데이터 교체만 한다.

## STEP 1 — 종목 페이지: 공시의 AI 요약 제거

현재 종목 페이지 "최근 중대 공시" 항목을 펼치면 「AI 요약」 블록이
나온다. 이를 제거한다.

- **제거**: AI 요약 블록(LLM 생성 요약문). 근거: 이 플랫폼은 검증된
  사실만 전달한다는 원칙이고, 검증된 증권사 리포트 바로 아래에 AI 생성
  요약이 나란히 놓이면 시청자가 같은 신뢰 수준으로 읽는다.
- **유지**: 공시 목록 자체(제목·날짜·DART 원문 링크). 원자료라 가치가
  있고, 링크로 원문에 보내면 우리가 해석을 얹지 않는다.
- 요약을 생성하던 API 라우트는 이번에 삭제하지 말고 **화면 호출만**
  끊는다(라우트 정리는 크론·API 정리 STEP에서).
- 요약 제거로 미사용이 되는 i18n 키·헬퍼가 있으면 같이 정리.

## STEP 2 — 홈: 렌즈 상태 변화 → 리포트 피드

홈의 "간밤 미국 / 한국 · 상태가 바뀐 종목" 두 섹션이 아직 모델(렌즈
상태 변화) 데이터를 보여준다. 이를 **리포트 피드**로 교체한다.

- **섹션 구조는 유지**(국가별 2섹션). 내용만 교체:

  | 섹션 | 한국어 화면 | 영어 화면 | 데이터 |
  |---|---|---|---|
  | KR | 오늘의 증권사 리포트 | Today's Broker Reports | channel_reports where country='KR' |
  | US | 오늘의 실적 가이던스 | Today's Earnings Guidance | channel_reports where country='US' |

- 정렬: report_date DESC(최신 위). 각 섹션 최근 N건(기존 홈이 5건씩
  보여주던 관례 따르기) + "더 보기" 링크.
- 카드에 보일 것(요약 수준): 종목명 · 증권사 · 판정(상향/유지/하향) ·
  목표주가. 상세(reasons·earningsSummary)는 종목 페이지에서.
- 카드 클릭 → 해당 종목 페이지(`/stock/{symbol}`)로. symbol이 NULL인
  미매칭 리포트는 홈에도 노출하지 않는다(클릭할 곳이 없으므로).
- **US 섹션은 지금 데이터가 0건이다**(US 적재는 아직 안 붙임) — 빈
  상태 문구("아직 없어요" 수준)로 두고, 섹션 자체는 만들어둔다. US
  어댑터가 붙으면 자동으로 채워지게.
- 기존 렌즈 상태 변화 조회·컴포넌트는 홈에서 **호출을 끊는다**. 관련
  크론·테이블은 이번에 건드리지 않는다(다음 STEP).
- i18n: 위 표의 4개 문구를 ko/en 양쪽에 추가(패리티 유지).

## 검증
- 홈에서 KR 섹션에 실제 적재된 리포트(팬오션 028670 · DB손해보험
  005830)가 뜨는지 확인. 카드 클릭 시 종목 페이지로 이동하는지.
- 언어 토글(ko↔en)에서 섹션 제목이 각각 맞게 나오는지.
- 라이브 홈·종목 페이지가 에러 없이 뜨는지(200).
