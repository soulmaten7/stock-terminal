# 무료 데이터 프로브 — 새 렌즈 후보 실현 가능성 (KR 우선 · 2026-07)

> **목적**: 우리 7렌즈에 없는 가족(정보 반응·수급/센티먼트·단기 시계)의 렌즈 후보를 **무료 데이터로 실제 채울 수 있는지만** 실측. **코드 미변경 · 렌즈 추가 여부는 장은태 결정.**
> **표본**: KR 상위 1,000(거래대금)에서 상위 30 + 무작위 70 = 100(A) / 상위 40(C·D) / 상위 5(E). 실측일 2026-07-28.
> 4기준(장은태): ① 계산법 공개 ② 무료 데이터로 입력 전부 ③ 결측률 낮음 ④ 우리가 검증 가능.

## 실측 근거(수치)

- **A**: `yf.quoteSummary(sym,{modules:['earningsTrend','recommendationTrend']})` KR 100표본 → `epsTrend`(7/30/60/90일 전 추정치) **55개**에서 유효, `recommendationTrend` 54개. 애널리스트 수 중앙값 2(US 대조 AAPL 31·MSFT 30·NVDA 40). 대형주(삼성·하이닉스·NAVER)는 채워지나 중소형(예 SK이터닉스)은 빔 → **결측이 크기에 상관**(대형주 편중).
- **B**: 클린 OpenAPI(`data-dbg.krx.co.kr/svc/apis`)에서 투자자별·공매도 후보 경로 전부 **404**(`stk_bydd_trd`만 200·943행). `data.krx.co.kr/comm/bldAttendant/getJsonData.cmd`는 세션 쿠키를 붙여도 **`LOGOUT` 400**(OTP 토큰 요구 추정). → 무료 클린 경로로는 미확보.
- **C**: `opendart.fss.or.kr/api/elestock.json` → 상위 40 중 **38 성공**(status 000). 필드 = `repror`(보고자)·`isu_exctv_ofcps`(직위)·`isu_main_shrholdr`(주요주주 여부)·`sp_stock_lmp_cnt`(소유주식수)·`sp_stock_lmp_irds_cnt`(증감). → **내부자 순매수/순매도 집계 가능**.
- **D-1**: `fundamentalsTimeSeries(sym.KS, annual)` 최신행에서 `operatingCashFlow`·`netIncome`·`totalAssets` 세 필드 **38/40** 동시 존재 → 발생액 = (순이익−영업현금흐름)/총자산 계산 가능.
- **E**: `list.json?pblntf_ty=A`(정기공시)로 분기·반기·사업보고서 **접수일** 확보(예 2026-05-15 분기보고서). 발표일 이벤트 타이밍은 되나 '서프라이즈' 크기는 A의 추정치 커버리지(55%)에 묶임.

## 통과 후보 → 렌즈 스펙(810 §1 형식 · 미리 작성 · 착수 시 그대로 사용)

### ✅ 후보 1 — 내부자 순매수 (Insider Trading · Lakonishok-Lee 2001)
- **검증 범위**: 라코니쇽·리(2001)가 미국에서 임원·내부자의 순매수가 이후 완만한 초과수익과 연관됨을 보였어요(특히 소형주). 집단 비교·저빈도 신호예요.
- **알려진 한계·실패 모드**: 효과가 약하고 느려요(수개월). 대량 거래 1건이 집계를 흔들 수 있고, 매도는 분산·세금 등 비정보적 이유가 많아 매수보다 신호가 약해요.
- **적용 조건**: 최근 3~6개월 순매수/순매도를 종목별로 집계, 시장 내 상대 비교. (입력 = DART elestock)

### ✅ 후보 2 — 발생액 (Accruals · Sloan 1996)
- **검증 범위**: 슬론(1996)이 이익 중 '현금으로 뒷받침되지 않은 발생액'이 큰 기업일수록 이후 수익이 약했음을 보였어요(발생액 이례). 집단 비교예요.
- **알려진 한계·실패 모드**: 개별 종목 예측이 아니에요. 회계 방식·업종 차이에 민감하고, 최근 연구는 프리미엄 축소를 보고해요.
- **적용 조건**: (순이익−영업현금흐름)/총자산, 낮을수록 우호. 연 1회 재무 갱신. (입력 = 야후 재무 · 이미 보유)

### ✅ 후보 3 — 52주 신고가 근접도 (52-Week High · George-Hwang 2004)
- **검증 범위**: 조지·황(2004)이 '현재가/52주 최고가'가 높은 종목이 이후 우위였고, **일반 모멘텀보다 모멘텀 크래시를 덜 겪었음**을 보였어요 — 우리 모멘텀의 약점 보완.
- **알려진 한계·실패 모드**: 모멘텀 가족이라 급반등장에선 함께 약해질 수 있어요. 신고가 자체가 상단 저항이 되기도 해요.
- **적용 조건**: 현재가 ÷ 52주 최고가, 높을수록 우호. 가격만으로 계산. (입력 = 가격 · 이미 보유)

### ✅ 후보 4 — 단기 반전 (Short-term Reversal · Jegadeesh 1990 / Lehmann 1990)
- **검증 범위**: 최근 1개월 과하게 오른 종목이 다음 달 되돌리는 경향(단기 반전) — 우리 12-1 모멘텀이 '최근 1개월을 빼는' 바로 그 이유예요.
- **알려진 한계·실패 모드**: 회전율이 높아 거래비용에 취약하고, 유동성 낮은 종목에서 왜곡돼요(우리 무거래 라이브엔 부적합할 수 있음).
- **적용 조건**: 최근 1개월 수익률, 낮을(많이 내린)수록 단기 반등 후보. (입력 = 가격 · 이미 보유)

## 통과 못 함 → 실패 원장(요약 · 상세 = `LOCALE_SOURCE_PLAYBOOK` §8)

- **B. KRX 수급·공매도**: 무료 클린 OpenAPI에 엔드포인트 부재(404), data.krx.co.kr 일반 JSON은 OTP/세션 요구(LOGOUT) → **무료 클린 경로 미확보**. (대안 = OTP 토큰 스크래핑이나 유료/증권사 API — 이번 기준 밖.)
- **A. 추정치 수정 / E. 서프라이즈**: 야후로 오긴 하나 KR 커버리지 55%·애널리스트 중앙값 2 → **중소형주 반쪽**이라 "대형주 전용 렌즈"가 됨(기준 3 걸림). 대형주 한정 파일럿은 가능하나 전 유니버스 렌즈로는 부적합.
