## §1 — 🔴 먼저: 자본집약도 기본값 재검토

852 결정 = `default level` · marginal 병기. **그러나 증거가 반대를 가리킨다.**

| | 값 | 원전 T8 = **15%** |
|---|---|---|
| level (현 기본값) | **6.9%** | 🔴 절반 이하 |
| marginal (원전 정의) | **14%** | ✅ 근접 |

**규칙 ⓪-2**: *"원전이 기준선 · 안 되는 것만 대체 + 사유"*. marginal은 **409종목에서 된다.**

🔴 **아래 안을 검토하고 결정 + 사유 기록**:

| 안 | 기본값 |
|---|---|
| A (852 현행) | `level` 항상 · marginal 병기 |
| ✅ **B (권장 검토)** | **`marginal` 기본 · 산출 불가(195종목)만 `level` 폴백** · 갈리면 병기 |

**판단 재료로 실측할 것**
1. B로 바꿨을 때 **verdict 분포 변화**(특히 `value_destroying` 149가 몇으로).
2. 🔴 **M&A 럼피니스 실측** — 5년 누적 marginal에서 인수가 차지하는 비중 분포. 럼피니스가 실제로 문제인지 숫자로.
3. 852의 "부호가 업종별로 갈린다"(자산경량 +100%p / 자산중형 −95%p)를 **어느 방식이 원전 정의에 부합하는지**와 분리해 판단할 것. **편향의 존재가 원전 이탈의 근거는 아니다.**

🔴 **어느 쪽이든 방법론 페이지에 트레이드오프와 도미노 대조값(15% / 14% / 6.9%)을 그대로 공개한다.**

## §2 — 종목 페이지

`app/[locale]/stock/[symbol]` 에 **역DCF 섹션 추가**. 기존 TR-AI 렌즈 헤더·카드 아래.

### 2-1. 5분기 헤드라인 (851 설계 · `RevDcf` messages 사용)

| verdict | 헤드라인 |
|---|---|
| `years` | "시장은 **{N}년**의 초과성장을 요구합니다" |
| `value_destroying` | "지금 이익률로는 **성장할수록 가치가 줄어듭니다**" |
| `below_one` | "**성장이 없다고 봐도** 지금 주가가 설명됩니다" |
| `over_cap` | "이 기법으로는 **설명되지 않는 가격**입니다" |
| `skipped` | 🔴 **사유별 4종** — `INSUFFICIENT_HISTORY` / `MISSING_TAG` / `NOT_APPLICABLE_SECTOR` / `NO_INDUSTRY`. **"데이터 없음" 금지** |

### 2-2. 밴드 (851 채택 = 안 A)
- 기본: "**14년** (자본비용 ±1%p에서 10~15년)"
- 🔴 **극단 규칙**: 밴드 >10년 **또는** `below_one`↔`over_cap`을 가로지르면 **점 숫자를 감추고** "자본비용 가정에 극도로 민감 — 숫자로 읽지 마십시오" + **3점 표**.

### 2-3. 🔴 method-dependent 표시 (852 신규)
두 방식 판정이 갈리는 **68종목**: "투자 강도 산정 방법에 따라 판정이 달라집니다" + 두 결과 병기.
- `value_destroying` 중 **두 방식 일치 105건만** 확신 문구. **이탈 16건은 반드시 병기.**

### 2-4. 함께 보여줄 것 (우리 원칙 = 계산 공개)
- **드라이버 전부**: 성장률·마진·세율·운전자본율·자본집약도·WACC
- 🔴 `growthIsHistorical`: "성장률은 **과거 5년 실적**에서 계산했습니다. 애널리스트 전망이 아닙니다."
- **임계마진 vs 현재 마진**
- 🔴 **기준일**: "세율·자본비용은 {damodaran as_of} 기준"
- **분포 내 위치**: "시장 상위 {x}%" — 🔴 **5% 단위**(1% 컷 금지) + 표본 정의 "미국 시총 상위 1,000 중 이 기법이 성립하는 {n}개 기준"
