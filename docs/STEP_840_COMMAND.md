## §1 — 🔴 본체: 매출 태그를 순서가 아니라 **일관성**으로 고른다

### 문제 (839 §1·§10-12에서 확인된 것)

839가 정한 우선순위 `Excluding → Revenues → Including → SalesRevenueNet`은 **MA에서 틀린 태그를 1순위로 고른다.**

**실측**: 마스터카드 CY2019 — `Revenues` **$16,883M(net·리베이트 차감)** vs `Excluding` **$24.98B(gross)**. 마스터카드 손익계산서는 **net에서 시작해 영업이익을 뺀다.**

```
영업이익 ÷ gross매출  →  마진이 통째로 왜곡
```

🔴 **핵심**: 이건 회사 간 비교 문제가 아니다. **한 회사 안에서 분자(영업이익)와 분모(매출)가 다른 손익계산서에서 오는 문제**다. 그러면 그 종목의 **현금흐름 경로 자체가 틀린다.**

### 지시 — 항등식으로 판별

각 종목·각 연도에서, **영업이익과 같은 손익계산서에서 온 매출 태그**를 고른다.

**검산 체인(순서대로 시도)**

| # | 항등식 | 필요 태그 |
|---|---|---|
| 1 | `매출 − 매출원가 = GrossProfit` | `GrossProfit` · `CostOfRevenue`(변형 포함) |
| 2 | `매출 − 총비용 = 영업이익` | `CostsAndExpenses` · `OperatingIncomeLoss` |
| 3 | 둘 다 불가 | **판별 불가로 기록** |

1. 매출 후보 태그를 **전부** 가져와 각각 위 항등식에 넣고, **성립하는 것**을 선택. 허용 오차를 명시(부동소수·반올림 고려).
2. **여러 개가 성립하거나 하나도 성립하지 않으면** 그 사실을 기록하고 기본 우선순위로 폴백 + **표시 플래그**.
3. 🔴 **선택 결과를 데이터에 남긴다**:
   - `revenueTag` — 실제 사용한 태그
   - `revenueBasis` — `gross` / `net` / `unverified`
   - `revenueCheck` — 어느 항등식으로 검증했는지(1·2·불가)
   - (809 `peBasis` 전례 — 플래그가 없어 화면이 거짓을 말했던 함정)
4. **`CostOfRevenue`·`CostsAndExpenses`도 태그 변형이 있을 수 있다.** 우선순위 나열 금지 — **데이터에서 발견**하고 커버리지 실측.

## §2 — `InterestExpense` 목적지 태그 규명 (839 못 잰 것)

839: 절벽 확인(CY2023 390 → CY2024 149) · `Nonoperating` 가설 **반박**(18개뿐) · 3태그 union도 456→201만 복구. **어디로 갔는지 미규명.**

**지시**: 가설을 세우지 말고 **데이터에서 찾아라.**

1. **CY2023에 `InterestExpense`가 있고 CY2024에 없는 종목**을 특정(≈189개).
2. 그 종목들의 **CY2024 companyfacts 전체 태그 목록**을 훑어 **이자 관련 태그를 빈도순 집계**(`Interest*` 패턴 전수).
3. 상위 후보의 커버리지 + **CY2023 값과의 연속성 검산**(이동이면 값이 이어져야 함).
4. 🔴 **이동이 아니라 소멸일 가능성도 검토**(무차입 기업 증가 등). 그 경우 그렇게 보고.
5. WACC 부채비용 산출에 **이자비용이 꼭 필요한지** 재검토 — 대안(다모다란 합성등급: 이자보상배율 → 신용등급 → 스프레드)이 있고 그건 **이자비용이 있어야 계산되므로 순환**이다. **총부채 + 공개 스프레드만으로 가능한지** 판단.

## §3 — `OperatingIncomeLoss` 폴백 확정

839: 단독 80.9%가 최대 낙폭 지점 · `GrossProfit` union → **90.1%** · 나머지 ~10%는 "Pretax+Interest 재구성" 제안.

**지시**:
1. `GrossProfit` 폴백이 **영업이익의 대체로 타당한지** 검증. 🔴 GrossProfit은 판관비 차감 **전**이라 영업이익이 아니다 — **그대로 쓰면 마진이 과대**된다. 어떻게 쓸 것인지(판관비를 빼서 재구성? 아니면 다른 태그?) **명확히** 하고 근거 기재.
2. "Pretax+Interest 재구성"(≈ EBIT 근사)의 **실제 커버리지와 오차**를 실측 — 재구성값 vs 실제 `OperatingIncomeLoss`가 둘 다 있는 종목에서 **오차 분포**를 낸다.
3. 재구성을 쓴 종목은 **플래그로 기록**하고 화면에 표시.
