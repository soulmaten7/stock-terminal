# 클로즈드 베타 — 초대 메시지 & 배포 플랫폼

> 목적: 소수(10~30명)에게 조용히 링크를 보내 **실사용 + 솔직한 피드백** 수집. 공개 출시(2차) 전 단계.
> 원칙: **공개 스팸 아님.** 아는 사람 · 작은 신뢰 그룹부터. 양보다 질.

한번 써봐줄래? → onetrillion.app

## 2. 어디에 올릴까 — 플랫폼 정리

### Tier 1 — 클로즈드 베타에 가장 적합 (지인·소수·신뢰) ← 여기부터

- **카카오톡 1:1 / 단톡방** — 실제로 주식하는 지인. 최우선. 반응률·피드백 질이 제일 높음.
- **내가 이미 속한 주식 오픈채팅방** — 방장·분위기 봐서 조심히. (새로 들어가 링크만 던지면 광고 취급)
- **네이버 밴드·소규모 투자 모임** — 내가 활동 중인 곳.

### Tier 2 — 조심스럽게 (가치 먼저 · 규칙 확인 · 스팸 금지)

- **주식 커뮤니티 게시판**: 에펨코리아(주식·재테크), 클리앙(재테크), 뽐뿌(증권), 디시 주식 갤러리 등. "만들었는데 피드백 구합니다" 톤으로. 자기홍보 금지 규칙이 많으니 **게시판 규칙을 먼저 확인**. 링크만 던지면 역효과(유사투자자문 얘기라 리딩방 홍보로 오해받기 쉬움).

### Tier 3 — 2차(공개 출시)용, 지금은 아직

- 인스타·스레드·X(트위터) 공개 게시 / 블로그·유튜브 / 오픈채팅 신규 개설.

## 3. 주의 & 팁

- **양보다 질** — 10명이 솔직히 써보고 피드백 주는 게, 링크 100번 뿌리는 것보다 낫습니다.
- 우리는 리딩방 '홍보'가 아니라 '정보 도구'인데 커뮤니티에선 오해받기 쉬워요 → 초기엔 **지인 중심**.
- **누구에게 언제 보냈는지 간단히 기록**해두면(누가 반응했는지) 나중에 도움됩니다.
- 피드백은 사이트 안 `/feedback` 폼으로 모이고, 방문 지표는 Vercel Analytics에 쌓입니다 — 며칠 지켜본 뒤 **진짜 문제만** 골라 수정 → 그게 2차 준비.
