# VOICE_GUIDE — 트릴리언 카피 보이스 (원어민 전문가처럼)

> 목표: "적절한 단어를 찾아 쓴 AI"가 아니라 **"적절한 단어를 고른 그 나라 전문가"**의 말투. 정확·전문·정직은 유지하되, **번역·직역·AI 조어가 아닌 원어민이 실제로 쓰는 말**로.
> 적용: `lib/lensCopy.ts`(ko/en 언어맵)·`lib/lenses.ts`·`lib/fscore.ts`·`app/stock/[symbol]/page.tsx` 등 모든 노출 카피.

## 대원칙
1. **원어민 재집필 ≠ 번역.** 각 언어는 그 언어 전문가가 처음부터 쓴 것처럼. 다른 언어로 갈 때 한국어를 옮기지 말고, 그 나라 사람으로서 다시 쓴다.
2. **경제적·자신감.** 전문가는 덜 말하고 더 믿게 둔다. 뻔한 걸 매 문장 다시 풀지 않는다.
3. **직역 조어 금지.** 한국인이 실제 쓰는 도메인 단어로. (예: "표본 약함"→"약한 신호", "근거 주의"→"자료 갱신".)
4. **정직·중립 유지.** 예측·"사라/사지마라" 금지는 그대로. 단, 딱딱하지 않고 자연스럽게.
5. **톤 = 토스증권/좋은 애널리스트.** 깔끔·따뜻·똑똑. 챗봇 아님, 교과서 아님. 해요체 기본(과잉 존댓말·"~습니다" 남발 지양).
6. **전문 용어는 OK — 단, 살아있게.** 어렵게 쓰지 말라는 게 아니라, 진짜 전문가가 그 단어를 쓰는 맥락·리듬으로.

## AI처럼 들리는 tell (피할 것)
- **직역 조어**: "표본 약함", "근거 주의", "그 차이가 정보예요"(= the difference is information).
- **과잉 설명·헷지**: 문장마다 "~이에요/~고요"로 반복 해설.
- **기계적 대칭**: "A · B · C · D" 딱 떨어지는 병렬 나열.
- **영어 어순 호흡**: 한국어 문장 숨이 아닌 직역체 끊기.

## 라벨 재집필 결정 (확정본)
| 지금 | → | 이유 |
|---|---|---|
| 표본 약함 | **약한 신호** | "표본"은 통계 전문용어·"약함" 조어. "우리 검증에선 약했다"를 자연스럽게 |
| 근거 주의(플래그) | **자료 갱신** | "주의"가 부정 경고처럼 들림 — 실은 중립적 사실 안내 |
| 건전성(F-Score 배지) | **재무 건전성** | 얇게 자른 "건전성"이 모호 — 한국인이 쓰는 정식어로 |
| 검증 · 참고용 · 새 사실 | (유지) | 이미 자연스러움 |

## before → after (문장 예시)
- ✗ "각 렌즈는 '예측'이 아니라… 그 차이가 정보예요."
  ✓ **"오를지 맞히는 게 아니에요. 검증된 기법들이 이 종목을 어떻게 보는지 그대로 보여드려요 — 시선이 엇갈리면 그게 오히려 봐야 할 지점이고요."**
- ✗ "⚠ 이 점수 근거가 최근 바뀌었을 수 있어요"
  ✓ **"이 점수는 옛 자료 기준이에요 — 최근 새 공시가 나왔거든요. 참고만."**
- ✗ "최근 사실 — 이 점수엔 아직 없어요"
  ✓ **"이 점수엔 아직 안 들어간 최근 소식이에요."**
