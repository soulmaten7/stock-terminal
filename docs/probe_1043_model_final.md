# probe 1043 — 각 칸의 최종 모델 확정

> 🔴 이 STEP은 **무엇을 쓸지**까지다. 표시·화면·플래그는 다루지 않는다(나오면 "표시 설계로 넘김"이라 적고 멈췄다). 코드 diff 0 · DB 쓰기 0 · 화면 변경 0. 원전 재검색은 저장소에 없는 것에만 했고, 어디를 왜 열었는지 아래 각 항목에 적는다. 최종 승인 = 장은태.

## 칸별 최종 모델 한 장

```
배수(이익·자산·매출 대비 비싼가)
  → 동점 4개, 판정 대상: EV/EBITDA · P/E · P/B · PSR(적자대안)
    (①②③ 전부 통과 + 서로 "같은 질문의 다른 분모"라 칸이 갈리지 않음.
     🔑 이미 결정된 Q1 "C안" 구성과 정확히 같은 4개로 수렴 — 우연이 아니라
     같은 기준을 다른 시점에 적용해도 같은 답이 나온다는 교차검증)
  → 후순위(③ 근거 없음): EV/Sales·EV/EBIT·P/CF·EV/FCF·PEG·NAV·Net-Net·
    Graham Number

재무건전성(개선되고 있는가, 악화되고 있는가)
  → 확정: Piotroski F-Score
    (Novy-Marx GP/A·DuPont은 "다른 질문" — ①에서 탈락, 아래 1-2)

시장내재기대(이 주가는 무엇을 가정하는가)
  → 확정: 역DCF(Rappaport & Mauboussin) — 경쟁 후보 없음

배당(얼마나 주고, 얼마나 오래 늘렸나)
  → 확정(보완 조합): 배당수익률(얼마나) + Dividend King/Aristocrat류
    연속증가연수(얼마나 오래) — "같은 배당 질문의 두 하위축", 동점 아님
  → 탈락: 총주주환원수익률(저장소 기존판정 STEP551로 이미 탈락)
  → 다른 칸으로: DDM/Gordon(적정주가류 — 관문②에서 이미 탈락한 것과 동일 성격)

부도위험(망할 위험이 있는가)
  → 확정: Altman Z-Score (Ohlson O-Score는 ③에서 밀림)
  → 🔴 단 이 칸은 "지금 만들 수 없다"(②재료 부재, 아래 1-3)

최근변화(최근 무엇이 달라졌는가)
  → 확정(보완 조합): 모멘텀 12-1(Jegadeesh-Titman) + 기술(RSI 단기+MA200
    장기) — 이미 보유
  → 후순위(③ 개별 근거 없음): MACD·볼린저밴드·OBV·상대강도(IBD RS)

0층(업종·이익상태) — 모델 아님, 후보 0개(1-5)
```

## 1-1. 각 칸의 질문 — 후보를 보기 전에 먼저

`probe_1040`의 칸 이름이 아니라 질문 형태로(모두 `probe_1037`§1-5·`USER_QUESTIONS`§2가 이미 확정해 둔 문구를 그대로 옮긴 것 — 이번에 새로 지어내지 않았다):

| 칸 | 질문 |
|---|---|
| 배수 | 이 회사가 이익·자산·매출 대비 비싼가, 싼가? |
| 재무건전성 | 이 회사의 재무 상태가 **개선되고 있는가, 악화되고 있는가**? (수준이 아니라 **방향**) |
| 시장내재기대 | 이 주가가 정당화되려면 앞으로 얼마나·얼마나 오래 성장해야 하는가? |
| 배당 | 현금을 실제로 얼마나 돌려주는가, 그리고 얼마나 오래 늘려왔는가? |
| 부도위험 | 이 회사가 망할 위험이 있는가? |
| 최근변화 | 최근 무엇이 달라졌는가? |

🔴 **모호함 표시**: "재무건전성"이 특히 위험하다 — "개선/악화(방향)"과 "얼마나 잘 버는가(수준)"는 일상어로는 둘 다 "건전성"처럼 들리지만 서로 다른 질문이다. `probe_1037`§1-5 원문("전반적 재무건전성**개선/악화 중인가**")이 방향 쪽으로 이미 확정해 뒀으므로 이 STEP은 그 정의를 그대로 쓴다 — 아래 1-2에서 이 모호함이 실제로 후보를 가른다.

### 부도위험 칸 (2개)

**②재현(오늘 DB 실측, `us_fundamentals` 스키마 재확인)**:
- Altman Z(운전자본·이익잉여금·EBIT·시총·매출·총부채 필요): `us_fundamentals`에 **`Assets`·`Liabilities`(총자산·총부채) 컬럼 자체가 없다**(`probe_1041`·`probe_1042`가 이미 확인, 오늘 재확인 동일). 운전자본(유동자산−유동부채)·이익잉여금도 없음. **원전 그대로 재현 불가.**
- Ohlson O-Score: Altman보다 입력이 많고(총자산 로그·GNP 디플레이터 등) 외부 데이터까지 필요(`MODEL_ROSTER.md`§3) — Altman보다 재현 조건이 더 나쁨.

**③사용률**: Altman Z = `MARKET_MODEL_USAGE_TOP20.md`§1#19 "신용·부도 맥락에서 표준(주식 밸류에이션 리포트에선 드묾)" — 약하지만 존재. Ohlson O-Score = top20에 없음, 🔴 **사용률 근거 없음**.

**결론**: 둘 다 ②는 지금 불가능(재료 부재)이지만, **모델 자체를 고르라면** ③에서 Altman Z가 유일하게 근거를 가진다 — **Altman Z-Score 확정.** 단 🔴 **이 칸은 "지금 만들 수 없다"**(1-4 참조).

### 최근변화 칸 (7개, 모멘텀12-1·IBD RS 경쟁 / RSI·MA200·MACD·볼린저 경쟁 / OBV 별도)

**②재현**: 모멘텀12-1·RSI·MA200 = ✅ **이미 완성**(7렌즈). IBD RS·MACD·볼린저밴드·OBV = 계산 자체는 가격 시계열만 있으면 가능(비용 낮음)하나 **미구현**.

**③사용률**: 모멘텀12-1 계열(횡단면 상대강도) — `MARKET_MODEL_USAGE_TOP20.md`§1#6 "펀드매니저 87%·개인 55%"가 "이동평균·추세" 항목에 걸려 있으나 이 수치는 **"기술적 분석" 카테고리 전체**를 잰 것이지 모멘텀12-1과 IBD RS를 구분하지 않는다. RSI·MA200·MACD·볼린저밴드도 마찬가지로 같은 카테고리 수치에 포섭될 뿐 **개별 근거는 없다.** OBV = 🔴 개별 근거 없음.

**결론**: ③이 카테고리 단위(87%)로만 있어 후보 간 우열을 가리지 못한다. **이미 구현·완성된 쪽(모멘텀12-1·RSI+MA200)이 ②에서 압도적으로 앞서 실질 확정** — 미구현 4개(IBD RS·MACD·볼린저밴드·OBV)는 "같은 질문을 다른 방법으로 또 만들 근거가 없다"(③ 차별화 불가 + ②비용 추가)로 후순위. 🔴 **동점이 아니라 재료·근거 둘 다에서 밀린 것**임을 명시(억지로 하나로 줄인 게 아니라 실제로 갈렸다).

## 1-5. 구조 잔여 3건 — 판정 재료만 (판정하지 않음)

### Beneish M-Score — 「회계 조작 탐지」 칸 신설 여부

- **원전 목적**: Beneish(1999), *Financial Analysts Journal* 55(5). 8개 재무비율로 **이익 조작(분식) 가능성**을 탐지 — 재무건전성("개선/악화")도 부도위험("망할 위험")도 아닌 **세 번째 질문**("이 숫자를 믿을 수 있는가")이다. `probe_1040`·`probe_1041` 어느 칸과도 안 맞는다.
- **재료**: `MODEL_ROSTER.md`§3 "임계값(−1.78 vs −2.22) 출처 간 불일치, 정본 미확정" — 원전 자체의 정의가 흔들림. 재현 비용 `MODEL_UNIVERSE_63`§1D#32 "5+"(최고 비용 등급).
- **사용률**: `MARKET_MODEL_USAGE_TOP20.md`§1#20 "전부 개인 투자자 담론 중심 · 전문가 리포트 실측 근거 0".
- 🔴 재료만 낸다 — 신설/폐기는 장은태 판정.

### 저변동성·자산성장 — 구조 밖 상태

- **원전 목적**: 저변동성 = Betting-Against-Beta(Frazzini-Pedersen), 자산성장 = Fama-French CMA. 둘 다 `MODEL_UNIVERSE_63`§1E가 스스로 명시하듯 **"포트폴리오 구성 기법 — 종목 단위 산출물 아님"**(횡단면 롱숏 팩터 검증용으로 설계됨).
- **화면에서 지금 무엇으로 보이는지(코드 확인)**: `lib/lenses.ts`의 `lowvol`(calm/mid/jumpy 3분류)·`assetgrowth`(conservative/mid/aggressive 3분류) 렌즈가 **종목별 백분위**로 변환해 개인 투자자에게 단일 종목 카드로 서빙 중이다(`lens_scores.lowvol_state`·`assetgrowth_state`). 🔴 **원전이 "포트폴리오 기법"이라 부르는 것을 우리가 "개별 종목 상태"로 변형해 쓰고 있다** — 이 변형 자체가 원전 이탈인지는 판정 대상(창작 금지 규칙 5-1의 "정의 고정·공개" 트랙으로 이미 처리 중인지 확인 필요, 이 STEP 범위 밖).
- `probe_1040` Layer A(수요 확정 7항목)에 이 둘은 원래 없었다(STEP1040에서 이미 관찰됨) — 즉 **수요 근거 없이 구조에 남아 있는 상태.**
- 🔴 재료만 낸다 — 존치·이관·제거는 장은태 판정.

### 0층(업종·이익상태) — 모델이 아니라 데이터·상태값

## 3중 규칙

- **못 한 축(시도 기록)**: DuPont·MACD·볼린저밴드·OBV의 원전 저자·최초 출판연도를 정밀 확인하는 웹검색은 안 함(전부 실무가 고안·저장소에 없는 자료라 "①의 판정에 필요"하지만 판정 자체(같은 범주 vs 다른 범주)는 목적 서술만으로 충분해 추가 검색 없이 진행 — ⓪-1b "저장소에 없는 경우에만" 조건에 해당하나 이번엔 판정에 지장 없어 생략).
- **아직 안 함**: 배수 칸 동점 4개 중 하나로 좁힐지(장은태 판정) · 저변동성·자산성장·Beneish M 처분 판정 · Altman Z 재료 확보(Assets·Liabilities 컬럼 신규 추가) 착수 여부.
- **철회·정정**: 없음(이번 STEP은 신규 도출이며 이전 결론을 뒤집지 않았다 — 오히려 배수 칸에서 기존 STATE.md 결정과 독립적으로 같은 답에 도달해 **재확인**했다).
- **미측정**: PSR의 개별 실사용률 수치(카테고리 97%에 포섭될 뿐 단독 수치 없음) · IBD RS Rating의 정확한 계산식 공개 정도(원전 확인 안 함, `MODEL_ROSTER.md`§4가 "전면공개"로 이미 분류해둔 것만 인용) · DDM을 "배당 칸에서 적정주가류로 옮긴다"는 재배치가 화면(예: Q2 카드 설계)에 실제로 어떤 영향을 주는지(표시 설계라 이 STEP 범위 밖).
