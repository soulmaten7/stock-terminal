## 1. 정지 지점 특정

### 1-1. as_of·갱신 이력

`lens_cuts`는 PK가 `(market, lens_key)`라 **이력 테이블이 아니다** — 지금 US 5행이 전부이고 `as_of`는 "마지막 성공 갱신일" 하나만 가리킨다. "최근 20일치"를 낼 수 있는 구조 자체가 없다(이 사실 자체가 하나의 발견).

`lens_scores`(US)는 이력이 있다(`updated_at` 컬럼, 행마다 개별 upsert). **날짜별로 "그날 갱신된 행 수"를 세면:**

| 날짜 | 갱신 행 수 |
|---|--:|
| 2026-08-09 | 910 |
| 2026-08-07 | 36 |
| 2026-08-06 | 57 |
| 2026-08-04 | 1 |
| 2026-08-03 | 3 |
| 2026-07-30 | 16 |
| **07-31·08-01·08-02·08-05·08-08** | **0 — 11일 중 5일은 US에서 단 한 심볼도 안 바뀜** |

🔴 **위 6개 날짜 합(910+36+57+1+3+16=1023)이 오늘 US 유니버스 전체 행수와 정확히 일치한다** — 즉 이 6일 외엔 US에서 아무 갱신도 없었다는 뜻이다. **STATE.md 미해결 13번의 "lens_scores는 08-07까지 정상 갱신"이라는 서술은 이번 실측과 다르다** — 정상(≈1000행/일)이 아니라 대부분의 날 0~57행뿐이었다. 이 STEP에서 정정한다.

### 1-2. 크론 신원

- 라우트: `app/api/cron/lens-scores/route.ts` → `computeLensScores(1000)`(`lib/lensPrecompute.ts`)
- 스케줄: `vercel.json` — 매일 UTC 21:30(`30 21 * * *`)
- `maxDuration`: 300초
- 쓰는 테이블: `us_market_cap`(내부 `topByMarketCap()`) · `lens_scores` · `lens_cuts` · `lens_state_changes` · `cron_heartbeats`
- 읽는 테이블: `us_market_cap`(직전 상위200 메가캡, 구성게이트용) · `lens_scores`(직전 유니버스, churn용)

### 1-3. 🔴 컷 계산이 건너뛰어지는 조건 — 코드 전수

`lib/lensPrecompute.ts`를 읽어 실제로 존재하는 스킵 분기 전부:

| 분기 | 위치 | 조건 | 효과 |
|---|---|---|---|
| **A. cutGateOk 실패** | `:453` | `coverageOk(freshCoverage≥97%) && compositionOk(직전 메가캡 200 중 오늘 확보≥95%)` 중 하나라도 거짓 | **5개 렌즈 컷 재유도 전체 스킵**, `lens_cuts` upsert 자체가 호출 안 됨. 그리고 `computeLensScoresFor`의 최종 `ok = universeOk && pass2Ok && cutGateOk`(:510)이라 **크론 전체가 실패로 보고되고 route.ts가 HTTP 500을 반환**(lens_scores 자체는 대부분 저장돼 있어도) |
| B. 표본 부족 | `:445` | 렌즈별 `cutValues[key].length < 30` | 그 렌즈 하나만 스킵 |
| C. upsert 에러 | `:456-457` | DB 쓰기 실패 | Sentry 캡처만, 조용히 실패 |
| D. 상류 예외 | (구조상) | `topByMarketCap`/`capGateDecision` 이전 단계에서 throw | 컷 코드 자체에 미도달, Sentry `[lens-cut-gate]` 메시지조차 안 남음 |

**🔴 08-09 실행에서 실제로 발동한 것은 A다 — 추측이 아니라 `cron_heartbeats`에서 직접 관측했다:**

```
job=lens-scores · ok=false · freshCoverage=93.04% · coverageOk=false · compositionOk=false
compRatio=94% · cutGateOk=false · computed=910/1000 · noCapField=416
```

`freshCoverage 93.04% < 임계 97%` → `coverageOk=false` → `cutGateOk=false` → 컷 갱신 스킵. **정확히 코드가 말하는 대로 동작했다.**
