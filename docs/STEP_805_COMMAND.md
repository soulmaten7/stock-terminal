# STEP 805 — 렌즈 판정을 `lens_cuts`로 전환 (상수 제거 · 이중컷 통일 · 검증 인용 범위 · PER 기준 명시)

**실행**: `cd ~/stock-terminal && claude --dangerously-skip-permissions --model opus` 🔴 **Opus 권장**(7개 렌즈 판정 로직 전면 · 순환 의존)

**전제 상태**: STEP 804 커밋 이후 HEAD · 트리 클린

**배경**: STEP 802가 컷 **산출·저장**까지 완료(`lens_cuts` 테이블 + 크론이 p30/p70 저장). 남은 것은 **소비** — 렌즈가 코드 상수 대신 이 컷을 읽어 판정하는 것. 802에서 순환 의존(값→컷→상태) 때문에 의도적으로 분리했다.

**802 실측이 보여준 것**(왜 이 STEP이 필요한가):

| 렌즈 | 기존 상수 | KR p30/p70 | 결과 |
|---|---|---|---|
| 변동성 | 20 / 40 | **56.8 / 84.5** | KR 하위 30%조차 기존 "고변동" 선(40)보다 높음 → **한국 종목이 사실상 전부 "출렁임·주의"** |
| GP/A | 15 / 40 | 8.5 / 20.2 | 대부분 "낮은 수익성" |
| 모멘텀 | −10 / +10 | −25.5 / 24.6 | 과민 판정 |
| PER | 10 / 25 | 9.10 / 26.86 | 영향 작음(싼 편 32%→30%) |

즉 지금 화면의 "주의" 상당수는 **종목 특성이 아니라 시장 레벨 차이**를 잰 것이다.

## 수정

### 1) 판정 로직을 `lens_cuts` 주입식으로 전환

- 7개 렌즈의 verdict 산출이 **코드 상수 대신 `lens_cuts(market, lens_key)`의 `lo`/`hi`를 읽도록** 리팩터.
- **컷이 없으면 판정하지 않는다** — `state`를 `'na'`로 두고 화면엔 **"기준 준비 중"**(신규 문구·ko/en). 🔴 **임의 상수 폴백 절대 금지**(그게 지금 문제의 원인).
- **제외 대상(고정값 유지)**: RSI 30/70, F-스코어 3/7 — 학술·업계 표준이라 분포 유도 부적합. 코드 주석과 서사에 "이 둘은 표준 고정값" 명시.
- 렌즈별 **방향(높을수록 좋음 / 낮을수록 좋음)**을 메타에 명시해 컷 해석에 반영(저변동성·자산성장·PER은 낮을수록, 모멘텀·GP/A는 높을수록).

### 2) 순환 의존 해소 — 크론 2-pass

- 문제: 컷은 분포에서 나오고, 분포는 값에서 나오며, 판정은 컷을 필요로 한다.
- 조치: 선계산 크론을 **2-pass**로 — ① pass1: 전 유니버스의 **값(value)만** 계산·저장 ② 분포에서 컷 산출 → `lens_cuts` 저장 ③ pass2: 저장된 컷으로 **상태(state)·톤** 산출·저장.
- 시간 예산(300s) 안에 들어오는지 확인. 초과 위험이 있으면 pass2를 값 재계산 없이 **DB 내 갱신**으로 처리(값은 이미 저장돼 있으므로 상태만 다시 매핑).
- 라이브 `/api/lens`(온디맨드 경로)도 같은 컷을 읽어 **선계산과 판정이 일치**해야 함(현재 화면·탐색·오늘이 서로 다른 판정을 보이면 안 됨).

### 3) 이중 컷 제거

- 같은 값에 verdict 컷과 label 컷이 따로 있다(모멘텀 verdict ±10 / label ±20, 변동성 verdict 20-40 / label 25-45). 주석에 "통일 금지"로 고착돼 있고 특성화 테스트가 모순을 스냅샷으로 박아뒀다.
- 조치: **`lens_cuts` 단일 컷으로 통일**. 스냅샷은 갱신(의도된 변경 — diff 눈으로 확인).

### 4) "검증" 배지·백테스트 인용의 적용 범위 명시

- 현재 `note`의 t값·기간은 **미국 유니버스 백테스트** 결과인데 KR 카드에도 그대로 붙는다. 또 검증된 것은 **3분위 롱숏의 방향성**이지 절대 컷이 아니다(이제 컷은 분포 유도이므로 오히려 정합).
- 조치: 인용에 **어느 시장·어느 기간 검증인지 명시**. KR에 대한 자체 검증이 없으면 **"이 시장에서는 아직 자체 검증 데이터 없음"**을 정직하게 표기. 배지 자체를 없앨 필요는 없으나 **근거의 범위를 속이지 말 것**.

### 5) PER 산출 기준 명시 (STEP 803 후속)

- 우리 PER은 **직전 연간 순이익** 기준(학술 E/P 정의). 외부 사이트 다수는 **TTM** 기준이라, 실적이 급변하는 국면에서 값이 크게 다르다(실측: 삼성전자 우리 33.8 vs 외부 18~19).
- 조치: 계산 변경 없이 **표시에 기준을 명시**("연간 실적 기준" · en "based on last fiscal year"). 근거 줄·서사에 반영해 사용자가 다른 사이트와 비교할 때 혼란이 없게.

### 6) 컷 출처 표시

- 근거 줄·서사의 "판정 컷" 표기를 **실제 사용된 컷 + 출처**로: `KR 분포 하위/상위 30% 기준 · N=808 · 2026-07-28`. 사용자가 숫자의 출처를 확인할 수 있어야 함.
