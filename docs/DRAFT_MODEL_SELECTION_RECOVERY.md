## §2 — 재조사: "실제로 가장 많이 쓰이는 모델"

🔴 **`CLAUDE.md` "검색은 결론보다 먼저다" 준수.** 결론을 정해놓고 뒷받침하지 말 것.

### 2-1. 조사 대상 = **플랫폼 → 모델** (역방향 금지)

🔴 **"인기 모델 순위"를 직접 검색하면 블로그·SEO 글이 나온다. 그건 근거가 아니다.**
**대신 실제 플랫폼이 무엇을 제공하는지를 세서 순위를 만든다.**

**최소 조사 대상**(각각 공식 페이지·가격표·방법론 문서를 열 것):

| 구분 | 예시 |
|---|---|
| 유료 리서치 | Morningstar · Zacks · Value Line · New Constructs · Simply Wall St · Stockopedia · GuruFocus · TIKR · FinChat/Fiscal.ai · Koyfin · YCharts · Seeking Alpha |
| 무료·개인 | Yahoo Finance · Finviz · TradingView · Alpha Spread · Wisesheets · 네이버증권 · 토스증권 · 키움 · 초이스스탁 · 딥서치 |
| 한국 | 🔴 **반드시 포함.** 우리 1차 시장이다 |

**각 플랫폼에서 기록할 것**
1. **제공 모델·지표 이름**(그들이 쓰는 표현 그대로)
2. **유료/무료 · 가격**
3. **사용자 규모 근거**(공개된 것만 · 없으면 "미공개")
4. **출처 URL + 취득일**

### 2-2. 🔴 순위를 어떻게 매길 것인가 — **먼저 기준을 정하고 적는다**

**결과를 보고 기준을 고르면 그건 조작이다.** 아래 중 무엇을 쓸지 **조사 전에 선언**하고 보고에 명시할 것:

- (a) **제공 플랫폼 수** — 몇 개 플랫폼이 그 모델을 싣는가 (가장 방어 가능)
- (b) **플랫폼 사용자 수 가중** — 사용자 수가 공개된 곳만 (결측 많음)
- (c) **검색량·언급량** — 🔴 대리지표라 약함

🔴 **(a)를 기본으로 하되, 셋 다 재서 나란히 보고**한다. **서로 다르게 나오면 다르다고 적는다.**

### 2-3. 🔴 원본 저장 (규칙 ⓪)

- 저장 위치 = **`data/sources/market_survey/`** (신규)
- 각 플랫폼의 **모델·가격·방법론 페이지를 raw HTML로** 저장. 첫 줄에 `<!-- 취득일 · URL -->`
