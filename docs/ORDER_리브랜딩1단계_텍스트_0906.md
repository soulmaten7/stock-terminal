# ORDER — 리브랜딩 1단계: 브랜드 텍스트 교체 (2026-09-06)

플랫폼 브랜드를 **Trillion(트릴리언) → EarthTicker**로 교체한다. 이번
STEP은 **텍스트만**. 도메인 전환·로고·컬러는 이후 별도 단계다.

## 확정 사항 (사용자 확정 2026-09-05~06)

- **새 브랜드명**: `EarthTicker` (한 단어, 대문자 E·T)
  - 한국어 표기: **어스티커** (필요한 곳에만. 기존 "트릴리언"이 있던 자리)
- **새 태그라인**:
  - ko: **「세계의 주식 정보를, 한 곳에서」**
  - en: **「Every market, one place」**
- **확보한 도메인**: `earthticker.app` (이번 STEP에서 **연결하지 않음** —
  텍스트에도 아직 쓰지 말 것. 2단계에서 전환)
- **이름을 바꾼 이유**(문서에 남길 근거): Trillion은 모델 시대에 지은
  "숫자·규모" 이름이라 현재 사업(각국 채널의 주식 정보를 한곳에 모으는
  중앙 플랫폼)을 설명하지 못한다. EarthTicker는 "여러 나라 + 금융"을
  이름 자체가 담는다.
- **채널명은 유지**: 스톡스카우터(KR)·WeTheTicker(US)는 각국 현지
  브랜드로 그대로. 플랫폼만 독립 브랜드.
- **살릴 자산**: 기존의 절제된 톤 — "사고팔 신호가 아니라, 스스로 판단할
  재료예요" 계열 문구는 그대로 유지한다. 이건 브랜드 자산이다.

## 이번에 바꾸는 것

사이트·문서 전체에서 `Trillion`/`트릴리언` 및 옛 태그라인(「종목을 보는
눈을, 누구에게나」/영문 대응)을 새 값으로 교체:

1. **헤더 로고 텍스트·서브텍스트** (지금 "Trillion 트릴리언 / 종목을 보는
   눈을, 누구에게나")
2. **푸터 브랜드 블록**
3. **About 페이지** — 제목·소개·본문의 브랜드 언급
4. **메타데이터**: `Meta` i18n 네임스페이스(title·description·
   jsonLdDescription·keywords), `app/layout.tsx`, 각 페이지
   `generateMetadata`, JSON-LD 구조화 데이터의 조직명
5. **PWA 매니페스트** (`app/manifest.ts`) — name·short_name·description
6. **법적 문서** `/terms`·`/privacy` — 서비스명 표기
7. **i18n 전체**(ko/en) — 위 항목이 참조하는 키 전부, 패리티 유지
8. **`messages.test.ts` 잠금 문자열** — 브랜드 보이스 테스트가 옛 문구를
   고정하고 있으면 새 값으로 갱신(테스트를 끄지 말 것)
9. **저장소 문서**: `docs/BRAND_IDENTITY.md`(이미 일부 동결 표시됨 —
   브랜드명·태그라인을 새 값으로 갱신하고, 옛 이름은 "2026-09-06
   EarthTicker로 변경" 이력으로 남김), `docs/STATE.md` ⓪,
   `README.md`, 그 외 docs-map이 지목하는 문서 중 브랜드명이 등장하는 곳

## 작업 방식

- 먼저 `Trillion`·`트릴리언`·옛 태그라인을 **전수 grep**해 목록을 만들고,
  각 항목이 (a)브랜드명이라 교체 대상인지 (b)인프라 식별자라 유지인지
  (c)동결된 옛 문서의 이력 서술이라 유지인지 분류할 것. 기계적 일괄
  치환 금지 — 분류 후 교체.
- 새 브랜딩 문구를 창작하지 말 것. 위에 확정된 이름·태그라인만 사용하고,
  기존 문장의 브랜드명 자리만 교체. 문장 자체를 새로 쓰는 게 불가피한
  곳이 있으면 그 목록을 보고하고 확정 받을 것.
- ko/en 패리티 유지, 아포스트로피 금지 규칙 유의.
