# AD_MONETIZATION_PLAYBOOK — 광고·수익화 런북 (전 언어권 공통)

> **이 문서는 `LOCALE_SOURCE_PLAYBOOK`의 "광고 버전"이다.**
> 데이터 소스 런북이 "각 언어권에서 시세·공시를 어떻게 가져오나"를 다뤘다면,
> 이 런북은 "각 언어권에서 **광고·제휴로 어떻게 수익화하나 — 그리고 어디가 왜 되고 왜 안 되나**"를 다룬다.
> **목표 비전: 전 세계 240개국. 주식이 거래되고 정보가 필요한 모든 언어권을 거미줄처럼 엮는다.**
> 그래서 이 문서는 "한국만"이 아니라, **한국을 첫 항목으로 채운 프레임**이다. 새 국가탭 착수 시 §5에 그 나라 항목을 반드시 추가한다.

---

## §0 대원칙 (LOCALE_SOURCE_PLAYBOOK §0 계승)

1. **값이 아니라 방법·정의를 코드화한다.** "한국은 리딩방 광고 됨"이 아니라 "그 나라의 금융광고 규제를 **어떻게 확인하고, 무엇이 조건이고, 왜 되는지/안 되는지**"를 기록한다.
2. **정체성이 광고보다 위다.** Trillion = "종목을 보는 눈을, 누구에게나" — 정직한 1차 재료로 스스로 판단하게(무기·직시·자립 · `BRAND_IDENTITY`). **능력을 팔되 의존을 팔지 않는다 — 광고가 신뢰를 깨면 그 광고는 안 받는다.** (예: 침입형 전면광고, 근거 없는 수익률 광고, 리딩방 광고=철학적으로 독.)
3. **광고 = 브릿지, AI 구독 = 기둥.** 광고에 ad-tech·자동경매를 과투자하지 않는다. 구조는 확장 가능하게, 운영은 가볍게(수동 요금표).
4. **"규제 통과 ≠ 지속 사용 통과."** 데이터 소스처럼, 광고도 "한 번 게재 가능"이 "계속 합법·안전"을 뜻하지 않는다. 법 개정·심의·표시의무를 §6 게이트로 계속 확인한다.
5. **안 되면 "안 됨"만 쓰지 않는다.** **왜 안 되는지(근거 법령·출처)+무슨 조건이면 되는지+상태**를 §5 원장에 단다. 막히면 §7에 보류로 남기고 배선은 보존한다.
6. **나는 변호사가 아니다.** §5의 법률 판단은 조사 기반 **초안**이며, 실제 제휴·게재 전 각 언어권 **법률/컴플라이언스 검토**를 거친다. 원장에 상태 플래그로 표기.

## §1 수익 계층 정의 (큰 파이 → 작은 파이)

전문가 조사(Investing.com·TradingView·Seeking Alpha·NerdWallet) 기반 우선순위. **국가탭마다 이 5계층을 §5에서 각각 판정한다.**

| # | 계층 | 성격 | 파이 | 비고 |
|---|------|------|------|------|
| **T1** | **AI 대화·구독** | 기둥 (정기결제 PG) | 최대·장기 | 정보 플랫폼의 코어 수익. Phase 5. |
| **T2** | **증권사 어필리에이트/리퍼럴** | 성과형 (계좌개설당 과금) | 큼·확장형 | NerdWallet 모델. "증권사 바로가기"와 결합. **투자권유 아님**으로 설계. |
| **T3** | **디스플레이/스폰서 슬롯** | 브릿지 (요금표·직접판매) | 중 | 고정 슬롯 전광판. 트래픽 비례. |
| **T4** | **데이터 라이선싱** | B2B (후순위) | 중·장기 | AI 렌즈 점수·공시요약 축적 후. |
| **T5** | **리딩방/투자자문 게재** | 규제 리스크 (소액) | 작음 | 규제 표시의무 강제 가능할 때만. 파이 작게. |

> **핵심 전략 결정(2026-07-10):** "리딩방 광고로 돈 번다"는 중심축에서 내린다.
> **진짜 큰 두 파이 = T1(AI 구독) + T2(증권사 어필리에이트).** T3는 구조화된 브릿지.

## §2 슬롯 인벤토리 스키마 (전 언어권 공통 "전광판")

**고정 슬롯을 정의해두고, locale마다 그 슬롯을 자기 나라 광고로 채운다.** 슬롯 자체는 전 국가 동일 → 광고 운영이 거미줄처럼 확장된다.

각 슬롯은 **의미우선(정체·목적·위치·포맷·노출단위·허용 buyer·표시의무)**로 정의한다:

```yaml
slot:
  id: string              # 전역 고유 (예: list_inline_10, preview_banner_pc, sheet_native_mobile)
  정체: string            # 이 슬롯이 무엇인가
  목적: string            # 왜 존재하나 (buyer가 사는 이유)
  위치: string            # UI상 정확한 자리
  포맷: enum              # in_feed_native | banner | sponsored_row | text_link
  노출단위: enum          # per_month(고정) | per_impression(CPM, 나중)
  허용_buyer: [enum]      # broker_affiliate | display_advertiser | feed_ad | (locale별 §5에서 제한)
  표시의무: [string]      # "Sponsored 표기" | (locale 규제에서 추가 — §5 참조)
  금지: [string]          # 이 슬롯에서 하면 안 되는 것 (예: 전면광고·자동재생)
```

### 표준 슬롯 3종 (한국 먼저, 이후 전 국가 동일 적용)

| slot.id | 정체 | 위치 | 포맷 | 비고 |
|---------|------|------|------|------|
| `list_inline_10` | 리스트 10개마다 인피드 광고 행 | 종목 보드 리스트 | in_feed_native | 현 "광고문의하기" 자리. Sponsored 표기. |
| `preview_banner_pc` | 미리보기 패널 배너 (PC) | "전체 렌즈근거보기" **아래** | banner | 고노출. 렌즈 콘텐츠 방해 안 함. |
| `sheet_native_mobile` | 모바일 종목 시트 네이티브 배너 | 모바일 종목 시트 내부 | in_feed_native | ⚠️ **전면광고(interstitial) 금지** — 구글 SEO 페널티·신뢰 훼손. |

> **`sheet_native_mobile`이 은태님 원안(모바일 전면광고)의 대체안이다.** 전환을 막지 않는 시트 내부 네이티브 배너로 간다.

## §3 어필리에이트 배선 스키마 (T2 — 진짜 큰 파이)

증권사 리퍼럴은 **광고 슬롯과 별개의 배선**이다(노출당이 아니라 성과당 과금). 기존 "증권사 바로가기"·"이 종목 거래하기" CTA에 추적 링크를 물린다.

```yaml
affiliate:
  broker_id: string       # 예: kr_kiwoom, kr_toss_sec, us_robinhood
  locale: string          # 이 제휴가 유효한 언어권
  정체: enum              # referral(계좌개설 유도) | brand_ad(브랜드 노출)
  과금모델: enum          # cpa_funded(입금계좌당) | cpl(리드당) | cpc | revenue_share
  추적: enum              # tracked_url(파라미터) | postback | promo_code
  규제_게이트: [string]   # §5에서 온 조건 (예: "투자광고 심의필 소재만", "투자권유 문구 금지")
  상태: enum              # live | contract_pending | legal_review | blocked
```

> **배선 원칙:** 우리는 **"어디서 거래할지 안내"만** 한다(리퍼럴/브랜드 광고). **특정 종목·상품을 "권유"하지 않는다** — 비예측 정체성과도, 규제(투자권유대행인 등록 회피)와도 맞는다. §5 KR 참조.

## §4 요금표·정산 스키마

| 계층 | 결제 방식 | 요금 구조 | 다수 지원자 처리 |
|------|-----------|-----------|------------------|
| **T1 AI 구독** | 정기결제 **PG** (통신판매업·전자상거래법 전제) | 월/연 구독 | — |
| **T2 어필리에이트** | **증권사가 우리에게 지급** (결제 인프라 불필요) | cpa_funded 등 성과당 | 여러 증권사 = 각 CTA/슬롯에 로테이션 or 종목·지역별 배정 |
| **T3 디스플레이 슬롯** | **수동 인보이스/계좌이체** (PG 불필요) | **슬롯당 월 고정 요금표** (협상 아님) | **월 단독(권장)**: 경쟁 시 최고가 입찰 or 선착순 → 수요>슬롯이면 로테이션(share-of-voice) |
| **T5 리딩방 게재** | 수동 인보이스 | 슬롯 고정가 (소액) | 로테이션 |

```yaml
rate_card:
  slot_id: string
  locale: string
  기간단위: month
  가격: number            # locale 통화. 트래픽 성장 전엔 고정가.
  판매방식: enum          # monthly_exclusive(월단독) | rotation(공유)
  경쟁처리: enum          # highest_bid | first_come | share_of_voice
  상태: enum              # open | sold | paused
```

> **은태님 판단 확인:** "요금표를 정해놓고" = **정답.** 직접판매는 CPM 환산 $10~20으로 프로그래매틱($1~5)보다 2~4배 비싸고, 트래픽 적을 땐 프로그래매틱이 안 돌아서 요금표 직접판매가 유일한 현실 모델. "광고문의하기 → 개별 소통 → 요금표대로 인보이스"가 맞는 흐름.

| 계층 | 판정 | 이유 / 조건 | 근거 |

## §6 검증 게이트 ("규제 통과 ≠ 지속 사용 통과")

새 광고·제휴를 켜기 전, 그리고 주기적으로 확인:

1. **표시의무 게이트** — 이 슬롯/제휴에 법정 표시(Sponsored·유사투자자문 고지·투자광고 심의필)가 붙는가? UI로 강제되는가?
2. **소재 게이트** — (T2 증권사) 게재 소재가 **심의필**인가? 우리가 임의로 만든 문구는 아닌가?
3. **권유 경계 게이트** — 문구가 "안내/리퍼럴"에 머무는가, "특정 종목 권유"로 넘어가는가? (넘어가면 등록 필요 → 중단.)
4. **신뢰 게이트** — 이 광고가 사용자를 속이거나(과장 수익률) 방해하는가(전면광고)? 그렇다면 정체성 위반 → 거절.
5. **법 개정 게이트** — 해당 언어권 규제가 바뀌었는가? (§5 조사일 오래되면 재확인.)

## §7 광고 실패·보류 원장 (Parked Feature Protocol 광고판)

특정 언어권/슬롯이 막히면(규제·제휴 불발) — **"안 됨"만 남기지 않는다.** 이유·조건·재개 트리거를 남기고, 배선(코드)은 보존한 채 스위치만 OFF.
