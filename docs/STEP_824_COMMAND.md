## 1. 이 렌즈의 확정 사실 (STEP 813 3중 검증 + 806/808)

1. **계보 = Baker-Bradley-Wurgler(2011)**, 저변동성 이상현상. **총변동성 계열이 맞다**(801의 BAB→BBW 정정이 옳았음). ⚠️ **BAB(Frazzini-Pedersen)는 베타 기반이라 인용 불가.**
2. **실무 변형**: 원전은 60개월 트레일링 **월별** 총변동성·**5분위**·월별 리밸런싱 / 우리는 **1년(252거래일) 일별 실현변동성·3분위(p30/p70)·시점 스냅샷**.
3. **이 렌즈는 수익 신호가 아니다.** 원전의 결론은 **위험 대비 우수(CAPM 반증)**이며, 우리 자체 백테스트에서도 **수익 우위는 약하고 불안정**(점추정은 재현 실패로 화면 미기재).
4. **알려진 반론**: 상승장에서 뒤처짐 · 수익 우위 약함.
5. **`calmHigh` 40% 임계는 임의 실무 상수**다(BBW 원전 근거 아님). KR calm 종목의 64%가 절대 40%를 넘어 실제로 필요한 구분이었음이 실증됐다.
6. **최소 표본 120 수익률** 미달 시 계산 불가(803).

## 2. 고칠 주장 (저변동성)

### 2-1. 🔴 `calmHigh` 40% 임계가 임의 상수임을 화면에서 말하지 않음

- 813이 **문서(`LENS_COMPLETION_STANDARD.md`·플레이북 #43)에는 "명시"라고 기록**했으나, `lensCopy`의 lowvol `note`·`scope`·`readings.calmHigh`와 `messages` 어디에도 **"40"이라는 숫자도, 임의라는 사실도 없다**.
- 조치: **임계값과 그것이 임의 실무 기준이라는 사실**을 화면에 드러낸다(scope 또는 readings 중 자연스러운 자리 택1). 🔑 문서가 "반영했다"고 적어둔 것과 실제 화면이 어긋난 사례이므로, **문서 기록도 실제에 맞게 정정**한다.

### 2-2. 🔴 `mid` 상태에 절대 수준 병기가 없음

- 806의 절대 sanity 가드(`calmHigh`)는 **calm에만** 걸리고 `mid`엔 없다. KR 실측 컷(lo≈56.8 / hi≈84.5) 기준으로 **연변동성 66%인 종목이 "변동 중간권"**으로 표시된다 → 사용자는 연 66% 변동을 '중간'으로 읽는다.
- 조치: `mid`(및 필요하면 `jumpy`)에도 **절대 수준을 함께 보여주는 표현**을 검토. 🔑 headline에 이미 절대값(`연변동성 X%`)이 있으므로 **중복이 아닌 방식**으로(예: 판정 문구에 "시장 중간권이지만 절대 수준은 …" 계열). 과밀해지지 않게 판단하고 근거를 보고에 기재.

### 2-3. 게이지 양끝·근거줄 (저변동 해당분)

- 위치: `StockLens.factorEnds.lowvolLo/Hi` · `StockLens.narrativeCutoffLowvol`.
- 🔑 **저변동은 percentile이 있어 게이지가 렌더된다**(모멘텀·밸류와 같은 경로). 823까지의 보고에서 **`en`에 "classified low/high" 절대 표현이 남아 있다**고 지적됐다 → 실제 렌더 여부 확인 후 **상대 표현**으로 정합.
- 🔑 **방향(낮을수록 pos)**이 라벨과 맞는지 함께 확인.

### 2-4. 등급 배지 "검증(방어)"의 정합

- 819에서 범례에 "검증(방어)" 항목이 추가됐다. 이제 **저변동 note·scope(수익 우위 약함)와 배지 문구가 서로 반박하지 않는지** 확인.
- 조치: 필요하면 배지 문구 또는 scope 표현을 조정해 **"방어 관점에서 검증됐고 수익 신호는 아니다"**가 한 번에 읽히게. ⚠️ 다른 렌즈의 등급 값은 건드리지 말 것.

### 2-5. 실무 변형 표기

- §1-2의 차이(창 60개월 월별 → 1년 일별 · 5분위 → 3분위)가 **scope에 정확히** 드러나는지 확인. 813에서 기록했으나 화면 문구에 반영됐는지 재확인.

### 2-6. 모집단·결측 사유

- 모집단 표기가 시장별로 정확한지(KR=거래대금 / US=시총 상위 1,000).
- **최소 표본 120 미달** 종목의 결측 사유가 정확히 표기되는지(822에서 밸류에 적용한 사유 분기와 같은 원칙 — "데이터 없음"으로 뭉뚱그리지 말 것).
