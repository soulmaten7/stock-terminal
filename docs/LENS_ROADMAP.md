# 기법(렌즈) 로스터 & 로드맵

> **제품 정의**: "미래를 맞히는 곳"이 아니라 **검증된 프로 기법들이 이 종목을 각각 어떻게 읽는지 + 각 기법이 얼마나 믿을 만한지**를 한자리에. 선택·판단은 사용자. (상세 포지셔닝: `docs/BUSINESS_STRATEGY.md` 결정 로그 2026-07-03.)
> 개인이 혼자 모든 검증된 기법을 종목마다 못 돌리니 = 진짜 가치. (커머디티 데이터 허브와 다름.)

## 진행 순서 (2026-07-03 확정 · 이 순서 지킴)
1. **① 결과값 정직화** — 지금 5개 렌즈의 라벨/판정이 검증 범위를 넘지 않게. *(진행 중: 밸류 절대 PER "저평가/고평가" 판정 → 서술형 "낮음/보통/높음"으로 순화. 모멘텀 임계값 ±20%는 후속.)*
2. **② UI·디자인 틀 완성** — 카드 구조(요약 → 쉬운 해석 → **신뢰도 등급 겉면 노출** → 자세히), 기법 **엇갈림 표시**, 문구("이 기법이란?" → "{기법} 알아보기") 등. 틀을 먼저 완성.
3. **③ 기능·기법 추가** — 아래 후보를 각각 "정의→데이터→백테스트→t·알파→표현" 통과 후 추가. 못 통과하면 정직하게 제외/참고.

## 현재 기법 (7 · 운영 중)
> **채용 기준 = 효용(독립된 새 축 + 해석가능)** / **등급 = 통계 유의성**. 독립성 있으면 넣되(사용자가 볼 가치), 유의 못 넘으면 "표본 약함"으로 정직 표기. 겹치면(주주환원=밸류 재포장) 탈락. — STEP 553~554 확립.
