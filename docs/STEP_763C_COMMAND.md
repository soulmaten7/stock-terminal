## 수정

### 1) 안내 블록 상시 복원 — 보드 6개 공통

- `lens_hint_seen` localStorage·X 닫기 로직 **제거** → 힌트 2줄(문구 + "사고팔 신호 아님"·우측 범례) **항상 표시**. 스크롤로 지나가는 콘텐츠로 취급.

### 2) 드롭다운 밀착 + 항목 확대 — [전체▾]·[1일전▾] 공통(6개 보드)

- 패널을 **트리거 바로 아래 밀착**(`top: 100%` + 2~4px·좌측 라인 정렬·763b에서 트리거 커진 만큼 오프셋 어긋난 것 교정).
- 항목: **높이 ≥44px·텍스트 15px**·패널 폭 ≥ 트리거 폭·선택 항목 민트 강조(현행 유지)·바깥 탭 닫기 유지.
- 데스크톱 패널도 분리 떠 있으면 동일 교정(밀착은 화면 불문 원칙).

### 3) 정렬줄 재배치 — [1일전▾]을 우측 열 위로

- 모바일 정렬줄: 좌측 `[전체 ▾] [현재가 ↑↓]` … 우측 끝 `[1일전 ▾][방향 ↑↓]` (`justify-between`) — 기간 드롭다운이 행의 "1일전 -x.xx%" 열 바로 위에 오게(헤더=데이터 열 정렬 원칙).

### 4) 렌즈 판정 3열 정렬 — `StockLensClient`(모바일+데스크톱 공통 교정)

- 렌즈 목록 행을 그리드로: `[렌즈명 auto] [판정 텍스트 — 고정 시작점(약 40~45%)에서 좌측 정렬·1fr] [배지 — 고정폭 열(최장 배지 "검증(방어)" 기준)·중앙/우측 정렬]`.
- 판정 텍스트 좌측 가장자리가 세로로 일직선 = 스캔 라인 생성. 색·문구·배지 스타일은 불변(위치만). 미리보기 카드(`LensPreview`)의 동일 목록도 같은 규칙.

### 5) 칩 디자인 언어 통일 — `ToolboxClient` + 보드 6개

- **모바일 셀렉터 칩 단일 스펙**: 높이 44px(min-h-11) · radius 12px(rounded-xl) · 활성 = `bg-unjong-strong` + 흰색 + font-medium · 비활성 = `text-unjong-muted` + **테두리 없음**(현재 혼재 → 없음으로 통일) · 라벨 14px.
- 적용: 국가 칩·종목/정보 탭·주식/ETF/ETN/리츠 서브탭·검색 아이콘 버튼·드롭다운 트리거 전부. 데스크톱은 기존 스타일 유지(`sm:` 분기).
