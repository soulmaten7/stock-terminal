## 909 추가 — 안건 1 재료 보완(부호 반전 실측)

906은 도미노 1건에서만 현행식의 부호 반전(−2.135% vs 원전 0.501%)을 확인했다. 909가 비교가능 246사 전체에서 재보았다(906 재현 확인 완료 — `docs/probe_909_wc_sign.json`): **부호 반전 26/246건(10.6%)**, 전부 도미노와 같은 방향. 레버리지는 반전군이 높은 쪽으로 치우치나(중앙 0.196 vs 전체 0.120) 극단치만은 아니고(p75 0.263), 업종은 21개로 분산(상위3 비중 23.1%뿐) — 레버리지축은 어느 정도 쏠리고 업종축은 안 쏠리는 혼합 양상. 반전군 자체의 GAP·판정 이동은 0건(26건 전부 `oldVerdict==newVerdict`). 도미노(DPZ) 자신은 2020~2023년 이자부 태그 결측으로 이번 표본에서 측정 불가(백분위 미산출). 상세 = `docs/DECISION_907_WC_DEF.md` §9. **이 재료가 안건 1의 판정을 바꾸지 않는다 — 907의 권고(하이브리드)는 그대로다.**

## 참고 — §10 미결목록과 DoD 9항목은 별개다

1번(driver4 정의)·2번(`#17·37·43`)은 `docs/REVDCF_SPEC.md` §10 "미결 목록"(904가 전수 감사한 76개 항목) 소속이고, 4번은 `docs/LENS_COMPLETION_STANDARD.md`의 **DoD 9항목**(공식 완성 기준) 소속이다. **§10은 DoD의 하위 체크리스트가 아니다** — 904 감사도 이 둘을 판정하지 않은 채로 남겼다. 즉 1·2번을 전부 어느 방향으로 정리해도 그 자체로 DoD 항목의 상태(✅/🅿️/🔶/❌)가 바뀌는 것은 아니다 — 다만 완성도에 대한 **정성적 판단 재료**로는 연결된다(905 §5의 "안 하면 모델이 틀리는 것 0건" 관찰이 4번 판단의 배경 재료가 될 수 있다는 뜻이지, 인과관계가 있다는 뜻은 아니다).

## 909 추가 — 안건 4 사실 확인(선택지가 실제로 몇 개인지 · 판정 없음)

`docs/LENS_COMPLETION_STANDARD.md:13` 직접 인용: **"완성 9항목 (전부 통과해야 "완성")"**. 같은 문서 39·53행이 DoD3에 명시적으로 적은 것: *"🔴 ✅가 아니라 🅿️ — '3종목 충족'이 아니라 '이 도메인에서 도달 가능한 최대치 도달'이라는 사실을 표기 자체가 숨기지 않는다."*

**사실 확인 결과 — Cowork의 사전 서술이 맞다.** "9항목 전부 ✅"는 **지금 이 순간 성립하지 않는다**(DoD3 = 🅿️, ✅ 아님). 게다가 이 🅿️는 863·864가 "무료로 접근 가능한 외부 검증 경로 8곳을 소진"한 뒤 붙인 것이라(도메인 상한), **재도전으로 언젠가 ✅가 될 여지가 있는 미완료**와는 성격이 다르다는 사실도 원문이 스스로 밝히고 있다.

`docs/STEP_903_COMMAND.md` §3 직접 인용(903 자신이 지적한 순환): *"STATE 보류 목록이 '항목 7·9 — 모델 완성 전 재개 금지'라고 적혀 있다. 7·9가 보류인 채로 나머지가 다 닫히면, '모델 완성'의 정의가 무엇인지가 열린 질문이 된다."*

**선택지 3개와 성립 여부(사실만·판정 없음)**:

| 선택지 | 현재 성립 여부 |
|---|---|
| "9개 전부 ✅" | **불가** — DoD3이 🅿️(도메인 상한, 원문이 "✅ 아님"을 명시). 재측정으로 바뀔 여지도 8곳 소진으로 낮다는 사실이 원문에 있음(판정은 안 함) |
| "3을 🅿️로 인정하고 나머지 8개 ✅"(즉 DoD7·9도 ✅화) | **현재 미성립** — DoD7=🔶(보류)·DoD9=❌(보류), 둘 다 아직 ✅ 아님. ✅가 되려면 `REVDCF_ENABLED` Production ON이 전제인데, STATE 보류 목록 자체가 "DoD 7·9는 모델 완성 전 재개 금지"라 적어 — 903 §3이 지적한 순환(완성의 조건과 재개 조건이 서로를 전제)이 실제로 존재함 |
| "7·9를 뺀 7개 닫힘" | **이미 성립**(903 시점부터) — 1·2·4·5·6·8 ✅ + 3 🅿️ = 7개. 추가 조치 없이 현재 상태 그대로 |

🔴 이 표는 어느 선택지를 권하지 않는다. 세 선택지 각각이 **지금 참인지 거짓인지**만 사실로 적었다.
