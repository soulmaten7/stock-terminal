## 수정

### 1) AI 요약 = 온디맨드 (핵심)

- 각 공시 행에 펼침 토글(우측 ▾·44px 터치 타깃). **닫힘이 기본**.
- 요약 fetch를 **펼칠 때 최초 1회만** 실행(현행 `useEffect` 마운트 호출 제거). 한 번 받은 요약은 컴포넌트 상태에 보관해 재펼침 시 재호출 없음.
- 로딩·실패 처리는 현행 유지(실패 시 조용히 숨김·원문 링크는 행에 유지).
- **원문 링크 동작 보존**: 행 전체가 DART/EDGAR 링크였다면 → 링크는 제목 영역에, 펼침은 토글 버튼에 분리(클릭 충돌 방지·`stopPropagation`).

### 2) 기본 5건 + 더 보기

- 목록 기본 **5건**, 나머지는 `{n}건 더 보기 →`로 펼침(같은 카드 안에서 확장·페이지 이동 아님). 5건 이하면 버튼 미표시.

### 3) 제목 공백 트림

- `report_nm`류 제목 문자열 `.trim()`(연속 공백도 1칸으로 정규화). **표시 단계에서 처리**(원본 데이터·링크 파라미터 불변).

### 4) 같은 날·같은 제목 묶기 (중복 오해 제거)

- 목록에서 **같은 날짜 + 같은 (트림된) 제목**이 2건 이상이면 **한 행으로 묶고** 제목 옆에 `2건` 배지(muted·776 "외 N건" 문법과 같은 계열).
- 펼치면 **각 건의 요약을 순서대로 모두** 표시(각각 별도 fetch·건별 원문 링크 유지). **건수는 절대 줄이지 않음**(표시층 묶기만).

### 5) 적용 범위 = 6개국 전부

- KR(`KrEventLayer`/`KrFilingSummary`) · US(`EventLayer`/`AiFilingSummary`) · JP · CN · VN · GB — `StockLensClient.tsx` 내 동일 패턴 6벌.
- **가능하면 공용 컴포넌트로 추출**(행·토글·더보기·묶기 로직 공유, 국가별 차이는 props: 라벨 키·요약 API 경로·식별자 필드명·날짜 포맷). 추출이 위험하다고 판단되면 6벌 동일 수정 + 이유를 보고에 기재.
- 국가별 필드명이 다르므로(`rcept_no`/`accession`/`doc_id` 등) **각 국가의 실제 필드를 코드에서 확인 후 매핑**(추측 금지).
