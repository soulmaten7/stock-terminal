## 1. 할 일

### 1-1. 🔴 롤백 재료 확보 — 먼저
`lens_cuts` US 5행(`as_of=2026-07-30`)을 **문서에 원문 그대로 기록**한다: `market`·`lens_key`·`lo`·`hi`·`n`·`method`·`as_of`.
🔴 `lens_cuts`는 upsert라 갱신되면 07-30 값이 **사라진다.** 이 백업이 유일한 대조군이다.
🔴 `lens_scores` US 1,036행의 **7축 `*_state` 분포**도 기록한다(전이 대조용).

### 1-2. 게이트 산식 전환
`lib/lensPrecompute.ts`의 `capGateDecision`:
- 🔴 **상수를 명명 상수로**, 근거 주석과 함께:
  ```
  ABS_FLOOR  = 0.85  // 절대 하한. 서서히 나빠지는 것을 막는다(1025 §W2)
  DROP_LIMIT = 0.03  // 전일 대비 낙폭 상한. 832형 사고(98.6%→~0%)를 잡는다
  ```
- `coverageOk`를 **새 산식으로 교체**:
  `freshCoverage >= ABS_FLOOR && (priorCoverage == null || freshCoverage >= priorCoverage - DROP_LIMIT)`
- 🔴 `priorCoverage` 출처는 1025가 배선한 그대로(`us_coverage_history` → `cron_heartbeats` 폴백 → `null` 부트스트랩)
- 🔴 **`compositionOk`는 한 글자도 바꾸지 않는다**
- 🔴 1025가 넣은 관측 필드(`newCoverageOk`·`newCutGateOk` 등)는 **그대로 둔다** — 이제 `cutGateOk`와 같은 값이어야 하므로 **일치 여부가 자체 검증**이 된다

### 1-3. 🔴 프루닝 명시적 차단
`canPrune` 조건에 **차단을 추가**한다.
- 🔴 **방식은 되돌리기 쉬운 것으로** — 예: 명명 상수 `PRUNE_ENABLED = false`를 두고 `canPrune = PRUNE_ENABLED && (기존 조건)`
- 🔴 **기존 조건식을 지우지 않는다.** 다음 STEP에서 상수만 바꾸면 켜지도록
- heartbeat에 `pruneBlockedByFlag: true`를 실어 **차단이 실제로 걸렸는지 관측 가능**하게 한다

### 1-4. 833 테스트 — 보존 + 확장
