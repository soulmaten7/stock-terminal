## 2. 할 일

### 2-1. 매핑표 작성 — 🔴 근거는 `파일:줄번호`
9개 테이블 각각에 대해:

| DB 테이블 | 원본 파일 | 시트 | 헤더 행 | 사용 열 | 적재 코드 |
|---|---|---|---|---|---|

🔴 적재 코드 칸은 반드시 `scripts/xxx.ts:줄번호`. 추정 금지 — 못 찾으면 `확인불가`.

### 2-2. 행수 대조 — 🔴 차이는 전부 해명한다
원본 데이터 행수 vs DB 행수. **다르면 어느 행이 빠졌는지 이름으로 나열한다.**
🔴 **특히 `tax_rate` 96 vs `beta`/`capex`/`wacc`/`working_capital` 94의 2행 차이를 반드시 해명한다.** "총계/평균 행이 섞였나"가 첫 후보다.
🔴 **"대체로 맞다"는 판정으로 쓰지 않는다.**

### 2-3. 값 대조 — 전수
각 테이블의 전 행·전 수치 컬럼을 원본과 대조한다. 부동소수 비교는 **상대오차 1e-9** 기준.
불일치는 **전수 나열**: 테이블 · 키(업종명 등) · 컬럼 · 원본값 · DB값 · 상대차.

🔴 **특별히 볼 것**
- **백분율 표기**: 원본이 `21`인지 `0.21`인지. 🔴 세율·마진·성장률이 위험 구간이다
- **부호**: 운전자본률·자본지출률에 음수가 있는가. 원본과 부호가 같은가
- **날짜/시점**: 🔴 **1003의 Excel 1904 날짜체계 버그(1,462일 오차)와 같은 계열이 다른 파일에 없는가.** `ERPbymonth.xlsx` 외 날짜를 쓰는 파일 전부
- **업종명 정규화**: 원본 업종명 ↔ DB 키. 🔴 구두점·대소문자 정규화로 **서로 다른 업종이 합쳐진 건이 없는가**
- **`damodaran_industry` 48,144행**: 🔴 전수 비교가 무거우면 **업종×연도 축의 집계 지문**(행수·합계·min·max·null수)으로 전수 대조. **표본 추출 금지**

### 2-4. 버전 대조
각 엑셀의 **자기표기 시점**(파일 안의 "as of"/"Updated" 문구, 없으면 파일 mtime)과 DB의 `as_of`를 나란히 놓는다.
🔴 **원본이 DB보다 새로우면 "적재 정체"다.** #14·#15가 7개월 정체했던 것과 같은 계열이므로 반드시 표시.
🔴 **재적재를 실행하지 말 것.** 표시만 한다.
