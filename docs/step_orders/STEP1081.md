# STEP 1081 — 🟡 **23행의 「부족한 재료」를 갈라내고, 잴 수 있는 것을 잰다** (🔵 읽기 전용 · 코드 diff 0 · DB 쓰기 0 · 화면 변경 0 · 크론 수동 실행 0)

> 🔴 **판정하지 않는다. 선택지를 고르지 않는다. 순서·추천 금지.** 🟡를 🟢로 올릴 수 있는 것만 **재는 데까지**다.
>
> **왜 지금인가 — 3번 규칙(2026-08-19):**
> **축 A(원문)** — `BUILD_SEQUENCE.md` §6-C 대장이 각 🟡 행에 **무엇이 부족한지 스스로 적어뒀다**(예: *"전환 시 판정 바뀌는 종목 수 **미측정**"*, *"교체 시 실제로 판정이 몇 건 바뀌는지 **미측정**"*).
> **축 B(실무·실측)** — Cowork이 §6-C의 🟡 23행 문구를 전수 훑은 결과 **「미측정」류가 다수**다. 미측정은 **재면 풀린다** — 판정이 아니다.
> **축 C(반대 증거)** — ㉠🔴 **다 잴 수 있는 건 아니다** — *"선택지 미작성"*(놓는 문제) · *"대응 방안 자체가 탐색된 적 없음"*(탐색) · *"육안 검증 미실시"*(장은태만) · *"`STATE.md` 00-d 선행"*(종속)은 **재도 안 풀린다**. **먼저 갈라야 한다** ㉡**재려면 코드 실행이 필요한 것**이 있다(전환 후 판정 재계산 등) — 이 STEP은 **읽기 전용**이라 못 잰다. 그것도 갈라낸다 ㉢**이미 잰 것이 있다** — 다른 STEP·probe가 이미 측정했는데 대장이 못 받았을 수 있다(§8 #4 재조사 방지).

## §1. 1단계 — 🟡 23행을 **네 갈래로 가른다** (🔴 재기 전에 먼저)

| 갈래 | 뜻 | 이 STEP이 하는 일 |
|:--:|---|---|
| **㉠ 지금 잴 수 있음** | DB 조회·코드 읽기·git 이력으로 답이 나온다 | **§2에서 잰다** |
| **㉡ 코드 실행 필요** | 전환·교체 후 판정을 다시 계산해야 수가 나온다 | 🔴 **재지 않는다.** *"코드 실행 필요 — 이 STEP은 읽기 전용"*이라 대장에 명시 |
| **㉢ 재도 안 풀림** | 선택지 미작성 · 대응 방안 미탐색 · 육안 검증 · 다른 판정 종속 | 🔴 **재지 않는다.** 무엇이 필요한지 한 줄(예: *"선택지 작성 STEP 필요"*·*"장은태 육안 검증"*) |
| **㉣ 이미 잼** | 다른 STEP/probe가 이미 측정했는데 대장이 못 받음 | 🔴 **재지 않는다.** **좌표를 찾아 대장에 붙이고 🟢로 올린다** |

🔴 **㉣을 먼저 훑는다.** 재조사는 `BUILD_SEQUENCE §8 #4`에 등재된 반복 실수다. **재기 전에 "이미 있나"부터 본다.**
🔴 **23행이 4갈래로 전부 분류돼야 한다.** 분류 안 된 행 0개.

## §2. 2단계 — ㉠만 실측 (🔴 읽기 전용)

### §2-0. 🔴 묶어서 잰다
㉠ 항목 중 **같은 테이블·같은 조회로 함께 잴 수 있는 것**을 묶는다. 종목 단위 조회를 항목마다 따로 돌리지 않는다.

### §2-1. 측정 원칙
- 🔴 **모든 조회에 UTC 시각 병기.**
- 🔴 **분모를 반드시 명시**한다(전체 5,820인지 · 기준연도 보유 3,606인지 · 라이브 998인지 — `probe_1054`가 *"분모 주의 — 두 겹이다"*라 경고한 그대로).
- 🔴 **정방향+역방향 둘 다**로 재고, 다르면 **다르다고 쓴다**.
- 🔴 **잰 값만 쓴다.** 산술 추정은 *"산술이지 실측 아님"*이라 명시(대장의 933 항목이 이미 그 표기를 쓴다).

### §2-2. 못 잰 것
🔴 조회를 시도했는데 안 나오면 **"시도했으나 못 쟀다 + 사유"**라 쓴다. 🔴 **그럴듯한 수를 채우지 않는다.**

### §2-3. 🔴 상한
한 STEP에 23행을 다 못 재도 된다. **잰 것만 반영하고 나머지는 🟡로 남긴다** — 남긴 것은 §5 보고에 **전부 나열**한다.

## §3. 3단계 — 대장 반영

측정 결과를 §6-C 각 행의 **「지금 정할 수 있나」 칸**에 반영한다:
- 재서 답이 나온 행 → **🟢로 승격** + 측정값·좌표 병기
- ㉡·㉢ → 🟡 유지 + **갈래 표시**(`🟡㉡ 코드 실행 필요` / `🟡㉢ 선택지 작성 필요` 등)
- ㉣ → **🟢로 승격** + 이미 있던 측정 좌표

🔴 **「고르면 따라오는 것」 칸도 갱신**한다 — 측정으로 위험 크기가 드러났으면 거기 적는다.
🔴 **§6-C 머리의 집계(🟢/🟡/🔴 행 수)를 갱신**한다.
🔴 **옛 문구를 지우지 않는다** — 취소선 + 정정.
