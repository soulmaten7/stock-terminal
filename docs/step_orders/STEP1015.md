### 2-1. 항목 8개 전수 — 성립 조건을 코드에서 찾는다
`ANSWERABILITY_MAP.md` §2의 A~H 각각에 대해:

   - 🔴 API 라우트(`app/api/**`)와 화면 컴포넌트 **양쪽**을 본다. 판정이 어디에 있는지가 이 STEP의 답이다

### 2-2. 🔴 중복·불일치 검사
같은 값에 대한 판정이 **여러 곳에 있는가**. 있으면 그 조건들이 **서로 같은가**.
- 예: PER을 안 보여주는 조건이 API에도 있고 컴포넌트에도 있는데 서로 다르다면 → 🔴 **전수 나열하고 크게 보고**
- 🔴 "같을 것이다"로 넘어가지 말 것. 실제로 대조한다

### 2-3. 조건이 코드에 없는 항목
