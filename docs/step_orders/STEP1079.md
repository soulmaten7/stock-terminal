## §1. 판정 대장 신설 — `BUILD_SEQUENCE.md` §6 아래

🔴 **새 파일 금지.** `docs/BUILD_SEQUENCE.md`의 **§6-B-1 다음**에 `§6-C. 🔴 판정 대장 — 지금 장은태가 정해야 할 것 전수`를 만든다.

각 판정 한 행:

| 칸 | 채울 것 |
|---|---|
| **#** | 통번호(신규 부여) — 🔴 **원래 번호를 지우지 않고 「원 좌표」 칸에 남긴다** |
| **무엇을 정하나** | 🔴 **원문 문장 그대로**(요약 금지) |
| **원 좌표** | 파일:절 또는 파일:줄 (예: `LENS_DISPOSITION §7-4 #7`) |
| **선택지** | 원문에 있는 것만. 없으면 **"선택지 미작성"** |
| **지금 정할 수 있나** | 🟢 **가능**(재료 완비) / 🟡 **재료 일부 부족**(무엇이 부족한지 한 줄) / 🔴 **다른 판정에 종속**(어느 것에) |
| **고르면 따라오는 것** | 코드 diff 필요? 라이브 화면 영향? 별도 승인 필요? — 🔴 **실측된 것만.** 모르면 "미확인" |

🔴 **「지금 정할 수 있나」의 판단 근거는 원문이어야 한다.** 예: `BUILD_SEQUENCE` 부록-5가 *"재료가 더 필요한가 = 불필요"*라 적었으면 🟢. 원문에 그런 언급이 없으면 **"원문에 재료 상태 기록 없음"**이라 쓰고 🟡.

## §2. 종속 관계도 (🔴 순서 아님, 전제 관계만)

§6-C 아래에 **종속만** 적는다:
- `X → Y` = **X가 정해져야 Y를 정할 수 있다**
- 종속이 없으면 **「독립」**
- 🔴 **"먼저 하는 게 좋다"는 적지 않는다.** 독립 항목이 여럿이면 그냥 여럿이라 적는다.

이미 있는 근거를 그대로 쓴다: `BUILD_SEQUENCE` 부록-3 종속표(C~F) · §6-B-1 「다음에 필요한 것」 열 · `LENS_DISPOSITION §7-4`의 상호 참조.
