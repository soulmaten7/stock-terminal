## §1. ② 입력 검증 — 네 가지를 **수치로**

각 입력 필드마다:

| 재는 것 | 어떻게 | 🔴 규칙 |
|---|---|---|
| **출처** | 야후 어느 API/필드인지 · DB 어느 테이블·컬럼인지 — **코드 경로로 확정** | 🔴 "아마 야후" 금지. **코드 좌표**를 댄다 |
| **단위** | 비율인지 %인지 · 배당조정 여부 · 통화 | 🔴 `adjUsed` 혼재(결함#9)가 여기 걸린다 — **혼재 비율을 수치로** |
| **결측률** | non-null / 전체 | 🔴 **분모 명시**(라이브 998인지 · 유니버스 5,820인지) |
| **이상치** | 상·하위 극단 분포(p1·p99·max·min) | 🔴 극단 **상·하위 10건은 종목명까지** 적고 **육안으로 말이 되는지** 본다 |

🔴 **`adjUsed` 혼재는 반드시 수치로 낸다** — 결함#9의 실체이고, STEP1083이 노출은 했으나 *"혼재 자체는 남는다"*고 기록했다. **몇 종목이 raw이고 몇 종목이 adj인지.**
🔴 **잰 것만 쓴다.** 못 재면 **"시도했으나 못 쟀다 + 사유"**.
