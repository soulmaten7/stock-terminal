## ⓪ 전제 점검 — 🔴 명령서를 쓰기 전에 채운다. 비어 있으면 그 명령서는 미완성이다

> 이 절의 목적은 **틀린 사실 위에서 세 번 생각하는 일을 막는 것**이다.
> 읽기가 사실 오류를 막고, 3번 생각이 판단 오류를 막는다. **읽기가 먼저다.**
> 🔴 인용은 **필요한 줄만**. 문서를 통째로 붙이지 않는다(Claude Code 컨텍스트를 먹는다).

🔴 슬롯을 안 건드리는 STEP이면 `해당 없음`이라고 적고 넘어간다. 억지로 채우지 않는다.
