## §1. 마이그레이션 (🔴 7컬럼, 전부 nullable)

`supabase/migrations/` 에 **파일 하나** 신설. 내용은 #7-부록 §3의 초안 그대로:

```sql
ALTER TABLE lens_scores
  ADD COLUMN gross_profit numeric,
  ADD COLUMN total_assets numeric,
  ADD COLUMN total_assets_prior numeric,
  ADD COLUMN rsi14 numeric,
  ADD COLUMN pos52w numeric,
  ADD COLUMN fscore_reason_code text,
  ADD COLUMN adj_used boolean;
```

🔴 **주의**
- **`NOT NULL`·`DEFAULT`·인덱스를 붙이지 않는다**(기존 1,976행이 전부 null이어야 하고, 인덱스는 필요성이 확인된 적 없다).
- **다른 테이블·다른 컬럼을 건드리지 않는다.**
- 파일 상단 주석에 **롤백 SQL**(`ALTER TABLE lens_scores DROP COLUMN ...`)과 **근거 좌표**(`LENS_DISPOSITION §7-4 #7-부록`, STEP1085·1087)를 적는다.
- 🔴 **적용 방식은 이 저장소의 기존 마이그레이션 관행을 따른다** — `supabase/migrations/` 기존 파일들의 명명·적용 방식을 **먼저 보고 그대로** 한다. 새 방식 창작 금지.
