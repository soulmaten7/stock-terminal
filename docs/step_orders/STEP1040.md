## 1. 할 일 — 🔴 이 순서를 지킨다

### 1-1. 층 A — 무엇을 보여주는가 (재조사 없음)

각 항목에 **관문 ①②③ 통과 여부**(`ROADMAP_V2` F-4 인용)와 **우리 재료 상태**를 붙인다.

### 1-2. 🔑 층 B — 선행 의존 실측 (이 STEP의 핵심)

**판정 질문**: *"A를 모르는 채로 B를 계산하면 답이 얼마나 달라지는가."*

**방법 ① DB 실측** — 우리 데이터로 잴 수 있는 쌍은 전부 잰다. 최소 아래는 포함:
- **업종 → 배수**: 시장 전체 분포 대비 섹터 분포로 판정할 때 몇 %가 바뀌나 (🔴 기존 실측 33.0% 재확인 또는 갱신)
- **업종 → 재무건전성·수익성**: 같은 방식
- **이익 상태 → 배수**: 적자 종목에서 PER이 성립하지 않는 비율 (`us_valuation.unavailable` 사유 분포)
- **현재 값 → 변화**: 변화는 값의 차분이므로 논리적으로 선행 — 🔴 **자명한 것도 근거를 적는다**
- 그 밖에 잴 수 있는 쌍을 스스로 찾는다 (🔴 **위 목록은 하한이지 상한이 아니다**)

**방법 ② 논리·원전** — 각 모델의 **원전이 무엇을 전제로 정의했는가**. 예: Piotroski는 고B/M 집단 안에서의 도구 · Novy-Marx는 금융업 제외 · 배수는 이익 부호가 양수여야 성립.

🔴 **두 방법 결과를 나란히 놓고 어긋나는 곳을 표시한다.**

**출력**: **의존 표** — `A · B · 무시했을 때 변화율(%) · 실측/논리 · 근거 좌표 · 의존 강도`

### 1-3. 의존 그래프 → 순서 도출
1-2의 표에서 **방향 그래프**를 만들고 위상 정렬한다.
- 🔴 **순환이 나오면 순환이라고 적는다**(⓪-4 넷째)
- 🔴 **의존이 없는 항목끼리는 순서를 정하지 않는다** — 그건 수요나 표시 설계가 정할 몫이다. **억지로 줄 세우지 말 것**
- 결과를 **층**으로 표현한다(전제 / 그 위 / 그 위…)

### 1-4. Q0~Q5와 대조 — 🔴 도출 이후에만
1-3의 결과와 현재 Q0~Q5를 **나란히** 놓는다.
- 일치하는 것 / 순서가 다른 것 / 합쳐지는 것 / 어느 쪽에도 없는 것
- 🔴 **Q0~Q5를 기준으로 삼지 말고, 도출 결과를 기준으로 대조한다**

### 1-5. 층 C — 각 항목에 딸리는 것
Model Card 9섹션(`ROADMAP_V2` H-1-3) 중 **우리가 실제로 붙일 수 있는 것**을 고른다.

### 1-6. ①-B 실무 조사 — 최소 3곳
