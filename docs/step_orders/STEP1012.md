## 2. 할 일

### 2-1. 커버리지 실측 (Supabase `select`만, 새 네트워크 호출 0)
`us_sector_nasdaq.market_cap`과 오늘의 결측 집합을 조인한다.
- `us_market_cap`에서 `as_of`가 최신이 아닌 심볼(= 오늘 야후가 못 준 것) + `us_market_cap`에 아예 없는 심볼 = 결측 집합
- 그중 `us_sector_nasdaq.market_cap`이 **값이 있는 건수**
- 🔴 **1008 4분면과 교차**: 환경차이 284군 / 이중결측 86군 각각에서 몇 건을 덮는가. **두 군을 합쳐서 보고하지 말 것** — 성질이 다르다.
- 예상 커버리지 산출: `(5,601 + 덮는 건수) / 5,973`이 **97%를 넘는가**

### 2-2. 계열 차이 실측 — 🔴 전수
야후와 나스닥 **둘 다 값이 있는 종목 전수**에서 상대차를 낸다.
- 절대 상대차의 **중앙값 · p90 · p99**, `20% 초과 비율`
- 🔴 **시가총액 규모별로 쪼갠다**(≥100B / 10–100B / 2–10B / 0.3–2B / <0.3B). 1006이 대형주만 보고 틀렸다.
- 🔴 **날짜 주의**: 나스닥 값은 2026-08-08 스냅샷이고 야후는 오늘 값이다. **가격 변동이 섞인다.** 같은 기간 `us_stock_perf` 수익률로 보정한 값과 보정 안 한 값을 **둘 다** 낸다. 🔴 보정치를 정답으로 제시하지 말 것 — 보정 자체가 가정이다.
