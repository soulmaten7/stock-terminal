## 파트 A — `docs/LENS_COMPLETION_STANDARD.md`에 **§10 깊이 표준** 신설

렌즈가 "완성"이려면 기존 9항목에 더해 **아래 4축을 갖춘다.** 각 축은 **이미 보유한 데이터로 계산 가능해야 하며, 불가하면 그 사실을 명시**한다(축을 비워두는 것은 허용, 지어내는 것은 금지).

**① 구성요소 분해** — 최종 값이 **어떤 원자료에서 어떻게** 나왔는지. 가능하면 **항등식 분해**(예: A = B × C)로 "왜 이 값인지"가 읽히게. 🔴 최종값에서 역산 금지 — 원자료에서 각각 계산.
**② 시계열 추이** — 여러 회계연도/기간의 값. 🔴 연도 불연속·결측은 정직 표기(빈칸을 채우지 말 것).
**③ 분포 내 위치** — 백분위 숫자 하나가 아니라 **실제 분포에서의 위치**(컷 경계값·분위 요약 등 DB에서 계산). 🔴 하드코딩 금지.
**④ 판정 이력** — 이 종목·이 렌즈의 상태 변화 이력. 🔴 **종목 값이 변해서인지 시장 기준(컷)이 움직여서인지 구분**해 표기(806/808 이후 두 원인이 섞여 있다 — 구분 못 하면 이력을 제공하지 않는다).

각 축은 **정확성이 검증된 것만** 노출한다. 검증 방법은 기존 9항목과 동일(손계산·외부 대조).

## 파트 B — 퀄리티(GP/A)에 적용

### 패스 1 — 문헌

원전: **Novy-Marx (2013)**. 815에서 확정된 사실: 분자 = 매출 − 매출원가, **분모 = 같은 회계연도 기말 총자산(AT)**.

🔴 **이번에 원문으로 확인할 것**:
1. **분해에 대한 원전의 서술**: Novy-Marx가 총수익성을 **마진(GP/매출)과 자산회전율(매출/총자산)**로 나누어 논의하는지, 아니면 그 분해가 우리 표현인지. 🔑 원전에 없으면 **"항등식 분해(우리 표현)"**임을 밝히고, 논문 주장인 것처럼 쓰지 말 것.
2. **시계열 관점**: 원전이 GP/A의 **지속성·추세**를 다루는지(수익성의 persistence 논의가 있는지). 있으면 추이 제시의 근거가 되고, 없으면 "우리가 참고용으로 보여주는 것"으로 표기.
3. **후속 비판**(Ball 외 2015 분모 민감도)이 분해 표기와 충돌하지 않는지.

### 패스 2 — 구현

**① 구성요소 분해**
- `detail`에 **매출 · 매출원가 · 매출총이익 · 총자산**을 추가하고, **GP/A = 매출총이익률 × 자산회전율** 항등식을 제시.
- 🔴 세 값은 **각각 원자료에서** 계산(최종 GP/A에서 역산 금지). 항등식이 실제로 맞는지 **코드에서 검산**(부동소수 오차 허용범위 명시).
- 야후가 `grossProfit`을 직접 줄 때와 `revenue − COGS`로 계산할 때를 **구분해 표기**(어느 경로인지 데이터에 남길 것).
- 결측 시: 항목별로 정직하게 비움. 분해 불가면 분해 섹션 자체를 표시하지 않음.

**② 시계열 추이**
- 보유한 재무 rows(다년)로 **연도별 GP/A**를 계산. 각 연도는 **그 해 기말 총자산**을 분모로(815 정합).
- 🔴 **연도 불연속·결측 연도는 건너뛰지 말고 표시**(예: 2022·2024만 있으면 2023이 없다는 사실이 보이게).
- 몇 년치를 보여줄지는 데이터가 허용하는 범위에서 결정하고 근거 기재.

**③ 분포 내 위치**
- `lens_cuts`의 p30/p70과 `lens_scores`의 시장 전체 값에서 **분포 요약**(예: 최소·p30·중앙·p70·최대 또는 구간별 종목 수)을 계산해 제시.
- 🔴 DB에서 계산. 상수 금지. 시장별(KR/US) 분리. 표본 수(N)와 기준일 함께.
- 성능: 상세 페이지 요청마다 전 종목을 스캔하지 않도록 **집계 방식·캐시**를 설계하고 비용을 보고에 기재.

**④ 판정 이력**
- `lens_state_changes`에서 이 종목·퀄리티의 변화 이력을 조회.
- 🔴 **원인 구분이 핵심**: 같은 날 그 시장의 컷이 움직였는지(`lens_cuts.as_of`/값 이력)를 대조해 **"종목 값 변화"와 "기준선 이동"을 구분**한다. 구분 불가한 이력은 **표시하지 않는다**(잘못된 인과를 주지 말 것).
- 컷 이력이 남아 있지 않아 구분이 불가능하면 → **④는 이번에 구현하지 않고**, 무엇이 필요한지(예: `lens_cuts` 이력 테이블)를 보고에 남긴다. **억지로 만들지 말 것.**

**공통 — 화면 배치·게이트**
- 새 데이터는 **근거 상세** 성격이므로 기존 게이트 정책(판정·headline 무료 / 근거 상세는 로그인)과 **일관**되게. 예외를 두려면 근거 기재.
- 과밀 방지는 **말을 줄여서**가 아니라 **구조로**(접힘·표·정렬). 🔴 기존 scope·note를 임의로 삭제하지 말 것.
- `DETAIL_LABELS`에 신규 키 **ko/en 동시** 추가. 단위·소수 자릿수 명시.

### 패스 3 — 산출·외부 대조

- **손계산 vs API**: KR·US 각 2종목의 매출·매출원가·매출총이익·총자산·마진·회전율·GP/A를 **직접 계산**해 API 값과 소수점까지 대조.
- **외부 독립 출처 대조**: 위 원자료를 공개 재무 데이터와 대조(최소 KR·US 각 2종목). 🔴 `CLAUDE.md` 절대 규칙 — 훈련지식으로 판단 금지, 독립 출처 확인.
- **항등식 검산**: 마진 × 회전율 = GP/A가 전 종목에서 성립하는지 표본 검사(오차 허용범위 명시).
- **결측률 실측**: 구성요소별·연도별 결측 비율(KR·US 각각 %).
- **분포 요약 검증**: 계산된 분위값이 `lens_cuts`와 정합하는지.
- **화면 무모순**: 새 구성요소·추이가 기존 판정·scope·note와 어긋나지 않는지. 다른 렌즈 문구 불변.
