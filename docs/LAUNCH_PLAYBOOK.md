## 0. 대원칙 (순서를 관통하는 기준)
- **한 탭(한국)을 끝까지.** "완전성 = DoD 전 항목"(§COUNTRY_TAB_PLAYBOOK) — 축소 금지. 공개는 한국탭 하나를 완성해 먼저.
- **컴플라이언스·데이터신뢰 = 공개의 전제, "나중" 아님.** (SaaS 조사: 법적·신뢰 이슈가 초기 이탈 30% 유발.)
- **검증의 복리.** 문서화된 출시 프로세스 = 성공률 +45%, 베타 검증 = 치명버그 -60%. → 이 체크리스트를 실제로 하나씩 소진.
- **데이터는 정확+정직.** 실측값이 이상해도 내 지식으로 단정 말고 독립 검증(§LENS_DEV #28). 이상치 가드로 진짜 데이터 지우지 말 것.
- **포지셔닝이 곧 법적 방패.** "예언·추천 안 함, 재료만 제공"은 브랜드일 뿐 아니라 **유사투자자문 리스크를 낮추는 법적 포지션**(아래 §1-C).

## 1. 제작 → 공개 순서 (7단계 A→G)

### A. 한국탭 기능 완성 (Feature-complete)
DoD 전 항목이 실제 작동하는지 — "만들다 만 것" 0:
- 배관(데이터 파이프라인·스냅샷 크론) · 종목보드(코스피/코스닥) · 검색 · 미리보기(LensPreview) · TR-AI 렌즈 6종 · 관심종목 · ETF "상품 구성"/ETN "상품 정보" · 검증 탭(등록업체) · link_hub(정보 탭) · 지수바 · 매매처(brokers) · 모아보기 · 로그인(Google OAuth) · 모바일.
- **끝의 기준:** 새 기능 추가가 아니라 "빈 곳/깨진 동선 0". 여기서부터는 확장(타국) 금지, 한국탭 하드닝.

### B. 데이터 신뢰성·정확성 게이트
정보 플랫폼의 생명 = 값이 맞아야 함:
- 현재가·수익률(r1d~r1y) 실측이 **독립 소스와 일치**하는지 스팟체크(대형주 몇 개 검색 대조). 이상해 보여도 **가드로 지우지 말고** 독립 검증(§LENS_DEV #28).
- 스냅샷 크론 정상 동작(매일 갱신·`updated_at` 신선도) · as_of 날짜 시장 로컬화 · 결측 처리(신규상장 '—'는 정상).
- 공시·뉴스·지수 소스 살아있음(막힌 소스는 보류 원장 기록, 가짜로 안 채움).

### C. 법적·컴플라이언스 게이트 (KR) ★ 공개 전 반드시
> 순서상 **공개(F) 전에, 그리고 유료구독 켜기 전에** 통과해야 하는 관문.
- **유사투자자문 판단(가장 중요).** 조사 결과: ①**유료 구독(멤버십)으로 투자정보 대가를 받으면 → 유사투자자문업 신고 대상 가능성 높음.** ②광고수익만이면 신고 불필요. ③유료 1:1 상담은 정식 투자자문업(무거움). ④2024 개정으로 대가受 실시간 종목추천 '리딩방'은 불법. → **Trillion은 "추천 안 함·재료만"이라 조언성이 약해 회색지대.** 구독 켜기 전 금융위 규제민원/전문 변호사에 확정 질의. (무료 정보+광고로 먼저 공개 → 구독은 확인 후.)
- **사업자·전자상거래법 표기:** 상호(원트릴리언)·대표·사업자번호(210-39-33812)·주소·연락처·통신판매업신고번호를 푸터/약관에 표기.
- **이용약관 + 개인정보처리방침**(로그인·OAuth 있으니 필수). 2026.4.24 개정 지침 반영(생성형 AI 부록 등).
- **면책 문구**(투자정보 사이트 필수): "정보 제공 목적, 투자자문·매수매도 추천 아님, 정확성 보장 안 함, 투자 판단·책임은 본인, 광고 포함 가능."
- **광고표시(표시광고법):** Sponsored/제휴는 "○○의 유료광고 포함"처럼 **명확·근접 표기**. 평가↔광고 분리(브랜드 원칙과 일치). 2026.1 **AI 생성물 표시제** — AI 생성 이미지/카피 쓰면 표시.

### D. 검수(QA) — §2 체크리스트 전수
아래 §2를 **하나씩** 소진. 통과 못 하면 공개 게이트 닫힘.

### E. 비공개 베타 (Closed beta, 20~50명)
- 실사용자 20~50명(지인·타깃)에게 제한 공개 → 치명버그·혼란 동선 수집(조사: 치명버그 -60%).
- 온보딩 "첫 이해(aha)"까지 2분 내 도달하는지 관찰.

### F. 소프트 런치 → 정식 공개
- 소프트: 검색 노출/입소문 최소로 열고 실트래픽에서 성능·에러 모니터. 문제 없으면 정식 공개(홍보 시작).
- 공개 당일: 대시보드 15분 간격 모니터(에러·다운·이탈), 문의 1시간 내 응답.

### G. 공개 후 (모니터링·수익화 활성화)
- 30일 활성화율 40%+ 목표. 리텐션 > 가입수.
- **여기서** 구독(법적 확인 완료 후)·광고문의 슬롯 활성화. 그다음 타국 탭 확장.

## 2. 공개 전 검수 체크리스트 (하나씩 ☑)

### 2-1. 기능 (Functional)
- [ ] 종목보드: 정렬(거래대금/등락/기간)·검색·페이지네이션·상한/하한 표시 정상

- [ ] TR-AI 렌즈 6종 + 근거 수치 + 정직 문구 표시
- [ ] ETF "상품 구성"·ETN "상품 정보"·종목 렌즈 분기 정확

## 3. 단계적 공개(rollout) 게이트
| 단계 | 공개 범위 | 통과 기준 |
|---|---|---|
| 비공개 베타 | 20~50명 | 치명버그 0 · aha 2분 내 · 핵심 동선 완주 |
| 소프트 런치 | 제한 공개(무홍보) | 실트래픽 에러율 낮음 · 성능 안정 · 데이터 신선 |
| 정식 공개 | 전체+홍보 | §2 전 항목 ☑ · 법적 게이트 통과 · 모니터링 가동 |
| 수익화 | 구독/광고 | 유사투자자문 확정 · 결제 컴플라이언스 · Sponsored 표기 |

## 4. 이 프로젝트 특이 주의
- **Supabase RLS + service-role**: 정보 노출/권한이 가장 큰 보안 리스크. 공개 전 정책 전수 점검.
- **데이터 정직**: §LENS_DEV #28 — 실측 이상치를 지식으로 단정 금지, 독립 검증. 가드로 진짜 데이터 삭제 금지.
- **"추천 안 함" 포지셔닝 유지**가 유사투자자문 회색지대에서 유리 → 카피에서 "신호/추천/매수" 단정 표현 금지, "재료·해석"으로.
- **무료 먼저, 구독 나중**: 무료 정보+광고로 공개해 트래픽 확보 → 유사투자자문 확정 후 구독 개시가 안전한 순서.
