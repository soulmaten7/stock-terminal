## 1. 운종(雲從) 한 줄 정의

> **"한국 주식 동선의 출발점 — 정보·대화·허브·신뢰 4박자 플랫폼"**

雲從 = 구름처럼 사람이 모여드는 곳 (조선 한양 운종가에서 차용).

거래는 안 한다. 정보를 정확히 보여주고, 그 정보를 가지고 대화하고, 다른 플랫폼으로 연결하는 **허브** 역할.

---

## 2. 핵심 정체성 — 5가지

| 영역 | 운종이 하는 일 |
|------|-------------|
| **정보** | 한국 주식 시장 데이터를 매매 스타일별로 큐레이션 |
| **대화** | 단타·장타·미국주식 3창 분리 실시간 채팅 |
| **허브** | 모든 한국 주식 사이트·도구 출발점 (참고 사이트 + 사이트 모아보기) |
| **수익** | Partner-Agnostic Lead Gen (광고·계좌 개설·강의 등) |
| **신뢰** | 인증 시스템 3 Tier (사기·작전·리딩방 차단) |

## 3. 라이브스코어 톤 — 비율 정의

| 영역 | 비율 | 역할 |
|------|------|------|

정보가 주인공, 채팅은 반응. 채팅이 메인을 압도하지 않음.

## 4. 3창 구조 — 매매 스타일별 페이지 분리

### 4-1. 본질
같은 종목이라도 단타꾼·장투꾼·미장꾼이 보는 데이터가 완전히 다름. 한 화면에 다 깔면 누구도 만족 못 함. **사전 설정된 "데스크" 3개** 를 제공.

### 4-2. 라우트

```
unjong.com/scalper    → 단타창 (장중 09:00~15:30)
unjong.com/longterm   → 장타창 (저녁·주말)
unjong.com/us         → 미국주식창 (새벽 22:30~05:00)
```

루트 `/` 는 1차로 단타창 자동 리다이렉트 (인구 최대), 2차로 사용자 성향 선택 기억.

### 4-3. Layout 구조 (Next.js App Router)

```
app/
├── (creek)/                     # 라우트 그룹 (URL 영향 X)
│   ├── layout.tsx              # 헤더 + 좌측 사이드 + 우측 패널 (고정)
│   ├── scalper/page.tsx        # 단타창 메인 카드
│   ├── longterm/page.tsx       # 장타창 메인 카드
│   └── us/page.tsx             # 미국주식창 메인 카드
├── dashboard/page.tsx          # V3 5섹션 (강등)
├── calendar/page.tsx           # EconCalendar (보조)
├── screener/page.tsx           # Screener (보조)
└── page.tsx                    # 루트 / (단타창 리다이렉트)
```

## 5. 화면 구조 — 4영역

### 5-1. 상단 헤더 (고정)

```
┌─────────────────────────────────────────────────────────┐
│ 운종(雲從) | 통합검색 | 글로벌지수 티커 | 📚사이트 | 알림 │
├─────────────────────────────────────────────────────────┤
│ [단타창 ●]  [장타창]  [미국주식창]                       │
└─────────────────────────────────────────────────────────┘
```

- 운종 로고 (좌)
- 통합 검색창 — Layer 5 에서 모든 출처 통합 검색
- 글로벌 지수 티커 바 — KOSPI/KOSDAQ/S&P/Nasdaq/USD-KRW 슬라이드
- 📚 사이트 모아보기 (Layer 2)
- 알림 + 프로필
- **3창 카드 박스** — 현재 활성 강조, 클릭 시 페이지 라우트 변경

### 5-2. 좌측 사이드 (폭 300px, 고정)

```
┌─ 좌측 사이드 ───────────┐
│  [💬 단타창 채팅]       │  ← 헤더 (창별 자동 변경)
│  ─────────────────      │
│                         │
│  채팅 메인 영역          │
│  (고정 크기, 스크롤)     │
│                         │  60% 비율
│  트레이더A: ...         │
│  트레이더B: ...         │
│  ...                    │
│  ─────────────────      │
│  [✏️ 메시지 입력]       │  10% 비율 (고정)
│  ─────────────────      │
│  [👀 관심종목 12개]     │  ← 헤더
│  005930  +1.2% ▲       │
│  000660  -0.5% ▼       │  30% 비율 (가변 스크롤)
│  035720  +3.4% ▲▲      │
│  ...                    │
└─────────────────────────┘
```

- 채팅창 = 위, 관심종목 = 아래
- 채팅창 크기 고정, 스크롤로 보기
- 입력창 고정 크기 (확장 없음)
- 관심종목은 사용자별 가변 (스크롤)
- 3창 전환 시 채팅창 내용만 자동 변경 (위치는 그대로)

## 7. 인증 시스템 — 3 Tier (Layer 3)

### Tier 1 — 공식 라이선스
- 🏛️ 금융위 인증 (증권사·은행·자산운용사)
- 자동 인증 (라이선스 번호 검증)

### Tier 2 — 운종 검증
- ▶️ 유튜브 인증 (구독자 10만+ / 운영 1년+)
- 📱 운종 검증 (텔레그램방 운영 1년+ / 신고 0)
- 👨‍💼 전문가 인증 (자격증 · 증권사 경력)
- 📚 강의 인증 (클래스101 평점 4.5+)
- 수동 검증 (24~48시간)

### Tier 3 — 인증 없음
- 시각적 회색 + "AD" 라벨
- 단가 ↓

### 사후 모니터링
- 사용자 신고 5건 누적 → 자동 일시 정지
- 운영진 검토 → 인증 박탈 또는 복원
- 사기 확인 → 영구 차단 + 블랙리스트
