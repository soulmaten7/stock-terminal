🔴 **모르면 모른다고 보고.**

## §1 — 🔴 컷 이력 테이블 (831 ④의 전제조건)

- `lens_cuts`는 `(market, lens_key)` 1행 **덮어쓰기**라 어제 컷이 없다 → 원인 분해가 원천적으로 불가능하다.
- **append-only 이력 테이블 신설**(예: `lens_cuts_history(market, lens_key, as_of, lo, hi, n, method, created_at)` · PK `(market, lens_key, as_of)`).
- 크론 pass2가 컷을 유도할 때 **이력에 append**(기존 `lens_cuts` 덮어쓰기는 유지 — 읽기 경로 무영향).
- **RLS·권한**: 다른 공개 데이터 테이블과 동일 정책(812·829 전례 — RLS on · anon/authenticated revoke). 🔴 새 테이블을 열어두지 말 것.
- 보존 기간·행 증가량을 실측 근거와 함께 기재(시장 2 × 렌즈 5 × 일 1 = 소량).

## §2 — 🔴 변화 원인 분해 (핵심)

diff 계산 시 **두 판정을 비교**해 원인을 가른다:

- **값 변화**: `상태(오늘값, 어제컷) ≠ 상태(어제값, 어제컷)`
- **기준선 이동**: `상태(오늘값, 오늘컷) ≠ 상태(오늘값, 어제컷)`
- 둘 다 참이면 **복합** — 단정하지 말고 복합으로 표기.

구현:

1. `lens_state_changes`에 **원인 컬럼** 추가(예: `cause`). 값 집합은 위 분해 + §3의 재료 변경 + 미상. 🔴 `null`을 "값 변화"로 간주하지 말 것(기존 행은 미상이다).
2. 어제 컷은 §1 이력에서 가져온다. 어제 컷이 **없으면**(이력 시작 전·결측) 원인은 **미상**이며, 미상은 화면에 **오늘의 변화로 내보내지 않는다**.
3. 🔴 **테스트로 잠글 것**(값 잠금·스냅샷 금지): 값만 바뀐 케이스 / 컷만 움직인 케이스 / 둘 다인 케이스를 각각 만들어 `cause`가 정확히 나오는지.

## §3 — 🔴 재료 변경 감지 (836형 사고 재발 방지)

836의 원인은 **야후 심볼 해석이 `.KS` → `.KQ`로 바뀐 것**이었다. 즉 같은 종목·같은 컷인데 **입력 계열이 교체**됐다.

- 836 §1에서 "어느 경로로 해석됐는지 남긴다"고 했으므로, **해석된 심볼(`resolved`)을 종목별로 보존**한다(이미 저장돼 있으면 그것을 쓰고, 없으면 저장 경로를 만든다).
- diff 시 **전 실행의 해석 심볼과 다르면** 그 종목의 변화는 `cause = 재료 변경`으로 태깅하고 **화면 제외**.
- 🔑 같은 아이디어를 **다른 입력 교체**에도 적용할 수 있는지 검토해 보고(예: PER 산출 기준 `peBasis`가 ttm↔annual로 바뀐 경우 — 809에서 만든 플래그가 이미 있다). 🔴 이번에 다 구현하려 하지 말고, **적용 가능 목록과 근거만** 보고할 것(한 번에 하나).

## §4 — 🔴 소급 정리: 07-30 KR 73건

- **원인 구분 불가**(컷 이력이 그날 없었고, 82% 코스닥 편중이 재료 정정을 가리킨다) → **화면에서 제외**한다.
- 방법: `cause`를 **미상 또는 재료 변경**으로 소급 태깅(삭제보다 태깅 우선 — 감사 가능성 보존). 🔴 **날짜 하드코딩 금지** — "그날 코스닥 편중" 같은 데이터 조건으로 판정하거나, 일회성 마이그레이션 SQL로 처리하고 **그 사실을 문서에 남긴다**(코드에 예외를 남기지 말 것).
- 🔑 **833의 US 07-30 스킵과 일관**한지 확인(그날은 아예 기록하지 않았다 → 소급 대상 없음).
- 정리 후 **오늘 화면 KR 변화 섹션이 어떻게 보이는지** 실제로 확인해 보고(빈 상태 처리가 정상인지 — 빈 화면 문구가 있는지).

## §5 — 🟠 화면: 원인을 어떻게 말할까

- **기본**: 오늘 화면 변화 섹션은 **값 변화**(+복합 중 값 요인 포함 여부는 택1하고 근거 기재)만 보여준다.
- **기준선 이동**은 숨기지 말고 **다르게 말한다** — 예: 시장 기준선이 움직여 판정이 바뀐 종목이 있다는 사실을 별도로(또는 종목 카드 안에서). 🔴 **말을 늘리지 말 것**(과밀 금지). 문구는 짧고 정확하게, ko/en 동시.
- 🔴 **기존 렌즈 note·scope·readings 삭제·수정 금지**(7렌즈 정합 유지).
- 작업 단위 = **주장**: 전수 grep(`lensCopy.ts`·`messages/{ko,en}.json`·컴포넌트·이메일 브리핑·daily-brief 프롬프트) → 정합 → **재grep 잔존 0**.
