## §2 — NOPAT<0 수학적 귀결

- 터미널 = `NOPAT×(1+i)/(WACC−i)`. WACC>i>0이므로 분모 양수 → **NOPAT<0이면 터미널 음수**. 실측: year0 잔여가치<0 = **39/78사**.
- 결과는 둘로 갈림: ① **monotonic down**(성장할수록 주당가치↓) → `value_destroying` 63사 ② **monotonic up이나 25년 주당가치 < 주가**(주가가 양수인데 25년치 가치가 음수/미미) → `25+` 15사.
- i=0(B)으로 바꿔도 터미널은 여전히 `NOPAT/WACC`(NOPAT<0이면 음수) → **부호·귀결 불변** → A=B.
- **어느 경우도 finite GAP(years) 불가**: 적자면 주당가치 경로가 주가를 아래에서 위로 가로지르지 못한다(음수 터미널이 눌러서).
