# 렌즈 완성 기준 (Definition of Done) + 3중 검증 규칙

> **왜**: 7렌즈를 한꺼번에 만든 결과 열 라운드에 걸쳐 전부에서 결함이 드러났다(RSI Cutler 오귀속·저변동 BAB 이름불일치·컷 전부 미국상수·F-스코어 은행 단정·GP/A 분모 상이). **새 렌즈 전에 기존 7개를 하나씩 완결**하고, 그 전에 "완성"의 정의를 세운다.
> **최우선 기준(장은태)**: **원전 대조.** "이런 방식이야"가 아니라 **"논문 원문 방식을 차용했다"**고 쓸 수 있을 만큼 정확 + **우리가 어디서 벗어났는지까지** 공개. 우리는 새 기법을 만드는 게 아니라 **이미 존재하지만 전문가의 말로만 듣던 것을 직접 보게** 하는 제품이다.

## 🔴 3중 검증 규칙 (렌즈마다 순서대로 · 하나로 대체 불가)

- **패스 1 (문헌)**: 논문 원문 기준 정의 확정. 2차 자료·요약 대체 금지 — 원문 또는 원문 직접 인용 자료.
- **패스 2 (구현)**: 코드가 패스1 정의를 구현했는지 **줄 단위** 대조 + **손계산 재현**(소수점까지).
- **패스 3 (산출)**: 실데이터 값이 **외부 독립 출처**와 맞는지 + **화면 문구**가 패스1·2와 무모순인지.
- 🔴 **불일치를 하나라도 고치면 세 패스를 처음부터 다시.** (수정이 다른 패스 전제를 흔든다.) 단 **순수 문구 정정(계산 무변경)**이면 패스1·2 결과는 유지되고 패스3 화면 일관성만 재확인 — 그 사실을 보고에 명시.
- 🔴 **모르면 모른다고 보고.** 확인 못 한 항목을 "정상"으로 적지 말 것.
- 🔴 현재·과거 시세·수익률은 **훈련지식 판단 금지** — 반드시 `WebSearch` 독립 출처(CLAUDE.md 절대규칙).

## 완성 9항목 (전부 통과해야 "완성")

1. **원전 대조표**(최우선) — 5칸 표(항목·논문 정의·우리 구현·차이·차이의 영향). 항목: 계산식·관측기간·분자/분모 시점·스킵 규칙·수익률 정의(총수익 여부)·모집단·분위 수·리밸런싱/보유기간·데이터 출처·검증된 기간·시장. 차이 전부 기록(없으면 "동일"). 이 "차이" 열 = 화면 §1 블록과 일치.
2. **입력 검증** — 필드 출처·단위·결측률·이상치를 **수치로** 실측.
3. **값 검증** — 손계산 + **외부 독립 출처** 대조(최소 3종목·자릿수 아니라 값). 차이 나면 원인 규명.
4. **컷·분포** — 시장별 유도 여부·표본 수·방향 부호(고정값이면 근거).
5. **경계 처리** — 계산 불가 조건·최소 표본·결측 표기.
6. **주장 정합** — 검증 범위·실패 모드·적용 조건이 §1 표와 무모순.
7. **화면 일관성** — 카드·목록·변화 피드·이메일·브리핑에서 같은 이름·판정·단위.
8. **테스트** — 참조값 유닛테스트 + 경계 케이스(스냅샷 금지·값 검증).
9. **라이브 실측** — KR·US 각 2종목.
