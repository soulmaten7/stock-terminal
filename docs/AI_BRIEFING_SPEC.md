# AI 브리핑 레이어 스펙 (R1~R3) — LLM = "글 읽어 사실로", 절대 예측 아님

> **이 문서 = 종목 페이지 위에 얹는 LLM 브리핑 레이어의 단일 기준.** 결정론 7렌즈·이벤트 층 위에, LLM이 **비정형 텍스트(공시 원문·뉴스)를 읽어 사실로 요약**하는 층. 가드레일 = `AI_LENS_SPEC.md §1` 계승(예측·권유 절대 금지).
> 관련: `EVENT_LAYER_SPEC.md`(8-K 이벤트 결정론 분류) · `LENS_DISPLAY_CHARTER.md`(카드 표시) · `BUSINESS_STRATEGY.md` 2026-07-06 결정 로그(접근/수익 모델).

## 0. LLM 경계 (제일 중요)

- **LLM은 딱 한 가지에만** — **비정형 텍스트를 읽고 이해**(공시 원문·뉴스). 그 외 전부 결정론 유지(렌즈·퍼센타일·이벤트 분류=수학·규칙).
- **LLM은 절대**: 점수 매기기·예측·"사라/사지마라"·종합 판정. → 이건 우리가 폐기한 "AI가 결론 내려주기"(TRAI 스텁 제거·2026-07-04).
- **뉴스 감성도 점수화 안 함**(아래 §6 리서치 결론). 뉴스 = 사실 요약 + 중립 토픽 태그(강세/약세 칩 아님).
- 한 줄: **"적절한 단어를 고른 원어민 전문가"가 사실을 읽어 나르되, 결론은 영원히 사용자 몫.**

## 1. R1~R4 정의

| 단 | 이름 | 하는 일 | 지금 build로? |
|---|---|---|---|
| **R1** | 공시 원문 요약 | 8-K/공시 원문 읽고 한국어 **사실** 2~3줄 + 원문 링크 | ✅ 배관 다 있음(호출·캐시·원문 URL) |
| **R2** | 종목 브리핑 | 렌즈+플래그+R1 → 1문단(**핵심 긴장 + 지켜볼 것**, 판정 아님) | R1 위에 · 소스 무관 공통 |
| **R3** | 뉴스 요약·토픽 | 중대 뉴스 있을 때만 요약 + 토픽 태그 | 국가별 뉴스 소스 필요 · 셋 중 가장 얇게 |
| **R4** | 자연어 Q&A(물어보기) | "이 종목 왜?" 대화 | 🚫 **영구 보류 · 미래 자산**(2026-07-06 결정, 아래 註) |

- **R2 브리핑 = 최고 애널리스트식 프레이밍**: "답"이 아니라 **"핵심 긴장(시간축/렌즈 엇갈림) + 관찰할 촉매"**. 예) "단기 과열 ↔ 중기·장기 강함 — 지켜볼 것: 과열 해소·다음 실적". **"그래서 오른다/내린다"는 절대 안 감**(가드레일 프롬프트에 명시).

- 🚫 **R4 보류 결정 (2026-07-06)**: R4(Q&A)는 사실상 "질문하면 답하는 어드바이저"에 가까워 **우리 포지셔닝(정보 허브 · "안 속게 돕는 곳")의 영역이 아님**. 유저별 무제한 LLM 비용·환각 위험도 큼. 무엇보다 이런 대화형 자문을 붙이면 **지금 서비스를 무료로 제공하는 논리와 상충**. → 만들지 않음. 기술적으로 "이렇게 가능하다"는 **미래 자산·의견제시용**으로만 남기고, 사업이 완성형이 된 뒤 재논의. (R1~R3 = 무료·공개 · SEO 엔진, 여기까지가 우리 AI 층의 완결 범위.)

## 4. 접근·비용 모델 (요약 — 상세는 BUSINESS_STRATEGY 2026-07-06)

- **AI 브리핑(R1~R3) = 완전 무료 + 공개**(로그인 불필요). 이유: ① 사실을 파는 건 정체성 위반 ② **공개라야 SEO·글로벌 트래픽** ③ 최고의 무료 유입 훅.
- **구독(Pro) 없음.** 수익 = 광고·디렉토리·브로커 제휴(트래픽 뒤·저거부감부터·배너 맨끝).
- **로그인 게이트 = 콘텐츠가 아니라 개인화**(즐겨찾기·알림). 콘텐츠 숨기면 SEO 죽음.
- **비용 형태**: 지연 생성(유저가 볼 때만)+캐시 = 수요에 묶여 저렴(공시당/종목당 1회·전역 공유). 전 종목 선행 생성(스크리너·다이제스트)만 비용 몰림 → 나중·선택.
- 모델 = `gpt-4o-mini`(기존 키·공시 1건 몇 원·캐시).

## 5. UI 구조 (v2 시안 확정)

위→아래: ① **가격 앵커**(실시간) → ② **R2 브리핑**(핵심 긴장+지켜볼 것·생성시각) → ③ 시간축 스트립(단기/중기/장기) → ④ **렌즈 한 줄 그림**(성장·품질 강·밸류 비쌈 = 엇갈림 합성) + 렌즈 행(판정·퍼센타일·신뢰도 등급) → ⑤ **중대 공시**(R1 요약 + **→ 렌즈 근거 갱신 인과선** · 루틴 공시는 한 줄로 눌러 경중 분리) → ⑥ 뉴스(R3·토픽 태그) → (⑦ 나중: 스케일 기능).
- **시각 규칙 하나**: 틴트(민트) 배경 = AI 생성 / 흰 카드 = 결정론 계산. 사용자가 항상 구분.
- **3개의 시계 노출**: 가격=실시간·렌즈=매일·공시=즉시·브리핑=생성시각. 층마다 "언제 기준" 표기 = 신뢰.

## 6. 리서치 결론 (이번 세션 · 왜 이 형태인가)

- **뉴스 감성을 "팩터 점수"로 만들지 않음** — 3라운드 리서치: 대형주(우리 유니버스)엔 예측력 약·이미 반영·거래비용 후 소멸, Loughran-McDonald 사전은 **상업 라이선스 유료**, 점수화=가짜 정밀도. FinBERT/LM은 오픈이나 **팩터로는 불필요**. → 뉴스 = R1~R3 **사실 브리핑**으로만(TipRanks가 감성을 8분의 1로만 쓰는 이유). ※ 2026-07-04 "FinBERT 감성 렌즈" 구상을 이 방향(점수화 안 함)으로 **정직하게 정정**.
- **"더 신선한 렌즈" 정답 = 추정치 변경(estimate revisions)** — 뉴스 감성 아님. 3라운드+라이브 실측: Yahoo `eps_trend`(7/30/60/90일 전 추정치)+`eps_revisions`(상향/하향 수)로 **라이브 신호 무료 확보**(삼성·도요타 대형주도 커버·애널 수 게이팅 필요). 단 **백테스트 이력은 유료(I/B/E/S)** → 자체 "검증" 불가 → **"참고용"으로만 가능 + 스냅샷으로 검증 예약**. **지금은 보류**(AI R1~R3 완성 우선).
