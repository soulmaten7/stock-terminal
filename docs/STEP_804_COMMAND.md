## 수정

### 1) 🔴 결측을 0으로 날조

- `app/api/yahoo/us-list/route.ts` 등에서 `changePercent: p.r1d ?? 0`, `amount: p.amount ?? 0`. DB가 NULL이면 **"+0.00%(보합)"**이라는 확정 정보로 둔갑하고, 거래대금 정렬 순위도 왜곡된다.
- 조치: **`?? 0` 제거 → null 유지**. 표시층은 이미 null을 `—`로 처리한다. 정렬은 null을 뒤로 보내되 "값 없음"임이 드러나게.
- 🔴 같은 패턴(`?? 0`)을 **전 라우트·lib에서 grep 전수**해 수치 필드에 대한 0 폴백을 제거(카운트 등 0이 의미 있는 곳은 유지 — 판단 후 보고).

### 2) 🔴 데이터 나이가 사용자에게 전달되지 않음

- `updated_at`·`bas_dd`는 DB에 있는데 서빙 라우트가 응답에 싣지 않는다. 크론이 멈추면 옛 값이 현재값으로 보인다.
- 조치: 가격·등락률·거래대금을 서빙하는 라우트(`krx/ranking`·`watchlist/quotes`·`explore/lens-top` 등)가 **데이터 기준일을 응답에 포함**하고, 화면이 기존 `AsOfBadge` 문법으로 표시. **오늘 데이터면 배지 생략**(현행 규칙 유지).

### 3) 🔴 `AsOfBadge`가 KST 오전에 사라짐

- 배지 조건이 `date === todayUtcDate()`인데 `change_date`는 크론 실행 시각의 UTC 날짜다. **KST 00:00~09:00 구간에는 UTC 날짜가 KST보다 하루 뒤처져** 어제 데이터가 "오늘"로 판정돼 배지가 숨는다. 한국 사용자의 아침 출근 시간대가 정확히 여기다.
- 조치: **시장 로컬 타임존 기준**으로 비교(`lib/marketDate.ts`에 이미 유틸이 있는데 이 화면들이 안 씀). 요일 표기(`{요일} 기준`)도 같은 기준으로.

### 4) 실패를 "없음"으로 말하는 잔여 4곳

797에서 공시만 고쳤다. 남은 곳:
- **관심목록**(`WatchlistClient`) — 조회 실패 시 "관심종목이 비어있습니다" + 추가 유도. 등록 종목이 있는데도.
- **오늘 관심 섹션**(`TodayClient`) — 실패를 `?? []`로 흡수 → 온보딩 카드가 등록 사용자에게 노출.
- **탐색 목록**(`ExploreClient`) — 실패 시 섹션 제목만 남고 본문이 빈 공백(에러 문구·스켈레톤 없음). 빈 응답과 실패도 구분 못 함.
- **ETF 구성**(`EtfLensClient`) — `'error'` 상태를 만들어놓고 렌더하지 않아 "구성 정보 없음"으로 표시.
- 조치: 각각 **실패 / 없음**을 구분해 표시(797에서 만든 문법 재사용).

### 5) 토글이 서버 실패를 롤백하지 않음

- `StockLensClient`·`EtfLensClient`의 관심 별이 `.catch`만 걸어둠 → `fetch`는 401/500에 reject하지 않으므로 **거짓 성공 상태**로 남는다(새로고침하면 사라짐). 같은 기능 5벌 중 2벌만 구멍.
- 관심 해제(X)도 `res.ok` 미검사 + 롤백 없음 → "지웠는데 살아있다".
- 이메일 브리핑 토글은 **조회 실패 시 OFF로 위장**(구독 중인데 해지한 줄 앎) + 실패 안내 없음.
- 조치: 전부 `res.ok` 검사 → 실패 시 상태 롤백 + 사용자에게 알림. 연타 방지(in-flight 가드).

### 6) 하이드레이션 중 로그인 사용자가 튕김

- `isLoading`을 안 보는 곳들: 모바일 '마이' 탭(href가 로그인으로 고정), 렌즈 게이트(펼치면 로그인 안내가 번쩍), 별 클릭 시 로그인 페이지 이동.
- 조치: 게이트·리다이렉트 조건을 **`!authLoading && !user`**로. 로그인 페이지에 **이미 로그인한 사용자 가드** 추가.

### 7) 시장 상태 동기화

- 홈은 로케일로만 시장이 정해지고(사용자가 바꿀 수단 없음), 탐색은 `?market=`·localStorage로 정해져 **두 화면이 서로 다른 시장**을 보여준다.
- 탐색 시장 토글이 **URL을 갱신하지 않아** 새로고침·공유 링크에서 되돌아간다.
- 조치: 시장 상태를 **단일 소스**로(URL 우선 + 저장은 보조). 홈·탐색이 같은 값을 쓰게. 토글 시 URL 갱신.

### 8) 톤 필터 칩 숫자 vs 실제 행 수

- 칩은 **전체 카운트**(예 137), 목록은 `limit=50` + 종목 묶기 후라 12행만 보인다.
- 조치: **표시 기준을 일치**시키거나("상위 50건 중" 명시) 서버 필터로 실제 해당 건을 가져오기. 택1하고 근거 기재.
