# 📱 Trillion 모바일 빌드 마스터 플랜 (STEP 377~380)

> **목적**: PC로 완성된 Trillion을 **375px 모바일**에서 제대로 동작·보기 좋게. 데스크탑 회귀 절대 금지(반응형 변형만 **추가**).
> **실행**: Claude Code(Sonnet)가 아래 STEP 파일을 **순서대로** 읽고 밤새 적용. 각 STEP = 빌드 통과 → 커밋. 시각 확인은 아침에 실제 폰에서(사용자) + Cowork과 미세조정.

## 📐 핵심 원칙 (모든 STEP 공통 — Sonnet 필독)

1. **Mobile-first**: 기본 클래스 = 모바일 상태. `sm:`(≥640)·`lg:`(≥1024)로 데스크탑 복원.
2. **데스크탑 클래스 삭제 금지**: 기존 클래스는 두고 `sm:`/`lg:` 변형만 **추가**하거나, `px-6` → `px-4 sm:px-6`처럼 모바일 기본 + 데스크탑 복원 형태로만 바꿈.
3. **가로 오버플로 금지**: 고정 픽셀 폭(`w-72`·`w-96`)은 반드시 `lg:`에서만(모바일에선 숨김/풀폭). 넓은 표는 `overflow-x-auto` 래퍼 안에 두고 `min-w`는 모바일에서 축소.
4. **터치 타깃 ≥ 44px 지향**: 주요 버튼/링크 `py` 충분히.
5. **브레이크포인트**: 이 앱은 `lg`(1024)가 데스크탑 피벗(사이드바 등장 지점). 폰 경계는 `sm`(640). 컬럼 숨김 등은 `sm:`, 사이드바 등장은 `lg:`.
6. **검증**: 각 STEP `npm run build` 무에러 → 커밋. 빌드는 문법/타입만 잡음 — **시각은 아침에 실제 폰**.

## 📱 시각 검증 방법 (아침, 사용자)

둘 중 하나:
- **(A) 실제 폰**: Mac에서 `npm run dev` 중, 같은 와이파이에서 폰 브라우저로 `http://<Mac-IP>:3333` 접속. (Mac IP: 시스템설정 → Wi-Fi → 세부)
- **(B) PC 브라우저 개발자도구**: 크롬 F12 → 기기 툴바(Cmd+Shift+M) → iPhone SE(375) / iPhone 14(390) 선택.

> STEP 380이 `docs/MOBILE_MORNING_CHECKLIST.md`를 만들어둠 — 아침에 그거 보며 화면별로 체크.

## ✅ 완료 기준 (이 플랜이 끝나면)
- 375px에서 가로 스크롤(의도된 표 제외) 없음.
- 모든 페이지 좌우 여백 일관(`px-4 sm:px-6`).
- 종목·상품 표가 모바일에서 핵심 4컬럼(현재가·1일·1주일·1년)만 보이고 나머지는 `sm:`부터.
- 리딩방·피드·마이페이지·즐겨찾기·법정 페이지 모바일에서 깨짐 없음.
- 데스크탑(≥1024) 외형은 **이전과 동일**.
- 아침 체크리스트로 미세조정만 남김.
