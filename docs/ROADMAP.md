# Trillion 마스터 로드맵 — 무엇을 / 어떤 순서로

> **이 문서 = "무엇을 어떤 순서로"의 단일 기준.** 매 세션 `SESSION_BOOT.md` 다음으로 이걸 본다. Phase는 위에서 아래로 순서대로. 현재 위치는 §6.

## 1. 골든서클 — 왜 만드는가

- **WHY** — 개인 투자자는 ① 정보가 흩어져 있어 뭐가 진짜인지 모르고 ② 검증 안 된 리딩방·상품에 속아 돈을 잃는다. 정확한 사실을 한눈에 모아주면 **스스로 안 속고 판단할 수 있다.** → *"투자상품에 속지 않게 돕는 곳."*
- **HOW** — ① 중립 허브(거래·보증·추천 X → 팔 게 없으니 편향 없음) ② 사실만(금감원 등록·공시·수익률·계산결과 / 주관평가 X) ③ 한눈에(한·미 종목·뉴스·공시·거시·리딩방 한 동선) ④ 신뢰가 중심축(광고도 '광고' 라벨로 사실과 분리).
- **WHAT** — onetrillion.app : 한·미 금융정보 허브 + 리딩방 검증 디렉토리 → (최종) Trillion AI 전망.

## 2. 변하지 않는 원칙 (LOCK)

1. **거래 X · 보증 X · 추천 X** — 정보·검증·연결만.
2. **사실만** 제공. 별점·후기 같은 주관 평가는 안 만든다(조작·명예훼손 리스크).
3. **신뢰 = 중심축·해자.**
4. **수익 ≠ retention 분리** — 광고 = *생존* 수익(트래픽에 과금, 재방문 불필요) / AI 구독 = *프리미엄·retention* 수익. 둘을 분리하면 "AI까지 못 버티면?" 리스크가 사라진다.
5. **한 번에 한 시장 / 한 언어씩 완성.** 한국 먼저. 펼치지 말고 끝까지.
6. **언어(표시) ≠ 시장기준(분석 데이터).** UI가 한국어여도 미국탭이면 분석·데이터는 100% 미국 기준. 각 탭은 그 시장의 완전한 소스만 새로 연결(한국 기준 끼워넣기 금지).
7. **AI 출력 = "투명한 계산."** "오른다" 단정 X → *"검증 기법 N개로 계산한 결과 + 방법론 공개 (보장 아님)"*. 매수추천 X → **유사투자자문업 신고 후** 유료 구독.

## 3. 수익 모델 (3층)

- **생존 — 국내 광고**: sponsored 슬롯('광고' 라벨 필수, 사실과 분리, 미등록을 인증처럼 X). 자가등록(승인제)을 광고주 인테이크로 확장.
- **생존 — 해외 어필리에이트**: 현지 영업 불가 → 증권사 가입 수수료 등 referral.
- **프리미엄·해자 — Trillion AI 전망 구독**: 종목 상세 페이지에 안착. 무료=요약 / 유료=전체 분석.

### 광고·게재 정책 — 리딩방·검증 (2026-06-27 확정)
- **게재 = 금감원 등록 확인된 곳만.** "디렉토리에 있다 = 등록된 곳"(존재 자체가 신뢰 신호, 없으면 주의).
- **신청 흐름**: 리딩방 등록 신청 → 자동 FSS 대조 → ① 매칭 = 게재 / ② 불일치 = **보류** → 관리자가 금감원 '파인'에서 직접 확인 → 등록 확인 시 게재 / 미등록 시 반려. (이 보류 검토가 곧 **검열 게이트**.)
- **등록 업체 과금**: 1개 링크(리딩방/유튜브/사이트) **무료** + 추가 링크마다 **유료(선불 월정액 = 결제형. 구독형은 추후 옵션)**.
- **미등록 = 게재 불가**(무료·유료 둘 다). 이유: 무료여도 위험한 곳을 호스팅할 명분 없음 + 유료는 '미신고인 줄 알면서 유료 노출 = 방조' 정황·브랜드 리스크. **미등록 보호는 검색 '등록 안 됨·주의' + 신고**로(현행 유지).
- **광고 표시 원칙**: '광고' 라벨 필수 + 금감원 사실 그대로 + **사실 랭킹 순서는 안 건드림**(별도 핀/인피드). 인피드 = 리딩방 `AD_EVERY`개마다 1개.
- **인프라**: 자가등록 폼 + FSS 대조 + 관리자 승인제 **이미 구현**(STEP 301·363). 추가분 = 관리자 '등록 직접확인' 정책 + 결제(Phase 2 후반).
- ⚠️ **결제 붙이기 전 법률 자문 필수.**

## 4. 핵심 제품 결정 (메모)

- **종목 상세 페이지 = Trillion AI의 자리.** 네이버·토스는 거기 차트·시세를 넣지만 우리는 AI 분석을 넣는다. 지금은 안 만들고 **비워둔 자리**(나중 AI의 그릇). 종목 상세에서만 '머무는 곳', 나머지는 허브.
- **콜드스타트(리딩방 관심·신고 0)는 지금 안 건드린다.** 유저 생기면 자연히 채워짐. 금감원 등록 1,804건의 '사실 가치'는 지금도 유효.
- **결제 연동은 Phase 2 후반.** 광고주 0인데 결제부터 만들면 과투자 → 수동 영업(문의폼→수동 게재→인보이스) 먼저. 결제 키·연동은 **사용자가 대시보드에서** (Cowork은 화면·흐름만, 보안상 키 미취급). 한국=Toss/PortOne(`TOSS_*` env 흔적 있음).
- **i18n 번역·현지콘텐츠는 후순위.** 한국 완성 후 한 언어씩.
- **AI는 "공장" 구조.** 기법은 국불문 동일 → 한 시장에서 완성·검증(트랙레코드) 후, 시장별 데이터만 갈아끼워 확장. 시장마다 무료 데이터 양이 달라 돌릴 수 있는 기법 수만 차이(=소스 연결 완성도 문제, 기법 문제 아님).

## 5. 실행 순서 (Phase — 위에서 아래로)

### Phase 0 — 한국 '완성' 정의 ✅ 완료 (2026-06-27)
- **목표**: ① 모바일 폴리시 마무리 ② **한국 완성 감사** — 한국탭 기능·리스트·UI를 있다/예약/안 만든다로 도장.
- **결과**: `docs/KR_COMPLETENESS_AUDIT.md` 확정. **한국 = 허브 기준 완성, 블로킹 빈틈 없음.** (토론 제외 STEP 424 · 카카오 버튼 제거 STEP 425 · 모바일 시트 통일 STEP 422·423.)
- **결론**: Phase 1 큰 빌드 없이 **Phase 2(광고 슬롯)로 진행 가능.**

### Phase 1 — 한국 기능 완성
- **목표**: 감사에서 나온 '없다(만들어야 함)' 항목을 채워 한국탭을 기능적으로 끝낸다. (종목 상세는 'AI 자리'로 비워두는 게 정답이면 스킵.)
- **완료 기준**: 감사 체크리스트 전 항목 ✔ 또는 '안 만듦' 확정.

### Phase 2 — 한국 수익화 토대 (광고)
- **목표**: 광고 슬롯 UI 정의(리스트 상단 sponsored·사이드·리딩방 상위 등, '광고' 라벨) + 자가등록을 광고주 인테이크로 확장(sponsored 등급). **수동 영업**으로 시작.
- **나중**: 셀프서브 광고주 페이지 + 결제 자동화(수요 증명 후).

### Phase 3 — 첫 retention 훅 + 앱 출시
- **목표**: 관심 종목·리딩방 변화 **푸시 알림**(retention의 첫 계단). 이걸 **앱스토어/플레이스토어 출시와 한 세트**로(앱의 존재 이유 = 알림. 개발자 결제는 준비됨).
- **묶음**: **이메일 OTP 가입 + 카카오 로그인 재추가**도 여기서 — 알림용 SMTP가 어차피 필요하니 로그인 전환과 한 번에(현 로그인 = 구글 단일). 한국 유저는 카카오·인증번호 선호.
- **이유**: 알림 없이 웹앱 래퍼만 올리면 애플 4.2 반려 위험 + 유저 이득 없음.

### Phase 4 — 해외 확장 (수익화 포함)
- **목표**: 미국 어필리에이트 수익화(증권사 referral) → 주요국 1~2개(미국 다음 **일본**). **한 나라/한 언어씩 끝까지.**
- **후순위**: 중국(규제·데이터 접근=만리방화벽).

### Phase 5 — Trillion AI (최종 · 해자)
- **목표**: 퀀트식 검증 기법으로 종목 분석 → **종목 상세 페이지에 안착**, 무료 요약/유료 전체. **한국에서 먼저 완성·검증 → 트랙레코드 → 언어권 확장**(틀은 이미 잡혀 있음).
- **전제**: 유사투자자문업 신고(자본시장법) + 법률 자문. 출력은 '투명한 계산'(원칙 §2-7).
