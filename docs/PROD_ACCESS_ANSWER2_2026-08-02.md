## §3. 게이팅 구멍 — 이전 세션의 독립 재검증

> 🔑 **새 세션의 보고를 그대로 믿지 않고 파일을 직접 열어 다시 쟀다.** 결과는 아래.

### 3-1. ✅ 일치 — `app/api/revdcf/route.ts`에 게이팅이 없다

`revdcfEnabled|REVDCF_ENABLED` 전수 grep = **6곳**, 그중 **소비처 3곳**:

```
app/[locale]/stock/[symbol]/page.tsx:20,176   ✅ revdcfEnabled() &&
app/[locale]/revdcf/page.tsx:3,16             ✅ if (!revdcfEnabled()) notFound()
app/api/revdcf/batch/route.ts:3,11            ✅ if (!revdcfEnabled()) return {enabled:false, verdicts:{}}
lib/revdcf/flag.ts:4,5                        (정의: process.env.REVDCF_ENABLED === "true")
```

`app/api/revdcf/route.ts` 상단 개봉 결과 — **import 목록에 `revdcfEnabled`가 없다.** `createAdminClient`만 import하고 곧바로:

```ts
const row = (await sb.from("revdcf_results").select("*")
  .eq("as_of", asOf).eq("symbol", symbol).maybeSingle()).data
```

**인증·시크릿·레이트리밋 0건. `select("*")`로 행 전체 반환.**

### 3-2. ✅ 일치 — 플래그 자체는 정상, **환경변수 문제가 아니다**

`batch` 라우트가 프로덕션에서 `{"enabled":false,"verdicts":{}}`를 반환했다는 새 세션 실측이 이를 증명한다. **`REVDCF_ENABLED`는 프로덕션에서 정상적으로 OFF다.** 문제는 **코드 누락 하나**다.

### 3-3. 🔴 **새 세션이 "배제 못 했다"고 남긴 것 → 배제 확정**

새 세션 검수란:
> *"853부터 공개는 git 이력 추론이다. 853~854 사이에 다른 방식으로 막혔다가 풀렸을 가능성은 배제 못 했다 — 중간 커밋들을 다 열지는 않았다."*

**배제된다.** `git log --follow -- app/api/revdcf/route.ts` = **이력 전체가 2개**:

```
2248b21  STEP 855
5475a95  STEP 853  (파일 생성)
```

854 게이팅 커밋 **`b9faf79`·`8d6d081` 둘 다 이 파일을 건드리지 않았다.** 파일이 두 번밖에 안 바뀌었으므로 중간 상태가 존재할 수 없다.
→ 🔴 **853 배포 시점부터 지금까지 계속 공개가 확정이다.**

### 3-4. ✅ **5번째 구멍은 없다** (이전 세션 추가 검증)

`revdcf_results`를 읽는 **앱 코드는 3개**뿐:

| 파일 | 상태 |
|---|---|
| `app/api/revdcf/route.ts` | 🚨 **게이팅 없음** |
| `app/api/revdcf/batch/route.ts` | ✅ 게이팅 |
| `app/api/cron/revdcf/route.ts` | ✅ **`CRON_SECRET` Bearer 검사 있음**(`route.ts:17-18` · 다른 크론과 동일 패턴) |

나머지는 전부 `scripts/`(서버 실행 · 외부 노출 아님).
`/api/revdcf`를 부르는 클라이언트도 **`components/RevDcfSection.tsx:27` 하나뿐**이고, 그 컴포넌트는 `revdcfEnabled() &&` 뒤에 있다. → **플래그 OFF면 호출자가 없다.**

### 3-5. 노출 범위 (새 세션 실측 · 이전 세션이 코드로 확인)

`select("*")` + 계산된 순위 필드 → **심볼당 26개 필드**: `verdict` · `gapYears` · WACC ±1%p 밴드 · `explainedPct` · `thresholdMargin` · `monotonic` · 드라이버 9개(매출성장·영업이익률·세율·고정자본율·운전자본율·WACC 등) · `verdictMarginal` · `skipReason` · 업종 · 분포 내 순위 · `expectationLevel`. **604 종목 전부 조회 가능 · 30분 캐시 · 레이트리밋 없음.**

🔴 **개인정보 유출이 아니다.** 공개 재무데이터에서 우리가 계산한 값이다.
🔴 **문제는 다른 것이다** — **DoD 3·4·5·6·8이 🔶인 미완성 모델의 숫자가, 장은태 육안 승인 전에, 우리 도메인 이름을 달고 나가고 있다.** `STATE.md`가 명시한 승인 게이트가 이 경로로 우회된다.

## §4. 🔴 내(1차 답변서) 잘못 — 새 세션이 옳았다

1차 답변서 §4-1 표에 **"소비처 3곳"**이라 적었다. 그건 **"플래그를 소비하는 파일"**을 센 것인데, **"노출 표면 전체"**로 읽히게 썼다.

→ **새 세션이 내 표를 안 믿고 전수 grep을 돌린 것이 옳았다.** 이건 규칙 A-0("우리가 이미 가진 것부터, 단 그대로 믿지 말고 다시 재라")의 모범 사례다.

🔴 **교훈(다음 세션도 해당)**: **"안전한 곳 목록"이 아니라 "위험한 곳 목록"을 만들어야 한다.** 게이팅 감사는 항상 **데이터 출구**에서 시작한다.
