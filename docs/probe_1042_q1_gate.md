## 1-3. 켜기 전 필수 / 켠 뒤 가능 — 분류 기준을 먼저

**기준**(먼저 정함): **켜기 전 필수** = 안 정하면 **틀리거나 오해를 부르는 값이 화면에 나가는 것**(값 자체의 정확성·정직성 문제). **켠 뒤 가능** = 나가는 값은 이미 옳거나 최선인데 **더 좋게 만드는 것**(표시 형태·투명성 강화).

| 항목 | 통 | 근거 |
|---|:--:|---|
| 조건부 4칸(PSR×Financials 등) 처리 판정 | 🔴 **필수** | 값 자체는 Damodaran도 발행하는 정당한 값("틀림"이 아니라 "조건부")이지만, REIT PER 320배 같은 극단치를 **설명 없이** 내보내면 사용자가 "오류"로 오해한다. 게다가 오늘 영향 범위가 405건으로 커졌다 |
| `sectorSource` 침묵 버그 | 🔴 **필수** | "출처를 함께 밝힌다"(규칙 5-2④)는 이미 코드에 구현된 원칙인데 **데이터 신선도 어긋남 때문에 100% 조용히 안 지켜지는 중**이다 — 고의로 숨기는 게 아니라 결함으로 숨겨지는 것이라 더 위험하다(발견하기 어렵다) |
| ⓛ(disagree 표시규칙) | 🟡 **나중** | sector 값 자체는 이미 최선(2-of-2 합의제), 표시 여부는 부가 투명성 문제. `USER_QUESTIONS` §7 자신도 "정답에 경고 달지 않는다"는 방향으로 이미 기울어 있다 |

### 0층 실측 연결 — 코드로 확인 + 실제 API 응답

`Q1Section.tsx:56-60`: 헤드라인은 `per.unavailable`에만 종속된다. `per.unavailable == null`이면 `{pct}% · {n}건` 헤드라인, 아니면 4개 사유 문구 중 하나로 완전히 대체된다. **PBR/PSR/EV-EBITDA는 헤드라인과 무관하게 각자 성립 여부를 따로 표시한다** — 즉 "PER은 안 되는데 PBR·PSR은 되는" 종목에서 헤드라인은 안전하게 물러나지만, 그 아래 grid에는 실제 percentile이 그대로 뜬다(아래 실측 사례).

### 🟢 로컬 dev 관찰 (Production 무접촉 — `Q1_ENABLED=true` 프로세스 오버라이드, 종료 완료)

`npm run dev`를 `Q1_ENABLED=true` 환경변수 오버라이드로 기동(파일 미수정) → `/api/q1/{symbol}` 직접 조회 → 관찰 종료 후 프로세스 종료(포트 3333 확인, 원상복귀). 대표 4종목:

| **AAOI**(적자·IT) | 적자 | PER·EV/EBITDA `unavailable: NO_VALUE`(값 null) · **PBR 17.3x(86.2%ile)·PSR 27.9x(88.9%ile)는 정상 표시**. 헤드라인은 "이 종목은 이 지표를 낼 수 없습니다" — 안전하나, 바로 아래 grid에 "매우 비싼 쪽" 신호(86~89%ile)가 떠 있어 **헤드라인과 grid가 다른 인상을 줄 수 있음**(육안 검증 재료로 기록) |
| **AAME**(적자·Financials) | 적자+금융업 | PER·EV/EBITDA `NO_VALUE` · PBR 0.30x(**1.6%ile**)·PSR 0.16x(1.6%ile, 업종 내 최하위권=매우 쌈). Financials라 `pbr_ok` 자체는 있으나 이 종목 개별로는 극단적으로 낮게 나옴 — 정상 동작 확인 |

## 1-5. 최소 승인 세트 — 판정 질문 형태

순서는 서로 독립(전제 관계 없음 — `probe_1040`의 의존 실측 방법을 적용했으나 이 항목들 사이엔 측정 가능한 의존이 나오지 않았다, 아래 미측정 참조).

2. **`sectorSource` 침묵을 어떻게 고칠 것인가** — `us_sector_wide` 신선도를 회복시킬지(크론 갱신 주기 점검), route.ts가 정확일치 대신 "가장 가까운 이전 as_of"를 찾도록 바꿀지. 재료: `STATE.md` #27이 이미 "신선도 상한 미설정"을 미결로 남겨뒀다 — 이번 발견(a)이 그 항목의 실제 피해를 처음 구체화했다.
3. **(선택) ⓛ·ⓞ를 켜기 전에 함께 정할지, 켠 뒤로 미룰지** — 위 1-3 분류(둘 다 "나중")를 그대로 받아들일지 재확인만 필요. 새 재료 불필요.
