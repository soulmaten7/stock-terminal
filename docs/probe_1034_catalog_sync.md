## 🔴 1-4. 재검토 목록 (판정 아님 — 목록만, 순서는 중요도순이 아니다)

### ① SEC 자체 조립(96.95%) vs 야후(94.16%) — 정본 교체 여부
- **무엇이**: 시가총액(슬롯 #1) 취득의 정본을 현행 야후 3단 취득에서 SEC 주식수×종가 자체 조립으로 바꿀지.
- **왜 재검토 대상이 됐는지**: 97% 기준에선 둘 다 게이트 미달이라 비교 자체가 무의미했다. 85% 기준(STEP1031)에서는 **둘 다 게이트를 통과**하고, **SEC 쪽(96.95%)이 야후(94.16%, 08-14 실측)보다 2.79%p 높다.**
- **지금 상태 수치**: 야후 94.16%(현재 프로덕션) · SEC 자체 조립 76.2%(단독) / 96.95%(야후 결측 코호트 보완 결합).
- **재검토하려면 무엇이 필요한지**: (a) SEC 조립값과 야후값의 종목별 괴리 재실측(STEP1019 당시 p99 4064%·소형주 p90 225% 극단치 있었음 — 최신 데이터로 재확인 필요) (b) 정본 교체 시 `lens_scores`·`us_market_cap` 등 파생 테이블 영향 범위 산정 (c) 장은태 판정.

### ② §0-A "경로 소진" — 새 기준에서 각 경로의 지위
- **무엇이**: §0-A가 "다섯 경로 모두 소진"이라 결론 내렸던 것 전체.
- **왜 재검토 대상이 됐는지**: 97% 기준의 결론이었다. 85% 기준에서는 5경로 중 3경로(야후·SEC조립·유니버스정리후)가 통과, 1경로(나스닥)는 게이트와 무관하게 여전히 접근 불가, 1경로(quoteSummary)는 게이트와 무관하게 여전히 죽어 있음.
- **지금 상태 수치**: §0-A 정정 표(위 §1-1 항목3) 참조.
- **재검토하려면 무엇이 필요한지**: 없음(이미 표로 정리됨) — 다음 판단은 ①과 동일 선상.

### ③ 나스닥 — 커버리지는 충분하나 접근 불가
- **무엇이**: 나스닥 스크리너 결합 예상 커버리지 97.25% — 게이트 기준과 무관하게 충분히 높다.
- **왜 재검토 대상이 됐는지**: 게이트와는 별개로, 이 경로는 여전히 `robots.txt`로 원천 차단돼 있다(1019 확정, 재시도 금지 — ⓪-3).
- **지금 상태 수치**: 97.25%(예상, 배선 시) — 단 겹치는 208건 중 13.5~20.2%가 야후값과 20% 초과 차이(소형·중형주 특히 크다).
- **재검토하려면 무엇이 필요한지**: robots.txt 차단이 해제되거나(우리가 통제 불가), 나스닥이 공식 API/피드를 열거나(우리가 통제 불가) — **현재로선 재검토할 새 경로가 없다.** 게이트와 무관한 별개 장벽이므로 이 STEP의 정정 대상도 아니다.

### ④ 슬롯 #12·#13(자본지출률·운전자본률, 원리적 단일) · #16(베타, 실질적 단일=SPOF)
- **무엇이**: 대체 소스 없음 상태.
- **왜 재검토 대상이 됐는지**: 게이트 변경과 직접 관련은 없으나, STEP1034가 20슬롯을 전수 재대조하며 함께 확인 대상에 포함됨(1-2 지시).
- **지금 상태 수치**: #12·#13은 개념 자체가 우리 계산법(원전 T5·T4 방식)으로만 정의돼 "대체 소스"라는 질문이 성립하지 않음(원리적 단일, 1002 판정 유지). #16은 92개 소스 전수조사(997+998)에서도 대체 무료 기관을 못 찾음(실질적 단일=진짜 SPOF, 1002 판정 유지) — `damodaran_beta` 94행·`as_of=2026-01-05`로 변화 없음(이번 STEP 재확인).
- **재검토하려면 무엇이 필요한지**: #12·#13은 원리적으로 재검토 대상이 아님(대체할 개념 자체가 없음). #16은 Damodaran `betas.xls`가 접근 중단되거나 갱신을 멈추는 사건이 실제로 발생해야 재검토 트리거가 생긴다 — 지금은 그런 사건 없음(관측만 계속).
