- **순환 없음.** 업종·이익상태(전제) → {배수·재무건전성·시장내재기대·배당·부도위험}(1차 정보층) → 없음(1차 정보층 항목 간 상호 의존은 측정하지 않았고, 측정할 근거도 못 찾았다 — 억지로 줄 세우지 않는다).
- **최근변화는 별도 축이다.** 논리적으로는 "값"(가격) 자체에 의존하지 1차 정보층 항목(배수·재무건전성 등)의 파생이 아니다. 다만 업종 컷을 적용하면 19~44%가 흔들리므로(실측) 업종의 영향은 받는다 — 그래서 그래프에서 업종 아래 나란히 놓되, 1차 정보층과는 점선(다른 성격의 의존)으로 구분한다.
- **층 표현**:
  - **0층(전제)**: 업종 · 이익상태
  - **1층(정보)**: 배수 · 재무건전성 · 시장내재기대 · 배당 · 부도위험 — **서로 순서 없음**(측정된 상호 의존 0건)
  - **1층과 병렬(시간축)**: 최근변화 — 자기 자신의 전제(가격 시계열)를 가지며, 0층(업종)의 영향은 공유
- **의존 강도 구간**(이 STEP에서 쓴 잠정 구간, 표시 설계가 아니라 서술 편의): 강 ≥30% · 중 15~29% · 약 <15% · 성립불가 ≥60%(구조적 결측). 배수(강)·재무건전성(강, 금융업은 성립불가)·최근변화(약~강, 지표별로 갈림)·이익상태→배수(강)·이익상태→역DCF(약, 논리 근거)·업종→역DCF(미측정, 표본 부족)·배당(재료 갭으로 판정 보류)·부도위험(미측정, 미구축).

## 1-7. 도출 결과 — 하나의 답

**층 A·B·C를 하나의 구조로 제시한다.**

1. **0층(전제) = 업종 + 이익상태.** 업종은 이미 Q0로 존재(형태까지 확정: 카드 아님, 각 카드에 녹임). 이익상태는 **이번에 새로 분리된 전제**다 — 근거: 🔴 **정정(2026-08-15 STEP1041)** — "43.4%가 32.5%보다 크고"는 잘못된 근거였다. 둘은 **같은 종류의 양이 아니다**: 32.5%는 「업종을 무시하면 판정(bucket)이 바뀌는 비율」이고 43.4%는 「적자라서 계산 자체가 성립 안 하는 비율」(범주 차이, 1-2 표의 "성립불가" 행이 이미 "강/중/약"과 별개 범주로 정의돼 있었다)이라 모집단도 다르다. **결론(이익상태 = 0층 전제)은 유지한다** — 성립 자체가 안 되는 것은 판정이 바뀌는 것보다 강한 의존이기 때문이다. 근거는 크기 비교가 아니라 **Q0의 기존 근거 서술(§2)에 이미 섞여 있었으나 별도 항목으로 취급된 적이 없었다**는 사실 하나로 충분하다.
2. **1층(정보) = 배수·재무건전성·시장내재기대·배당·부도위험.** Q1·Q2·Q4와 그대로 대응한다. 상호 순서는 매기지 않는다(측정 근거 없음).
3. **시간축 = 최근변화.** Q5와 대응. 0층(업종)의 영향은 받지만(19~44%) 1층 항목의 파생은 아니다 — 자기 자신의 원시데이터(가격)에 먼저 의존한다.
4. **업종대비위치는 항목이 아니라 표시형식이다.** 실측(1-3)·Q0 기존 결정(§2)·실무 4곳 조사(1-6) 셋이 전부 같은 방향을 가리켰다.
5. **방법론 공개는 항목이 아니라 Layer C(모든 항목에 붙는 신뢰 장치)다.** `probe_1037`이 이미 "Q0~Q5 밖"이라 확인한 것의 구체적 자리를 이번에 정했다 — Model Card 9섹션.
6. **근거 없는 부분(판정 필요로 명시)**:
   - 업종 → 시장내재기대(역DCF): 표본 부족으로 실측 불가(섹터 컷 1/11만 존재) — **근거 없음, 판정 필요**
   - 배당 → 이익상태: `payout_ratio` 전부 NULL이라 실측 불가 — **근거 없음, 판정 필요**(재료 갭이 먼저 해소돼야)
   - 부도위험(Altman Z)의 업종 의존: 모델 자체가 미구축이라 실측 불가, 논리적 근거(원전 문헌)도 이번엔 못 찾음 — **근거 없음, 판정 필요**
   - Layer C를 실제 화면에 어떻게 얹을지(범위 밖 4항목의 카피 인프라 확장 여부): **UI 판정 필요, 이 STEP 범위 밖**

## 3중 규칙

- **못 한 축(시도 기록)**: 부도위험(Altman Z)의 업종별 적용 배제 여부를 원전에서 직접 확인하지 않았다(`MODEL_ROSTER` §3 인용에 그쳤다, 재검색 안 함 — ⓪-1b 재조사 금지 원칙 준수). link_hub 신규 조회를 하지 않았다(기존 기록 인용만).
- **아직 안 함**: 이익상태(전제)를 실제 화면에 어떻게 반영할지(예: 종목 카드 상단 배지) — 이 STEP은 구조 도출까지다, 화면 설계는 다음 단계. 부도위험 모델 자체의 착수 여부(F-4 순위표 판정 사항, 별건).
- **철회·정정**: momentum 19.0%·technical 43.9%·fscore 37.4%는 이 STEP에서 처음 실측했고 이전 기록이 없어 정정 대상 아님. valuation 32.5%·quality 34.0%는 기존 33.0%·33.8%의 **소폭 갱신**(표본 변화, 방향·결론 불변)이라 "정정"이 아니라 "갱신"으로 구분해 적는다.
- **미측정**: 1차 정보층 항목 간 상호 의존(예: 배수를 모르면 재무건전성 읽기가 얼마나 달라지는지) — 측정 방법 자체를 못 찾았다(둘 다 업종에 의존하지만 서로 직접 의존하는지는 별도 실험 설계가 필요). 업종 → 시장내재기대·배당 → 이익상태·부도위험의 업종 의존(위 1-7 참조, 근거 부족 3건). fscore·technical의 "고정임계 vs 섹터tercile" 비교가 실제 판정 변경 이력과 얼마나 다른지(방법론 자체가 다르다는 것만 확인, 크기 차이의 원인은 미분석).
