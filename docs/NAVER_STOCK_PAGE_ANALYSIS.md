# 네이버증권 종목 페이지 디테일 분석 + 운종 Gap (V6)

> **목적**: 운종 종목 페이지(`/stock/[code]`)를 "네이버 수준 디테일 + 직관"으로 끌어올리기 위한 레퍼런스. 기존 `MARKET_RESEARCH_V1.md`(2026-04-21)는 **홈 대시보드** 분석이고 네이버는 당시 봇 차단(신뢰도 中)이라 종목 페이지 분석이 없음 → 이 문서로 신규 대체.
>
> **방법·신뢰도**: 네이버 `finance.naver.com` 직접 수집은 환경 blocklist 로 차단됨 → **도메인 지식 + 공개 자료**(나무위키 종목토론실, FnGuide, 증권플러스) 기반. 구조는 안정적이라 신뢰도 中上, 단 수치 라벨은 실제 페이지에서 최종 확인 권장.
> **확정일**: 2026-06-03 · 전제 코드: STEP 138 (HEAD `e92d49d`)

---

## 0. 한눈 결론

1. **종목별 토론은 이미 있다** — `DiscussionBoard`(종목코드별, hot/recent, 작성·좋아요·tier). 네이버 "종목토론실"에 대응. 오히려 tier·신뢰 정렬은 운종이 더 나음.
2. **부족한 건 "디테일 정보"** — 네이버의 ① 기업실적분석(재무표) ② 투자자별 매매동향 ③ 동종업종 비교 ④ 시세 메타(시총순위·상장주식수·외국인보유율·배당).
3. **희소식: 백엔드 API 상당수가 이미 있다** — `investor`(투자자별)·`orderbook`(호가)·`execution`(체결)·`sector`(업종) KIS 라우트 존재. **종목 페이지에 연결만 안 됐다.** 특히 **"인사이트" 탭이 빈 placeholder**.
4. 따라서 작업의 다수는 "신규 개발"이 아니라 **"있는 API를 종목 페이지에 연결"** + **재무표(DART, Phase 2-④)** 추가.

## 1. 네이버증권 종목 페이지 전체 구조

URL 패턴: `finance.naver.com/item/main.naver?code=005930` (종합정보). 상단 탭으로 하위 페이지 전환.

### 1-1. 상단 종목 헤더
- 종목명 + 코드 + 시장(코스피/코스닥) + 업종
- **현재가** + 전일대비(등락액·등락률·▲▼) + 색(상승 빨강/하락 파랑 — 한국 관습)
- 미니 차트(1일) + 체결 시각
- 관심종목 추가 ★

### 1-2. 시세 요약 (헤더 우측 표)
| 항목 | 항목 |
|------|------|
| 전일·시가·고가·저가 | 거래량·거래대금 |
| **시가총액 + 시총순위** | **상장주식수** |
| 액면가·매매단위 | **외국인소진율(보유율)** |
| 52주 최고·최저 | 투자의견·목표주가(컨센서스) |
| **PER·EPS** (TTM/추정) | **PBR·BPS** |
| **배당수익률·주당배당금** | **동일업종 PER·등락률** |

### 1-3. 상단 탭(하위 페이지)
`종합정보 · 시세 · 차트 · 투자자별매매동향 · 뉴스공시 · 종목분석 · 종목토론실 · 전자공시 · 공매도현황`

### 1-4. 기업실적분석 (종합정보 하단 — 네이버의 상징)
연간 3~4기 + 분기 4기 표:
- **매출액 · 영업이익 · 당기순이익**
- **영업이익률 · 순이익률 · ROE(%)**
- **부채비율 · 당좌비율 · 유보율**
- **EPS · PER · BPS · PBR**
- **주당배당금 · 시가배당률 · 배당성향**
> 출처: 회사 정기공시(연결/별도) — 운종은 **DART**로 재현 가능(계산·정제 = Phase 2-④).

### 1-5. 투자자별 매매동향
- 외국인·기관 **일별 순매매**(수량·금액)
- 외국인 **보유주수·보유율 추이**
- 개인/기관/외국인 누적

### 1-6. 동일업종 비교
- 같은 업종 종목들 PER·등락률·시총 나란히 비교

### 1-7. 종목토론실
- 게시판형: 제목·글쓴이·날짜·조회·**공감/비공감**
- 말머리(매수/매도/의견), 종목별 분리, 비로그인 읽기·로그인 작성
> 운종 `DiscussionBoard`가 이미 대응. 단 네이버엔 **실시간 채팅이 없음** → 운종 우측 `StockChatPanel` 이 차별점.

## 2. 운종 현재 종목 페이지 현황 (실제 코드)

`/stock/[code]` = 3컬럼: 좌 `StockInfoPanel`(sticky) / 중 `StockTabs` / 우 `StockChatPanel`(실시간 채팅).

| 영역 | 구현 | 데이터 |
|------|------|--------|
| 좌 `StockInfoPanel` | 현재가·등락%·시고저·거래량·52주·**PER·PBR·시총** + 일봉 차트 | 한국 KIS `/api/kis/price`, 미국 Yahoo |
| 중 탭 `차트·시세` | `StockChartSection` | KIS chart |
| 중 탭 `토론` (기본) | `DiscussionBoard` — 종목별 토론 hot/recent·작성·좋아요·tier | `discussions` |
| 중 탭 `뉴스` | `StockNewsModule` | RSS + Yahoo |
| 중 탭 `인사이트` | **빈 placeholder** ("추후 통합 예정") | — |
| 우 `StockChatPanel` | 종목별 실시간 채팅 | `chat_messages` |

`/api/kis/price` 응답엔 이미 `tradeAmount`(거래대금)·`dividendYield`(배당수익률)도 있으나 **패널에 미표시**.

**이미 존재하는 KIS API (종목 페이지 미연결):**
`investor`(투자자별 매매동향) · `orderbook`(호가 10단) · `execution`(체결) · `sector`(업종) · `investor-rank` · `vi`(변동성완화장치)

## 4. V6 경계 적용 (뭘 만들고 뭘 외부로)

PRODUCT_SPEC_V6 ④ 원칙 = "판단에 필요한 핵심 + 출처 링크, 깊은 분석은 외부".

- **만든다 (핵심·무료 데이터)**: 기업실적분석 재무표(DART), 투자자별 매매동향(KIS), 호가·체결(KIS), 동종업종 비교(KIS), 거래대금·배당·외국인보유율(KIS).
- **외부 링크로 넘긴다**: 투자의견·목표주가 컨센서스, 정밀 재무 스크리닝, 리포트 → FnGuide·증권사. (운종은 "여기서 핵심 보고, 더 깊은 건 외부" 동선)
- **캐싱**: KIS rate limit → 시세성 30초~1분, 재무·수급 일 1회 캐시.

## 5. 우선순위 로드맵 (종목 페이지 디테일)

### 🥇 STEP A — "있는 API 연결" (저비용·고효과)
빈 **인사이트 탭** + 시세 패널을 채운다. 신규 데이터 소스 0:
- `StockInfoPanel` 에 거래대금·배당수익률 노출 (이미 응답에 있음)
- 인사이트 탭 = **투자자별 매매동향(kis/investor) + 동종업종 비교(kis/sector)** 섹션
- 차트·시세 탭 하단에 **호가 10단(kis/orderbook) + 체결(kis/execution)** (초보용 단순 카드 토글)

### 🥈 STEP B — 기업실적분석 재무표 (Phase 2-④)
DART 정기공시 → 매출·영업이익·순이익·ROE·부채비율·EPS·BPS·배당 표 + PER/PBR 계산.
- 마이그레이션: `stock_fundamentals` 캐시 테이블 + 일 1회 임포트(파인 방식과 동일 패턴)
- 인사이트 탭에 "기업실적분석" 표 렌더

### 🥉 STEP C — 메타·공시 보강
외국인보유율·상장주식수·시총순위(KIS 추가필드) + 공시 탭(DART) + 외부 링크(FnGuide 목표주가).

## 6. 즉시 정정 / 메모

- "종목 검색 → 종목별 토론" 은 **이미 동작**(검색 → `/stock/[code]` → 기본 탭 "토론"). 사용자 체감이 약하면 검색 UX·기본 탭 노출을 점검할 것.
- 인사이트 탭 placeholder 가 "추후 통합 예정"으로 비어 있어 디테일이 없어 보이는 주원인 → STEP A 가 1순위.
- 한국 등락색은 **상승=빨강/하락=파랑**(네이버 관습) vs 운종 현재 **토스식(상승 초록/하락 빨강)**. 정체성상 토스식 유지 권장 — 단 일관성만 확인.
