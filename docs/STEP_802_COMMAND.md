# STEP 802 — 판정 컷 데이터 기반화(시장별 분포) + 결측 집계 정정 + 백분위 정직 표기

**전제 상태**: STEP 801 커밋 이후 HEAD · 트리 클린

**착수 전 필독**: `docs/LENS_DEV_PLAYBOOK.md`.

## 배경

1. **판정 컷이 전부 코드 상수**이고 근거가 없다: 모멘텀 ±10%, RSI 30/70, PER 10/25, 변동성 20/40%, GP/A 15/40%, 자산성장 5/20%, F-스코어 3/7. `lib/momentum.ts` 주석이 "첫 버전 — 백테스트/분포로 튜닝 여지"라고 자백하고 있다.
2. **모든 시장이 같은 상수를 쓴다.** KR 중위 PER은 10~13인데 컷이 10/25라 **한국 종목 상당수가 자동으로 "싼 편(강점)"**이 된다. 사용자는 종목 특성으로 읽지만 실제로는 **국가 라벨**이다.
3. 🔴 **"한국은 8/15"처럼 숫자만 바꾸는 하드코딩은 금지**(장은태 지시). 컷은 **실제 분포에서 유도**되어야 하고, US·향후 시장이 같은 구조로 자동 정합돼야 한다.
4. **결측(na)이 `tone: 'flat'`으로 집계**돼 상단 헤더·닫는 카드·시간축 요약에서 "보통 1표"가 된다 → "판단할 근거 없음"이 "중립적으로 판단됨"으로 읽힌다.
5. **"시장 내 백분위"** 표기가 사실과 다르다(실제 모집단 = 시총/거래대금 상위 1000). 최상위 종목은 **"상위 0%"**로 표시된다.
6. `lens_scores`에 **삭제·신선도 필터가 없어** 유니버스에서 탈락한 종목의 옛 값이 백분위·랭킹에 영구 참여한다.

## 수정

### 1) 판정 컷 = 시장별 분포에서 유도

- **신규 테이블**(Cowork이 MCP 선적용 예정 — Claude Code는 마이그 파일만 아카이브): `lens_cuts(market, lens_key, lo, hi, n, as_of, method)` PK(market, lens_key).
- **산출**: 렌즈 선계산 크론(`kr-lens-scores`·`lens-scores`)이 유니버스 전체 값을 이미 계산하므로, **그 분포의 백분위로 컷을 유도**해 저장한다. 기본 방식 = **하위 30% / 상위 30%**(3분위 — 백테스트가 검증한 3분위 롱숏 구조와 정합). 표본 `n`과 산출일 `as_of`도 저장.
  - 렌즈별 방향 주의: 저변동성·자산성장·PER은 **낮을수록 좋음**, 모멘텀·GP/A는 **높을수록 좋음** — 부호를 렌즈 메타에 명시하고 컷 해석에 반영.
  - RSI(30/70)와 F-스코어(3/7)는 **학술·업계 표준 고정값**이므로 분포 유도 대상에서 **제외**하고, 그 사실을 코드 주석과 서사에 명시.
- **소비**: 렌즈 계산이 `lens_cuts`를 읽어 판정. **컷이 없으면 판정하지 않고 "기준 준비 중"**(임의 상수 폴백 금지 — 그게 지금 문제의 원인).
- **표시**: 서사·근거 줄의 "판정 컷" 표기를 **실제 사용된 컷 + 근거**로("KR 시장 상위/하위 30% 기준 · N=1,000 · 2026-07-27"). 사용자가 숫자의 출처를 알 수 있어야 함.
- 🔴 **이번 STEP에서 채우는 시장은 KR·US 둘뿐**(활성 시장). 구조는 시장 무관.

### 2) verdict 컷 vs label 컷 이중 기준 제거

- 같은 값에 두 개의 컷이 걸려 있다(모멘텀 verdict ±10 / label ±20, 변동성 verdict 20-40 / label 25-45). 주석에 "통일하지 말 것"으로 고착돼 있고 특성화 테스트가 모순을 스냅샷으로 박아뒀다.
- 조치: **단일 컷(`lens_cuts`)으로 통일**. 스냅샷은 갱신(의도된 변경).

### 3) "검증" 배지·백테스트 인용 범위 정직화

- 현재 `note`의 t값·기간은 **미국 유니버스 백테스트** 결과인데 KR 카드에도 그대로 붙는다. 또 백테스트가 검증한 것은 **3분위 롱숏의 방향성**이지 절대 컷이 아니다.
- 조치: 배지·인용에 **적용 범위를 명시**(어느 시장·어느 기간 검증인지). KR에 US 검증 결과를 근거로 제시하지 말 것. KR 검증이 없으면 "이 시장에서는 아직 검증 데이터 없음"을 정직하게 표기.

### 4) 결측(na)은 집계에서 제외

- `verdict.tone`이 `'flat'`인 것과 **계산 불가(na)**를 구분(별도 필드 또는 tone `'na'` 신설).
- 상단 렌즈 헤더 카운트·788 닫는 카드·`axisMajority`(시간축 다수결)에서 **na는 세지 않는다**. 대신 "N개는 데이터가 없어 계산하지 못했어요"를 **명시적으로 표기**.
- 시간축 다수결이 **근거 1개**로 "대체로 유리"를 내는 것도 방지(최소 표본 미달 시 "판단 근거 부족").
- `/explore` 랭킹(`lens-top`)이 pos **개수**로 정렬해 결측 많은 종목을 구조적으로 불리하게 만드는 문제 → 정규화 또는 최소 계산 렌즈 수 조건 적용(택1하고 근거 기재).

### 5) 백분위 표기 정직화 + 신선도

- "시장 내 백분위" → **모집단을 정확히 표기**("거래대금 상위 1,000 종목 중"). ko/en.
- **"상위 0%" 방지**: 최상위는 "상위 1% 이내" 등으로 표기하거나 반올림 규칙 조정.
- `lens_scores` **신선도 관리**: 유니버스 이탈 종목 정리(오래된 행 삭제 또는 `updated_at` 기준 필터) → 백분위·랭킹·`/api/explore/lens-top` 전부에 적용. 헬스체크에 **행 수·최고 나이**를 함께 감시(현재 MAX(updated_at) 하나만 봐서 정체를 탐지 못함).
