## 1. 이 렌즈의 확정 사실 (STEP 818 3중 검증 + 803/806/808/819)

1. **원전 = Piotroski(2000)**. 9개 이진 신호의 합(0~9). **원전의 표본은 고BM(가치주) 최상위 5분위·소형중형 소외주 집중**이며, 대형주에서는 효과가 약하다.
2. **9항목 구성은 원전과 정합**. 분모 시점도 **기초 총자산**으로 정합(801이 옳게 적용).
3. **등급 ≥7/≤3은 우리 자체 밴딩**이다. 원전의 "높음"은 **8~9점**.
4. **금융업(은행·보험·증권)은 산출 불가** — 필요한 재무 항목을 보고하지 않아 자연히 `unsupported`로 빠진다(인위적 제외 아님).
5. **자체 백테스트는 지원관측 0**이라 재현할 수치가 없다. 즉 **성과 수치를 주장할 근거가 없다.**
6. **미지원 비율이 높다**: KR 42% · US 27.3%(3개 회계연도 + 9개 필드 요구).
7. 819에서 `FScoreCard`에 `ScopeBlock`을 렌더하도록 고쳐, 818이 쓴 scope 3필드가 이제 화면에 나온다.

## 2. 고칠 주장 (F-스코어)

### 2-1. 🔴 `t≈0.7` 백테스트 수치 — **근거 없는 수치가 화면에**

- 위치: `messages/{ko,en}.json`의 `StockLens.fscore.whyFinHealthBody` — "우리 넓은 표본·**12년 백테스트에선 점수와 이후 수익률에 유효한 관계가 없었어요(t≈0.7)**".
- 문제: 818 재실행 결과 **지원관측 0**으로 재현 불가. 813~821에서 **여섯 렌즈의 자체 백테스트 점추정을 전부 삭제**했는데 이것만 남았다. 게다가 그 백테스트는 EDGAR(미국) 기반인데 KR 종목 화면에서 "우리 넓은 표본"으로 읽힌다.
- 조치: **삭제**하고, 재현 가능한 정성 서술로 교체(예: 이 지표는 재무 체력 점검 도구이며 우리가 수익 예측력을 검증한 바 없다는 사실). **없는 검증을 있는 것처럼도, 실패한 검증을 한 것처럼도 쓰지 말 것.**
- 🔴 함께: `docs/LENS_COMPLETION_STANDARD.md` 818 절의 **"화면 카피도 성과 수치 미주장"** 오기를 정정(819 §6에서 지적된 문서 오류).

### 2-2. 🔴 등급 기준을 "실무 관행"이라 서술 — **거짓**

- 위치: `StockLens.fscore.howToReadBody` — "**실무에선 보통 7점↑ 양호** · 4~6 중간 · 0~3 취약으로 봐요".
- 문제: §1-3대로 **≥7/≤3은 우리 자체 밴딩**이고 원전은 8~9다. 818이 scope에 자체 기준임을 밝혔는데 이 문장이 정면으로 반박한다.
- 조치: **자체 기준임이 드러나게** 재작성하고 **원전의 기준(8~9)을 함께 표기**. scope와 중복되면 한쪽으로 정리.

### 2-3. `narrativeScopeFixed`의 F-스코어 몫 (820에서 남긴 것)

- 820이 기술 렌즈 몫만 고치고 **F-스코어 몫은 남겨뒀다**(키 분리 여부 포함해 이번에 처리).
- 확인: 이 문자열이 아직 F-스코어 카드에서 렌더되는지, 렌더된다면 "학술·업계 표준 고정값"이라는 **거짓 주장**이 남아 있는지 → §1-3대로 정정하거나 제거.

### 2-4. 적용 범위(가치주·소형중형) 표기가 화면에서 읽히는지

- 819로 scope가 렌더되기 시작했다 → **실제 화면에서** 원전 범위(가치주 집단 도구)·대형주 약함이 **읽히는지** 확인하고, `howToReadBody`·`whyFinHealthBody`와 **중복·모순이 없는지** 정리.
- 🔑 카드 분량이 과밀해지지 않게: scope와 본문 설명의 **역할을 분리**(scope=범위·한계 / 본문=읽는 법).

### 2-5. 미지원 사유·비율

- KR 42%·US 27.3%가 미지원이다. 현재 화면이 **왜 미지원인지**(3개 회계연도 필요 · 9개 항목 필요 · 금융업 미보고) 사용자에게 말하는지 확인.
- 803에서 "은행·보험" 거짓 진술은 제거됐다 → 지금 문구가 **사유를 정확히** 말하는지 재확인(822에서 밸류에 적용한 사유 분기와 같은 원칙).

### 2-6. 라벨 통일 재확인 (810 §5)

- 목록(`재무 건전/보통/취약`) · 상세(`양호/중간/취약`) · 브리핑 프롬프트(`우량/중립/부실`)가 810에서 통일됐다고 기록돼 있다 → **실제로 통일됐는지 전수 grep으로 확인**하고 잔존이 있으면 정합.
