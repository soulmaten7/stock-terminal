### 2) 보드 6개 공통 (`MarketBoard` + `{Us,Jp,Cn,Vn,Gb}MarketBoard`) — 동일 패턴 미러

**(a) 검색 필드 → 아이콘 접기(모바일)**: 서브탭(주식/ETF/…) 줄 오른쪽에 44px 검색 아이콘 버튼. 탭하면 검색 입력이 펼쳐지고(자동 포커스·X로 닫기), 닫으면 원상. 데스크톱은 기존 상시 필드 유지. **−1층.**

**(b) 시장 세그먼트 → 정렬줄 드롭다운(모바일)**: 세그먼트 줄을 가진 보드(KR=전체/코스피/코스닥 · CN=시장 구분 있으면 동일)는 그 칩 줄을 제거하고 **정렬줄 왼쪽에 드롭다운**("전체 ▾")으로 통합 — 기존 기간(1일전 ▾) 커스텀 드롭다운 패턴 재사용. 상태·URL 복원 로직 불변(표현만 이동). 데스크톱 세그먼트 칩 유지. **−1층.**

**(c) 렌즈 힌트 줄 → 첫 방문만**: `localStorage('lens_hint_seen')` 없으면 기존 힌트+범례 2줄 표시(닫기 X 버튼·표시 즉시 키 저장), 있으면 숨김. 대신 **범례는 정렬줄 우측에 상시 축약**(`●강점 ●주의 ●보통` 11→12px). **−1층(재방문 기준).**

**(d) 행 폴리시**: 종목명 15→**16px**·가격/등락 **14px**·별 아이콘 터치영역 패딩 확대(총 ≥40px)·로고 크기는 현행 유지(≈38px 확인). 도트 12px 유지.

**(e) 폰트 하한**: 모바일에서 `text-[10px]`·`text-[11px]` 전수 제거 → 최소 12px(컨트롤 라벨은 13~14px). 데스크톱 표기는 불변.
