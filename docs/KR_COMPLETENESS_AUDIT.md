## 결론
**한국 = 허브 기준 완성.** 블로킹 빈틈 없음. '예약'은 Phase 3·5로, '안 만든다'는 확정. → **Phase 1에 큰 빌드 없이 Phase 2(광고 슬롯)로 진행 가능.**

## 새 시장 복제 체크리스트 (Phase 4용)
새 국가 탭은 위 ✅ 칸들을 **그 시장의 완전한 데이터**로 채운다(한국 기준 끼워넣기 금지):
- 종목·상품 표 — 현지 거래소 데이터 + 통화 + 식별자
- 뉴스·공시·거시 피드 — 현지 소스 새로 서치·연결
- 유튜브/리딩방 등가물 — 있으면 연결, 없으면 스킵
- 증권사/운용사 바로가기 — 현지
- 수익화 — 국내=광고 / 해외=어필리에이트
- 언어 — 한 국가/한 언어씩 끝까지(번역은 후순위)
