## ✅ 기록 — 기법 1사이클(F-Score) 종료 & 배운 것
- **정의→데이터→엣지→검증→표현** 5단계 첫 완주. 방법론 자체는 확립.
- **핵심 교훈**: 기법을 rigorous하게 검증하니 "대형주에선 재무 우량≠초과수익"이 나옴 = 리서치 문서의 "대형주 알파 희박" 경고를 직접 확인. → 렌즈는 **"전망(오른다/내린다)"이 아니라 "상태·특징 해석"**으로 제시해야 정직.
- F-Score = **재무 건전성 렌즈**로 확정(수익 신호 아님).
