## 커밋 전 체크리스트 (순서대로)

### 1. 원본 게이트 (출처 `#76`·`#82`)
- [ ] 원전·문서를 근거로 말하기 전, **그 자리를 직접 열어서** 내용을 봤는가?
- [ ] `grep -l` 매칭이나 기억만으로 "들어 있다/맞다"고 단언하지 않았는가? (매칭 = 존재 증거, 내용 증거 아님)

### 2. 정정 게이트 (출처 `#77`·`#80`)
- [ ] 수치·주장을 고칠 때 **내용으로 grep**해 출현 목록을 만들었는가? (줄번호 인용은 문서가 자라면 밀린다)
- [ ] 목록의 **각 항목에 ✅정정 또는 제외사유**를 붙였는가?
- [ ] 그 목록을 **보고에 그대로** 실었는가?

### 3. 재현 게이트 (출처 `#78`)
- [ ] 산출물(JSON 등)을 커밋하면 **그것을 만든 스크립트도 같은 커밋**에 있는가?
- [ ] 출처 표기가 **실재하는(커밋된) 경로**를 가리키는가? (`/tmp` 금지 — 다음 세션엔 없다)

### 4. 근거 게이트 (출처 `#81`)
- [ ] ③판정의 모든 근거가 **실측 또는 직인용**에 걸려 있는가?
- [ ] 안 잰 대안을 "부적합하다/불가능하다"는 근거로 쓰지 않았는가? (안 잰 것은 "안 쟀다"로 적는다)

### 5. 완결 게이트 (출처 `#79`)
- [ ] 재료가 갖춰진 행을 "대기"로 남기지 않았는가?
- [ ] 선택지 목록이 아니라 **판정 하나**(권고안 1개)를 냈는가?

### 6. 커밋 게이트 (출처 `#78`)
- [ ] `git add -A` 후 **제외할 것만** `git reset --`로 뺐는가? (경로를 열거해 나열하지 않았는가 — 878·884 두 번 결함)
- [ ] `git status --porcelain`의 `??`(untracked)가 **0**인가?
