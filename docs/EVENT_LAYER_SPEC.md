# EVENT_LAYER_SPEC — 실시간 이벤트(공시) 사실 레이어 (US 완성형 · 3회 검수 확정본)

> 종목 렌즈 페이지의 **③번째 시계 = 이벤트 사실**. 느린 팩터 렌즈 옆에 "방금 일어난 사실"을 붙이되, **점수에 안 섞고 · 예측 없이 · 판단은 사용자.** 유료(StockTitan·Benzinga WIIM) 벤치마크 + 우리 차별(사건 → 어느 렌즈 신뢰를 흔드는지 연결).
> 관련 결정: `BUSINESS_STRATEGY.md` 2026-07-05("3개의 시계") · 2026-07-04(④ 사실 렌즈 재정의).

## 0. 정체성 가드레일 (절대 규칙)
- **안 섞음**: 이벤트를 팩터 점수에 합산 X (TipRanks Smart Score = 반면교사).
- **예측 아님**: 사건의 '사실 성격'만. "재무 재작성 = 신뢰 훼손"은 사실, "주가 내린다"는 예측 → 금지.
- **⚠️ 플래그 = 데이터 신뢰/신선도 경고 전용.** 절대 '방향 나쁨' 표시 아님. (이거 어기면 정체성 붕괴.)
- **억지 매핑 금지**: 특정 렌즈에 안 붙는 사건(catch-all)은 일반 버킷.
- **애매하면 "내용 봐야 → 원문"** — 좋다/나쁘다 안 찍음.

## 1. 이벤트 3분류 (3회 검수 핵심)
- **A · 근거를 흔듦 (⚠️ 신뢰 경고)** — 그 렌즈 계산의 '입력'이 방금 무효화/노후화. 그 렌즈 카드에 ⚠️ "이 점수 근거가 방금 흔들림/낡음".
- **B · 새 맥락 (📌 렌즈가 아직 못 봄)** — 렌즈 입력은 그대로지만, 판단에 중요한 새 사실. 관련 렌즈 옆 📌 "최근 사실, 아직 반영 안 됨".
- **일반 (버킷)** — 특정 렌즈에 안 붙음. 이벤트 리스트에만.

## 3. 거래량 맥락 (WIIM 핵심 — 빠졌다 재포함)
가격 움직인 이벤트엔 **거래량 동반 여부**를 붙임: "오늘 +8% · 거래량 평소 3배 = 시장이 중요하게 봄" vs "저거래 스파이크 = 참고". → '이 사건이 실질적인지'를 사용자가 판단.

## 4. 구현 (US 완성형 · 무료 결정론)
- **8-K item 코드는 EDGAR 메타데이터**(`data.sec.gov/submissions/CIK.json`의 `items` 필드) → **NLP 없이 결정론적 분류.** 기존 `components/toolbox/SecFeed.tsx` 배관 재활용.
- `lib/eightK.ts` = item→{label, 분류(A/B/general), lens[], 성격, 쉬운말} config(유지보수 1곳·SEC 신설 item 대응).
- API가 심볼별 최근 중대 8-K(위 표 item만 필터) 반환 → 페이지: 이벤트 리스트 + 관련 렌즈 카드에 ⚠️/📌.
- **텍스트 요약·감정 = Pro/LLM**(무료는 item유형+제목+원문 링크로 충분·정직).

## 5. Free / Pro
- **무료**: 최근 중대 8-K 리스트(유형·날짜·링크) + 렌즈 ⚠️/📌 + 하루 1회 팩터.
- **Pro**: 즉시 알림(StockTitan식 속도 티어) · LLM 원클릭 요약 · 뉴스 감정 · 거래량 맥락 자동.

## 6. KR(DART)는 별도 (US 먼저 완성 후)
DART 유형 체계(A정기/B주요사항/C발행/D지분)는 8-K와 1:1 아님 → **별도 매핑 테이블**. US 완성·검증 후 착수.
