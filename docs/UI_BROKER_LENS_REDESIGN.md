# 종목·상품 우측 레일 개편 — 증권사 탭 분리 + AI 렌즈 미리보기 (설계·2026-07-08)

> **동기**: 테스터가 "종목 보는 화면인데 우측에 왜 증권사 바로가기?"라며 혼란. 정보(종목) ↔ 상업(증권사 링크) 혼재 문제. 프라임 우측 레일을 차별화 자산(AI 렌즈)에 내주고, 증권사는 독립 탭으로, 광고는 유료 신청분만.

## 결정 (2026-07-08 사용자 확정)
1. **증권사 바로가기 → 독립 '증권사' 탭 신설** (종목·상품처럼 상단 탭). 발견은 이 탭에서. 국가별 region 기준(KR·US·JP·VN·GB, CN 미보유).
2. **종목·상품 우측 레일(현 w-72 증권사 사이드바) → "선택한 종목 AI 렌즈 미리보기"** 로 교체 + **더 넓게**. 표에서 종목 클릭 → 우측에 그 종목 5렌즈 읽기+신뢰도 요약 → 종목 페이지 전체 렌즈로 연결(딥링크). **기존 수익률 패노라마도 이 패널로 합침.**
3. **광고 슬롯(AdSlotRow) = 유료 신청분만.** 광고주 0일 땐 슬롯 **접기**(빈/깨진 광고처럼 보이지 않게). 옅은 "광고 문의" CTA 하나만.

## 단계 (STEP 분할 — 하나씩 완전히)
- **STEP 662 (이번)**: 증권사 독립 탭 신설(additive). TAB_ORDER에 `broker` + SPECIAL_LABELS + region-aware BrokerRanking 렌더. 보드 사이드바는 이 STEP에선 유지(다음 STEP서 교체). → 증권사 발견 경로 먼저 확보.
- **STEP 663**: 보드 우측 레일 교체 = AI 렌즈 미리보기 패널. 6개 보드(KR·US·JP·CN·VN·GB) 중 **KR 먼저 레퍼런스** → 검증 후 미러. 사이드바 BrokerRanking 제거 + 렌즈 패널 삽입 + 수익률 패노라마 병합 + 레일 폭 확대(w-72→약 w-96). 클릭 종목의 렌즈 = lens_scores/`/api/lens` 재사용. 미선택 시 빈 상태("종목을 고르면 렌즈가 읽어드려요").
- **STEP 664**: 광고 슬롯 유료-only + 빈 상태 접기. (증권사 사이드바 제거로 "무료 노출"이 사라졌으니 유료 동기 강화 — 수익모델 정합.)

## 주의
- 모바일 = 우측 레일 없음(바텀시트). 렌즈 미리보기는 데스크탑 레일; 모바일은 기존 시트에 렌즈 추가는 후속 검토.
- CN은 brokers 미보유 → 증권사 탭에서 CN이면 "준비 중" 빈 상태 or 탭 숨김.
- 662와 663 사이엔 증권사가 탭·사이드바 양쪽에 잠깐 중복 노출(짧은 과도기·수용).
