## 🟢 결정 로그 (현행 · 최신순 — 아래 V3 본문과 별개)

### 2026-07-03 — 🗺️ 제품 청사진 확정: "검증된 기법의 원자 → 방향 → 조합 전략 → TRAI 종합" (4층)
> 긴 전략 대화로 최종 형태 합의. 핵심 = **7개 팩터는 목적지가 아니라 토대(원자)**. 그 위에 층을 쌓되 "사실 vs 전망"을 끝까지 분리.

- **왜 이 방향**: 날것의 7개 팩터만 일반인에게 보여주면 "이걸로 또 따로 분석해야" 하는 느낌 = 부족. 사람들은 이 유명 기법들을 *알아도* 매 종목마다 손으로 돌리기엔 노가다 → **그 계산을 대신 + 각 기법 방법대로 방향까지** 읽어주는 게 진짜 가치. 정답(오른다/내린다)은 못 주지만 "동전보다 살짝 유리한 데이터 근거 + 다각도 맥락"을 줌 → **"이렇게 보인다, 선택은 너."**
- **4층 구조**:
  1. **원자 = 7개 검증된 팩터** (모멘텀·저변동·퀄리티=검증 / 밸류·자산성장=표본약함 / F-Score=건전성 / 기술=참고). ✅ 완료(검증+3중 교차검증+UI 스펙트럼).
  2. **방향 층 = "그 기법 방법대로의 outlook"** — 측정("비쌈")에서 멈추지 않고, 그 기법의 *문서화된 방향 경향*을 적용: **[시간축 단기/장기] · [유리/불리/중립] · [신뢰도]**. **예측 아님** — 그 기법이 원래 검증한 base-rate 경향("이런 특징 종목은 역사적 평균 이런 편")이지 "이 종목 오른다"가 아님. *모든 기법이 수익 방향은 아님*: 모멘텀·밸류·퀄리티·자산성장=수익방향 / 저변동=위험 / F-Score=건전성 / 기술=상태. ← **다음 작업**(로직+카피, 새 데이터·예측 없음).
  3. **조합 전략(분자)** = 검증된 유명 조합 — 가치+모멘텀 · 방어형 퀄리티 · QARP(퀄리티+밸류, "좋은 회사를 싸게"=버핏류) · 피오트로스키 가치(밸류+F) 등. **각 조합도 개별 팩터처럼 검증 통과분만.** 정직 라벨 = **"~류 근사 · 우리 데이터로 이렇게 계산 · 이건 제외"**(예: 버핏의 정성적 해자·경영 판단은 숫자 밖이라 제외 = 느슨한 근사). 마법공식은 진짜 ROC 데이터 없어 보류(억지 근사 X).
  4. **TRAI = 최종 종합 전망** — 팩터·전략의 현재 사실 + 최근 뉴스·시장을 AI가 종합한 단기/장기 outlook. **명확히 "전망/의견"(예측 아님·보장 아님) 라벨.** 토대 다 깔고 **맨 마지막**(STEP 511 보류 유지). 애널리스트의 딥다이브(DCF·목표주가)에 대응하는 층.
- **인프라**: 방향까지 정해지면 **전 종목 하루 1번 미리 계산**(현재 사실 일괄) → "이 기법 눈에 지금 강한 종목" 랭킹·스크리닝 열림.
- **관통 원칙**: 되는 건 검증해서, **안 되는 건 솔직하게 뺌**(마법공식 보류·주주환원/발생액 탈락) — 이 절제가 "되는 것"의 신뢰를 만듦. **사실(팩터/전략)과 전망(TRAI)을 끝까지 분리** = 아무도 안 하는 차별점.
- **데이터**: 유료 팩터는 기회주의적(무료 소스 나오면 추가, 아니면 뺌).

### 2026-07-03 — 제품 정의(포지셔닝) 확정: "예측 아님. 검증된 렌즈들의 읽기 + 신뢰도, 선택은 사용자"
- **정의**: 미래를 맞히는 오라클이 아니라, **프로들이 쓰는 검증된 기법(팩터)들이 이 종목을 각각 어떻게 읽는지 + 각 기법이 얼마나 믿을 만한지**를 한자리에 보여주고 — 선택·판단은 사용자.
- **핵심 논리**:
  - 점수(팩터)는 본질적으로 "과거가 이랬으니"의 역사적 외삽 → 그래서 예측 아님·나침반. 앞을 보려면 새 정보·리스크 추론(TRAI)이 얹히되, 그것도 **"근거 있는 조건부 예상"이지 예측 아님**(역사는 rhyme하지 repeat 아님·비정상성). 유추도 팩터처럼 데이터로 grounding.
  - **기법끼리 엇갈림 = 상품**(모멘텀 강세 vs 밸류 비쌈 = "이건 성장주다"라는 정보). 숨기지 말고 지도처럼 보여줌.
  - 각 기법 = 읽기 + **신뢰도 등급(겉면 노출)** + 자세히(검증) → 사용자의 "정보에 근거한 선택".
  - 개인이 혼자 모든 검증된 기법을 종목마다 못 돌리니 = 진짜 가치(커머디티 데이터 허브와 다름).
  - 법적으로도 안전: 예측·투자권유 아님, 분석 틀 제시 + 판단 본인. "나침반이지 선장 아님"이 마케팅이 아니라 실제 제품 구조.
- **UI 함의**: "쉬운 해석(이해→선택)" + "자세히(검증→신뢰)" 2층은 STEP 541로 넣음. 남은 것 = **신뢰도 등급 겉면 노출** + 엇갈림 표시(②단계).
- **로드맵·기법 로스터**: `docs/LENS_ROADMAP.md` (3단계 순서 + 현재 5 + 추가 후보).

### 2026-07-03 — 종목별 "종합 데이터 허브"(뉴스·재무·리포트·거시 전면 붙이기)는 만들지 않는다
- **논의**: 종목 렌즈 페이지(예: BRK-A)에 그 종목의 뉴스·재무·리포트·거시를 다 붙여 매일 갱신하고 기법에 연결하자는 아이디어.
- **결정**: **전체 종합 허브 = 보류/비추.** 얇은 "근거 노출"만 우리다움으로 채택.
- **이유**:
  1. 종목 클릭 → 뉴스·재무·리포트·거시 = **네이버·토스·야후가 이미 하는 commodity(기본기)**. 데이터·라이선스·인력 정면 승부는 우리 해자 아님.
  2. **우리 해자 = "정직하게 검증된 렌즈 해석"이지 데이터 양이 아님.** 산더미 데이터는 그 특별함을 소음에 묻음.
  3. 큰 공사(심볼별 집계·라이선스·캐시). 정체성(허브)엔 맞아도 → **"정체성에 맞다 ≠ 우리 해자다."**
  4. **중요 구분**: 뉴스·거시(맥락)는 결정론 렌즈 숫자를 **안 바꿈**(렌즈 입력 = 가격·재무뿐). 맥락은 사용자 표시 + 미래 TRAI(LLM) 해석 재료일 뿐 — "데이터 많이 붙였으니 기법이 정확해졌다"는 착각 금지.
- **대신 할 것(저비용·우리다움)**: 그 렌즈가 **실제 쓴 근거만 얇게** 노출(F-Score 옆 재무 수치·모멘텀 옆 가격 흐름) + 뉴스 몇 줄+링크 정도 → 신뢰 강화.
- **조건부 미래**: 넓은 맥락은 **TRAI가 필요할 때 온디맨드로만**. 전 종목 DB 사전적재는 비추(비용·스케일).
- **교훈**: commodity 따라잡기에 시간 쓰지 말 것. **"뭘 안 만들까"를 정하는 게 코드보다 남는 장사.** (V3 §34 "미니 블룸버그 터미널" 지향에서 의식적으로 이탈 — 우리는 터미널이 아니라 "정직한 해석"이 축.)

## 1. 서비스 정의

### 핵심 콘셉트
"전업투자자의 투자 환경을 일반 투자자에게 월 구독료로 제공하는 서비스"

### 문제 인식
전업투자자들은 투자할 때 수십 개의 창을 동시에 열어놓고 본다:
- 재무제표 (DART)
- 수급 데이터 (KRX)
- 공시 (DART)
- 공매도/신용잔고 (KRX)
- 내부자 거래
- 배당 데이터
- 뉴스 (여러 경제 매체)
- 섹터별 자금 흐름
- 거시경제 지표 (한국은행, FRED)
- 실시간 차트 (TradingView)

일반 투자자는 이 세팅을 따라하려면 수년이 걸리고, 어디서 뭘 봐야 하는지조차 모른다.

### 해결책
이 모든 데이터를 하나의 플랫폼에 통합해서 보여준다 — "미니 블룸버그 터미널" for 개인투자자.

### 핵심 가치
- **정보의 통합**: 흩어진 투자 정보를 한 곳에
- **접근성**: 전문가 수준의 데이터를 누구나 쉽게
- **시간 절약**: 세팅에 수년 걸리는 환경을 즉시 제공

## 2. 투자심사 Q&A (내부 검증 완료)

### 질문 1: 경쟁사 대비 차별점은?
**결론: 이 갭은 실재한다**
- 한국에 주식 관련 "모든 데이터"를 한 플랫폼에 모아놓은 서비스가 없음
- 네이버증권은 기본 데이터만, 증권사 HTS는 자사 고객만, 유료 서비스들은 특정 데이터만 제공
- StockTerminal은 공시+수급+공매도+내부자+배당+뉴스+거시경제+AI정리를 "전부" 통합
- 링크 허브까지 포함해서 투자자가 필요한 모든 외부 사이트도 카테고리별 정리

### 질문 2: 개발/운영 비용은 감당 가능한가?
**결론: 개발비 0원, 운영비 최소**
- 개발: Claude Code로 전체 개발 → 외주 비용 0원
- 인프라: Vercel(무료~$20/월) + Supabase(무료~$25/월) = 거의 0원으로 시작
- 데이터: DART, KRX, ECOS, FRED 전부 무료 공공 API
- AI: OpenAI GPT API만 유료 (종목당 분석 비용 매우 저렴)
- 자동화: Make(Integromat) 무료 플랜으로 시작 가능
- **기존 인프라 활용**: 창업자가 주식/가상화폐 광고주 허가 콜센터를 운영 중이라 광고주 네트워크 확보됨

### 질문 3: 규제/법적 리스크는?
**결론: "데이터 정리" 포지셔닝으로 회피**
- 핵심 결정: AI의 역할을 "주가 예측"이 아닌 "공개 데이터를 분석 기법별로 정리"로 설정
- 투자 자문이 아닌 "데이터 정리 서비스"이므로 금융감독원 규제 대상 아님
- 모든 페이지에 면책 조항 표시: "본 사이트는 투자 자문이 아니며, 투자 책임은 본인에게 있습니다"
- 배너 광고에도 면책 고지: "광고 배너는 광고주가 직접 등록한 것이며, 사이트는 광고 내용에 대한 책임을 지지 않습니다. 인증마크는 사업자등록 확인을 의미하며, 상품의 품질이나 수익을 보증하지 않습니다."

### 질문 4: 커뮤니티 관리는?
**결론: 플로팅 채팅 + 자동 모더레이션**
- 별도 커뮤니티 페이지를 만들면 채팅이 "너무 무거워"지고, 채팅방 링크 배너 목적과 충돌
- → 커뮤니티 페이지 삭제, 플로팅 채팅만 유지 (화면 좌하단)
- 금칙어 자동 필터 (투자 권유, 스팸 링크, 리딩방 홍보 등)
- 제재 시스템: 경고 → 30분 음소거 → 1개월 음소거
- 링크 입력 차단 (스팸 방지)
- 사업자 인증 안 된 광고성 글 차단

## 3. AI 전략 — "예측"이 아닌 "정리"

### 왜 이렇게 결정했나
- 창업자 인사이트: "AI가 판단해주는 걸 얼마나 믿겠어. 정보를 한눈에 보여주는 게 더 가치 있다"
- AI가 "이 종목 올라갑니다"라고 하면 → 틀리면 신뢰 상실, 법적 리스크
- AI가 "이 종목의 가치투자 관점 데이터 정리"라고 하면 → 틀릴 수가 없음 (사실만 정리)

### AI 분석 5가지 기법
1. **가치 분석**: PER, PBR, ROE, 부채비율 등 재무 데이터 정리
2. **기술적 분석**: 이동평균, RSI, MACD 등 기술적 지표 정리
3. **퀀트 분석**: 팩터 점수, 모멘텀, 밸류 팩터 정리
4. **배당 분석**: 배당수익률, 배당성향, 배당 히스토리 정리
5. **수급 분석**: 외국인/기관 매매 동향, 공매도 비율 정리

### AI 출력 형식
- "~입니다" 서술형 (자연어 요약)
- 절대 "매수/매도 추천"이라는 표현 사용 금지
- "공개된 데이터를 기반으로 정리한 내용입니다"라는 고지 항상 포함

### ⭐ Trillion AI 분석 — 최종 단계 로드맵 (전망 레이어) · 2026-06-25 사용자 확정

> **2층 구조(모순 아님)**: 위 "AI = 정리(예측 X)"는 **현 플랫폼 핵심**(무료+프리미엄 '정리')에 그대로 유효 — 신뢰·무신고 유지. **그와 별개로**, 플랫폼·데이터 기반·MVP가 완성된 **최종 단계**에 'Trillion AI 분석' = **유료 전망·분석 레이어**를 딥하게 구축. **그래서 의도적으로 제일 마지막으로 미뤘다(= 확실히 기억할 것).**

- **형태**: 세상의 검증된 정통 기법 선별 → **skill(.md 지시문)로 박제** → 실시간 전망·분석 글 자동 생성 → **구독**. (AI Berkshire 패턴 참조: skill화·표준출력·반편향·코드 정밀계산·강세vs약세 균형. github.com/xbtlin/ai-berkshire, MIT — 성과 주장은 무시, 구조만.)
- **성격**: "어디서 사라"가 **아님** → "이 뉴스면 이 종목 이렇게 움직일 전망" 식 **전망·분석 콘텐츠**. (정리 ≠ 전망 — 이 레이어는 의도적으로 전망까지 감.)
- **확장성(핵심)**: 기법은 **국가 불문** → 지금 쌓는 **국가별 데이터 기반이 곧 이 엔진의 해자**. KR 완성 → 같은 엔진을 각국 데이터에 그대로 얹음(나라별 특징·데이터·법률만 조정).
- **규제(반드시)**: 한국에서 **불특정 다수에게 구독료 받고 전망·분석 제공 = 유사투자자문업(자본시장법) → 금융위 신고 대상.** "사라"가 아니어도 "오를 전망"류 의견은 투자조언으로 볼 수 있음 → **그래서 최종 단계**(신고는 추후). 각국 규제 상이(미국 SEC·investment adviser·publisher 예외 등). ※유료화 전 금융·핀테크 변호사 확인 필수.
- **차별점**: 타 리딩방과 달리 **신고 완료 + 방법론 공개 + 적중/빗나감 트랙레코드 투명 + 매수추천 X** → "안 속는 곳" 브랜드의 확장(심판이 직접 모범 선수). 리딩방·검증과의 정체성 긴장을 **투명성으로 역전**.
- **우선순위**: 지금은 **데이터 기반 + MVP(해자) 완성**에 집중. 이 레이어는 그 **다음**.

## 5. 다국가 확장 전략

### 핵심 아이디어
"같은 템플릿, 데이터 소스만 교체"
- 국가를 추가할 때 코드를 새로 짜는 게 아니라, 데이터 소스 연결 + 언어 번역만 하면 됨
- 한계 비용이 거의 0에 수렴

### 확장 로드맵
```
Phase 1: 한국 (코스피/코스닥) — 현재
Phase 2: 미국 (나스닥/NYSE) — 데이터 소스 이미 준비 (SEC EDGAR, FRED)
Phase 3: 일본 (TSE) / 홍콩 (HKEX) — 한국 투자자들이 많이 거래하는 시장
Phase 4: 크립토 — 별도 브랜드 분리, 24시간 시장, 국경 없음
Phase 5: 글로벌 — 영어 버전, 유럽/남미 시장 추가
```

### 국가 추가 시 필요한 것
1. 해당 국가의 공시 API (한국=DART, 미국=SEC EDGAR, 일본=EDINET)
2. 해당 국가의 거래소 데이터 (한국=KRX, 미국=NYSE/NASDAQ)
3. 해당 국가의 거시경제 API (한국=ECOS, 미국=FRED)
4. 언어 번역 (한국어 → 영어/일본어)
5. 결제 현지화 (한국=토스페이먼츠, 글로벌=Paddle)

### 수익 곱하기 효과
- 국가별 구독료 + 국가별 광고주 = 병렬 수익 구조
- 한 국가에서 성공한 모델을 복제하면 됨

## 8. 핵심 설계 결정 기록

### 결정 1: 커뮤니티 페이지 삭제
- **이유**: 별도 커뮤니티 페이지는 채팅을 "무겁게" 만들고, 채팅방 링크 배너 광고와 목적이 충돌
- **대안**: 플로팅 채팅만 유지 (좌하단, 접었다 펼 수 있음)
- **효과**: 가벼운 소통 + 배너 광고와 공존

### 결정 2: AI는 "정리"만 한다
- **이유**: 예측은 틀릴 수 있고, 법적 리스크와 신뢰 문제 발생
- **원칙**: AI는 공개 데이터를 분석 기법별로 정리만 하고, 매수/매도 추천 절대 안 함

### 결정 3: PC 우선 개발
- **이유**: 투자 데이터 터미널은 PC 환경이 주력 사용 환경
- **순서**: PC 완성 → 태블릿 → 모바일 순으로 반응형 대응

### 결정 4: MVP가 아닌 완성품
- **이유**: "절대 MVP라고 생각하지 마" — 처음부터 완성도 있게 만들어야 함
- **원칙**: 기능 축소 없이 전체 기능을 구현하되, 데이터가 없는 부분은 empty state를 깔끔하게

### 결정 5: 개발비 0원 전략
- **이유**: "세계최강의 코딩 AI Claude Code가 있는데 왜 개발비를 쓰냐"
- **방법**: Claude Code로 전체 개발, 인프라는 무료/저가 클라우드 활용
- **절감액**: 외주 개발 시 예상 비용 500~1000만원 → 0원

### 결정 6: Supabase 프로젝트 분리
- **이유**: 기존 POTAL 프로젝트와 테이블명이 겹치면 데이터 손상
- **규칙**: StockTerminal 전용 Supabase 프로젝트(OT-Marketing) 사용, 절대 섞지 않음
