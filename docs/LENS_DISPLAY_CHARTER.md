# 렌즈 표시 헌장 (Lens Display Charter)

> **목적**: 모든 렌즈 카드가 지켜야 할 **표시 규칙**. 새 카드를 만들거나 고칠 때 이 체크리스트를 통과해야 한다. **F-Score 카드가 첫 적용 사례이자 기준 템플릿**(§6).
> **왜 있나**: 규칙이 흩어져 있으면 카드마다 제각각이 되고(예: 신뢰도 등급이 실수로 빠짐), 우리다움(정직·근거·중립)이 새어나간다. 이 헌장이 그걸 막는 강제 체크리스트다.
> **적용 대상**: `/stock/[symbol]` 렌즈 카드 7종(모멘텀·저변동·밸류·퀄리티·자산성장·기술·F-Score) + 상단 공지.

## 0. 대원칙 (모든 카드 공통)
1. **예측 아님** — 검증된 기법이 '지금 이 종목을 어떻게 읽는지'만. 미래 단정 X.
2. **중립** — "사라/사지마라" X. 조건·사실만 제시(스크리너식 '픽' 금지).
3. **근거 있게** — 임의 해석 금지. 저자·학계가 정한 기준을 **그대로**, 그런 게 없으면 "실무 관행"이라 정직하게 꼬리표. (예: "피오트로스키가 3구간 정함"이라 쓰면 거짓 — 그는 8~9/0~1 극단만 정했고 3구간은 관행.)
4. **보는 사람의 언어로** — 전문가·초보 둘 다 이해. **전문용어는 남기되 쉬운 풀이를 () 안에 병기.** (유치해도 초보가 0.5초 만에 아는 게 이긴다.)
5. **외부 정보(뉴스·공시)도 사실로만** — AI가 '종합 결론/전망'을 대신 내리지 않는다. 뉴스·이벤트는 사용자가 판단할 *재료*(자체 렌즈·사실 플래그)로만 제시. **결론은 영원히 사용자 몫.** (유료 플랫폼도 뉴스를 팩터로 쓰지만 마지막 Buy/Sell 권유가 선을 넘는 지점 → 우린 확률·방향까지만.)

## 1. 상단 공지 = 범례 (페이지당 한 번)
- "이 화면 읽는 법": ①예측 아님 ②카드마다 **신뢰도 등급 4개**(검증 · 표본약함 · 참고용 · 건전성)가 뭔지 ③중립 선언("사라/사지마라 안 함").
- 카드의 등급 배지는 이 범례를 읽는 **꼬리표**. (범례=한 번 설명 / 배지=매 카드 라벨.)

## 2. 카드가 반드시 채우는 칸
1. **정식 이름(크게)** + **신뢰도 등급 배지**(필수·§1의 4개 중 하나) + 한 줄 기능.
2. **"이게 뭐예요?"** — 지금 *뭘 하는지*만(쉬운 말 한 덩어리).
3. **이 종목 판정** — 데이터를 **그대로** 시각화(트래커/스펙트럼) + 핵심 숫자. **저자 기준 그대로**, 우리 문장 해석은 최소.
4. **자세히(접힘)** — box에 **없는 것만**: 점수/구간 읽는 법 · 유래(저자·연도) · **얼마나 믿나(우리 검증 근거)** · 한계. 근거 수치는 **전문용어 + (쉬운 풀이)** 로 항상 노출.

## 3. 역할 분리 (중복 금지)
- **box = "뭘 하나" / 자세히 = "어떻게 읽고·얼마나 믿나".** 같은 말 두 번 쓰지 않는다.
- "수익 신호냐 아니냐"는 **등급 배지 + 범례**로 겉에서, 그 **근거**는 자세히에서 — 한 번씩만.

## 4. 밀도
- **기본 펼침은 가볍게**: [이게 뭐예요 + 시각화 + 한 줄 판정]까지만.
- 상세(개별 항목 · 구간 · 유래 · 한계)는 **'자세히' 뒤로 접는다**. — 이건 7장 중 1장임을 잊지 말 것.

## 5. 경쟁 레퍼런스 대조 (각 기법 완성 전 필수)
- 완성 전, **유료·정확 플랫폼**(GuruFocus · Stockopedia · Simply Wall St 등)이 그 기법을 어떻게 표시하는지 대조한다.
- 목적: ① 우리 구조가 업계 표준과 맞는지 검증 ② 표준에 있고 우리에 없는 것 발견(예: 그룹핑·추세) ③ 우리 차별점(쉬운 말·정직한 검증) 유지.

## 6. 기준 템플릿 — F-Score 적용 예 (2026-07-04 확정)
- **헤더**: "Piotroski F-Score"(크게) + `[건전성]` 등급 배지 + "· 부실 위험 체크"(기능).
- **이게 뭐예요?**: "재무가 튼튼한지 9가지로 점수 매겨요 — 돈 잘 버는지, 빚 감당되는지, 작년보다 나아졌는지." (*뭘 하나*만.)
- **판정**: 9칸 트래커(양호=초록 채움) + "6/9" + "9개 중 6개 양호 — 점수 높을수록 재무가 튼튼해요. 지금은 중간 정도."
- **자세히**:
  - **9항목 3그룹** (GuruFocus·Stockopedia 표준 그룹핑): 수익성(4) · 재무 안정성(3) · 효율성(2). 그룹별 통과 수 표기. 각 항목 = 전문용어 + (쉬운 풀이) + 근거 수치.
  - **점수 읽는 법**: 실무 관행 7↑ 양호 / 4~6 중간 / 0~3 취약 (피오트로스키식 9신호 합산·높을수록 튼튼).
  - **유래**: 회계학자 피오트로스키가 2000년, 저평가 가치주 중 부실(가치 함정) 거르려 만듦.
  - **얼마나 믿나(왜 '건전성' 등급)**: 우리 넓은 표본·12년 백테스트에선 점수↔수익 관계 없음(t≈0.7) → '수익 예측'이 아니라 '재무 건전성 해석'으로만.
- **9개 항목 쉬운 풀이(확정)**:
  - ROA 양수 (돈을 벌어요·흑자) / 영업현금흐름 양수 (팔아서 진짜 현금이 들어와요) / ROA 개선 (작년보다 더 잘 벌어요) / 이익의 질 (번 돈이 진짜 통장에 들어와요)
  - 장기부채비율 하락 (빚 부담이 줄었어요) / 유동비율 개선 (급할 때 갚을 돈이 늘었어요) / 신주발행 없음 (주식을 새로 안 찍어냈어요)
  - 매출총이익률 개선 (팔면 남는 게 많아졌어요) / 자산회전율 개선 (가진 걸로 더 많이 팔아요)
- **보류(다년 데이터 깔리면)**: F-Score 추세(연도별) · 동종/중앙값 대비.
