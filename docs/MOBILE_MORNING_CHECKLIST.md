# 🌅 모바일 아침 체크리스트 (STEP 377~380 적용 후)

> 실제 폰 또는 크롬 개발자도구(Cmd+Shift+M → iPhone SE 375 / iPhone 14 390)에서 화면별로 확인.
> **접속**: Mac `npm run dev` 중 → 같은 와이파이 폰에서 `http://<Mac-IP>:3333`. (Mac IP: 시스템설정 → Wi-Fi)
> 이상한 곳은 Cowork에게 "○○ 화면 △△ 부분"이라고 말하면 바로 STEP으로 고침.

---

## 1. 홈 / 게이트웨이
- [ ] 좌우 여백 적당(너무 붙거나 넘치지 않음)
- [ ] 한국/미국 토글, 카테고리 탭 가로 스크롤 매끄러움 + 탭 누르기 편함
- [ ] **종목·상품 표** = 현재가·1일·1주일·1년 4컬럼만, 가로 스크롤 거의 없음
- [ ] 표 아래 **증권사 바로가기** 목록 보임(모바일에서 새로 생김)
- [ ] 뉴스·공시·거시 등 피드가 세로로 잘 쌓임(좌우 안 잘림)
- [ ] 지수 티커(상단 마퀴) 정상 흐름

## 2. 리딩방·검증
- [ ] 검색창·플랫폼 탭·정렬 줄 안 깨짐
- [ ] 항목 탭 → 하단 **바텀시트 미리보기**(⭐ 즐겨찾기 포함) 뜸
- [ ] "+ 리딩방 등록" 버튼 보임(모바일용)
- [ ] 목록 행 이름·아이콘·바로가기 정렬 정상

## 3. 유튜브
- [ ] 순위 목록 + "N월 N주차 기준" 상단 표시
- [ ] "바로가기 🔗" 라벨 보임

## 4. 마이페이지
- [ ] 탭 = **프로필 / 내 신고** 2개만(즐겨찾기 탭 없어야 정상 — /favorites로 이동)
- [ ] 프로필 폼·신고 표 모바일에서 안 깨짐

## 5. 즐겨찾기 (헤더 ⭐ → /favorites)
- [ ] 링크·리딩방 섹션 표시 + 드래그 순서변경 동작
- [ ] 좌우 여백 적당

## 6. 헤더 / 푸터
- [ ] 헤더 한 줄에 로고·주식/코인·아이콘 안 넘침
- [ ] 국가/프로필 드롭다운 화면 밖으로 안 나감
- [ ] 푸터 2열 + 사업자정보 줄 자연스럽게 줄바꿈

## 7. 법정 페이지 (이용약관·개인정보처리방침·소개)
- [ ] 좌우 여백·본문 readable

## 8. 전반
- [ ] 어느 화면도 **가로 스크롤(표 제외) 없음**
- [ ] 버튼/링크 손가락으로 누르기 편함(너무 작지 않음)
- [ ] 글자 너무 작은 곳 없음

## 🔧 아침에 Cowork과 미세조정 후보 (예상)
- 종목·상품 표: 스크롤 시 **종목명 좌측 고정(sticky)** 추가할지 — 실제 폰 보고 결정.
- 뉴스 대표 이미지 높이 미세조정(h-32 적당한지).
- 리딩방 컨트롤 줄이 2줄로 접힐 때 간격.
- 헤더 메뉴(주식/코인) 너무 좁으면 간격.
