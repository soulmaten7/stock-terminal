## 2) 결과 전체를 그대로 붙여넣어 보고 (특히 아래 순서로 확인)
1. **[데이터 커버리지] 줄** — 먼저. `EDGAR성공 N/250`, `자기자본태그無`, `순이익無`, `주식수無`.
   - 👉 성공 종목이 너무 적거나(예 <80) 자기자본/순이익/주식수 無가 많으면 = **데이터 부족 문제**. 밸류 기각 아님 → 태그 보강 필요(STEP 521에서). 원인부터 진단.
2. **[관측치] 줄** — E/P·B/M 각 몇 건. (수백 건은 돼야 통계 의미.)
3. **E/P POOLED / B/M POOLED spread(싼−비쌈)** — 핵심 숫자.
   - `+`(양수) = 싼 종목이 비싼 종목보다 이후수익 높음 = **가치 프리미엄 존재(검증)**.
   - `0~음수` = 이 유니버스·기간에선 안 통함(정직 기각 or 조건부).
4. **코호트별 표** — 프리미엄이 특정 연도만인지(2017~2020 성장주 국면 침체 등) 전반적인지.

## ✅ 판정 기준 (STEP 521에서 반영할 것)
- E/P·B/M 둘 다 뚜렷한 `+` → **밸류 검증** ("미검증" 라벨 해제, 적합영역·플레이북 갱신).
- 한쪽만 / 약함 → **조건부** (어느 지표·어느 국면에서 유효한지 명시).
- 둘 다 ≤0 → **정직 기각** (렌즈는 "참고용" 유지, 왜 안 통했는지 기록).
- **어느 경우든** 커버리지가 부실하면 데이터부터 보강 후 재실행 (기법 판정은 그 다음).
