# AI 렌즈 — 주식 분석 기법 정밀 매핑표
> "AI보기" 기능의 설계 근거. 기법 × (결정론/LLM) × 오픈소스 × 데이터 × 무료/유료 × 라이선스.
> 목표는 **예측기 아님** — 기법을 정확히 돌리고 방향성을 정직하게 보여주는 "나침반". (2026-07-02)

## 0. 관통 원칙 (다시 못박음)
- **예측(❌) → 해석·방향성(⭕)**: "정확한 예측"이 아니라 "기법 정확 실행 + 단기/장기 방향성 + 백테스트로 정직한 신뢰도".
- **학습 = 재훈련(❌) → 맥락 검색+추론(⭕)**: 종목 프로파일·과거·시장을 *끌어와서* 새 정보를 해석(RAG식). 예측 모델 훈련 아님.
- **무료/유료 = 비용선 따라감**: 결정론적 계산(싸다) = **무료**, LLM 종합 해석(토큰비용) = **유료(온디맨드)**.
- **결정론은 코드(Python), 산수는 LLM에 안 시킴.** LLM은 추출·요약·해석만.

## 1. 결정론적 기법 (공식 → 무료 가능, 저비용)
FinanceToolkit(MIT, 180+ 지표·공식 투명) + pandas-ta/TA-Lib(기술지표)로 대부분 커버. **데이터만 우리 걸로 대면 됨.**

| 기법 | 무엇을 보나 | 오픈소스 로직 | 필요 데이터 (Trillion) | 티어 |
|---|---|---|---|---|
| 피오트로스키 F-Score | 재무 건전성 9점 | **FinanceToolkit** ✅ | 재무제표 (DART무료/야후) | 무료 |
| 알트만 Z-Score | 부도위험 | **FinanceToolkit** ✅ | 재무제표 | 무료 |
| 마법공식(Greenblatt) | ROC+이익수익률 랭킹 | 공식(ratios) | 재무제표 | 무료 |
| 그레이엄 방어적/NCAV | 저평가·안전마진 | 공식(ratios) | 재무제표 | 무료 |
| 밸류에이션 DCF | 내재가치 | **FinanceToolkit** ✅ | 재무+추정 | 무료(가정 노출) |
| PER/PBR/EV-EBITDA 밴드 | 과거밴드 대비 위치 | 공식 | 재무+가격(보유) | 무료 |
| 퀄리티(ROE·마진·DuPont) | 수익성·질 | **FinanceToolkit** ✅ | 재무제표 | 무료 |
| 듀얼모멘텀(Antonacci) | 절대+상대 모멘텀 | 가격수익률 | 가격(보유) | 무료 |
| 팩터 랭킹(밸류·모멘텀·저변동·퀄리티) | 팩터 점수 | ratios+가격 | 재무+가격 | 무료 |
| 기술지표(MA·RSI·MACD·볼린저·RS) | 추세·과열·상대강도 | **pandas-ta/TA-Lib** ✅ | 가격(보유) | 무료 |
| CAN SLIM | EPS성장·신고가·RS(+정성) | 정량부 공식 | 재무+가격 | 무료(정량부) |

→ **이 레이어가 차별화의 핵심.** 4개국(KR·US·JP·CN) 종목마다 유명 기법 결과를 **무료**로 주는 곳은 한국에 없음. 우리는 데이터·허브가 이미 있어 저비용.

## 2. LLM 해석 기법 (추론 → 유료, 온디맨드)
"AI보기" 눌렀을 때 그 종목만 그 자리에서 계산(토큰비용 발생 지점).

| 기법 | 무엇을 하나 | 데이터 (Trillion) | 티어 |
|---|---|---|---|
| 뉴스 감성·영향 해석 | 이 종목 맥락에서 뉴스 의미 | 뉴스 피드(보유) | 유료 |
| 공시 요약·리스크·모순 | 사업보고서/공시 핵심·플래그 | DART/공시(보유링크) | 유료 |
| 리포트·컨센서스 해석 | 목표가·의견 변화 의미 | 리포트(제한적) | 유료 |
| 거시 연결 해석 | 금리·환율·국면→종목 영향 | 거시 피드(보유) | 유료 |
| 해자·경쟁력(버핏式) | 정성 경쟁력 | 프로파일+공시 | 유료 |
| **종합 "AI보기"** | 위+프로파일 묶어 **기법별 단기/장기 방향 서술** | 전부 | 유료(핵심) |

→ 오픈소스 **ai-hedge-fund**(43k★)의 페르소나/분석 에이전트가 이 해석 로직의 참고 뼈대. (버핏·그레이엄·멍거·린치·우드·버리·다모다란 + 밸류/감성/펀더멘털/기술/리스크 에이전트)

## 5. 무료/유료 경계 (요약)
- **무료**: §1 결정론 기법 결과 (종목별 F-Score·Z·밸류밴드·모멘텀·기술지표·팩터). 데이터 보유분+DART로 저비용.
- **유료(저렴한 구독)**: §2 LLM "AI보기" — 실시간 뉴스/공시/리포트/거시를 종목 맥락에서 종합한 **기법별 단기/장기 방향성 서술**. 온디맨드(누르면 계산).
- 근거: 무료가 유입·신뢰, 유료가 토큰비용 회수. 증권사 광고(브로커 DB·슬롯 보유)는 별도 축.

## 6. 1단계 파일럿 추천 (백그라운드 최소 버전)
1. **범위**: 반도체 섹터 3~4종목 (삼성전자·SK하이닉스 + NVDA·마이크론).
2. **무료 레이어**: 결정론 기법 3개만 먼저 — **F-Score · 밸류에이션 밴드(PER/PBR) · 모멘텀/RSI**. (FinanceToolkit + 보유 가격데이터, KR재무=DART)
3. **유료 프로토**: 종목 1개에 "AI보기" — 최근 뉴스/공시 + 프로파일을 LLM이 종합해 기법별 단기/장기 방향 1장. 온디맨드.
4. **섹터 집계**: 3~4종목 결과를 묶어 "반도체 국면" 한 줄.
→ 이게 되면 기법·종목·국가를 확장.
